▷ Central Question

How do we know whether a trained model is actually good? A useful metric has to match the kind and cost of error that matters for the decision being made.

⚡ Ek Line Mein

In regression errors have a size: MAE (linear, original units), MAPE (relative %), MSE/RMSE (punish large errors), $R^2$ (how much better than the mean baseline), Adjusted $R^2$ (charges you for extra predictors). In classification errors have an identity: the confusion matrix shows which class got confused with which, and precision/recall/F1 focus on one specific class.

1Training Has Ended; Evaluation Begins

▷ Central Question

The model has already chosen its parameters. Are we measuring how it learns, or judging how well the finished model performs?

Training lossEvaluation metric
Main roleGuides parameter updates during trainingJudges a fixed model after training
Typical dataTraining dataValidation or test data (for generalisation)
ExampleMSE used by an optimiserMSE, MAE, $R^2$, F1 etc. reported after fitting
★ Key Insight

The same expression can play both roles. MSE is a loss when it guides learning, and an evaluation metric when it judges a finished model. Context decides the role.

Checkpoint 1

Set the context — write L (training loss) or E (evaluation metric)

StatementAnswer
(a) It is calculated on a held-out test set after parameters are fixedE
(b) The optimiser uses it to update coefficientsL
(c) It answers whether the finished model is acceptable for a decisionE

Can one number tell us everything about a model? No. A single number always aggregates something away. 66.7% accuracy can hide the fact that an entire minority class is barely being detected. $R^2 = 0.93$ says nothing about the actual size of the error. So always report a set of complementary metrics.

3Regression Error Metrics

▷ Central Question

Signed residuals show direction, but positive and negative values cancel each other out (see above: the signed total is only $-4$ even though individual errors reach 5). So how do we summarise the size of all eight errors?

3.1 Mean Absolute Error (MAE)

QuestionHow large is the typical absolute miss, in the original target unit?
Formula & result$\text{MAE} = \dfrac{1}{n}\sum_{i=1}^{n}|e_{A,i}| = \dfrac{22}{8} = \mathbf{2.75}$ thousand INR
AdvantageEasy to interpret; every extra unit of error gets equal linear weight.
DisadvantagesHides direction, depends on the target scale, and does not emphasise a rare large miss.

3.2 Mean Absolute Percentage Error (MAPE)

QuestionHow large is the typical error relative to the actual value?
Formula & result$\text{MAPE} = \dfrac{100}{n}\sum_{i=1}^{n}\left|\dfrac{e_{A,i}}{y_i}\right| = \dfrac{45.50\%}{8} \approx \mathbf{5.69\%}$
AdvantageA scale-free percentage, convenient when relative error is what matters.
DisadvantagesUndefined at $y_i = 0$, unstable near zero, and can over-emphasise small actual values.

3.3 Mean Squared Error (MSE) and Root Mean Squared Error (RMSE)

MetricFormula and Model A resultAdvantageDisadvantage
MSE $\dfrac{1}{n}\sum_{i=1}^{n}e_{A,i}^2 = \dfrac{74}{8} = \mathbf{9.25}$
(thousand INR)$^2$		 Strongly penalises large misses; useful during optimisation. Squared units; sensitive to unusually large errors.
RMSE $\sqrt{\text{MSE}} = \sqrt{9.25} \approx \mathbf{3.04}$
thousand INR		 Keeps the large-error penalty but brings it back into the target unit. Still scale-dependent and more outlier-sensitive than MAE.

  1. Concept check: if one absolute residual rises from 1 to 5, its contribution to $\sum|e_i|$ rises by ______, while its contribution to $\sum e_i^2$ rises by ______. Which metric family reacts more strongly? $$\text{Absolute: } 5 - 1 = \mathbf{4}\ \text{increase}$$ $$\text{Squared: } 5^2 - 1^2 = 25 - 1 = \mathbf{24}\ \text{increase}$$
    The squared family (MSE / RMSE) reacts far more strongly — 6× the increase for the same change in residual.
  2. True or false: "MSE = 9.25 means a typical miss of 9.25 thousand INR."
    False.

    MSE units are squared — (thousand INR)$^2$. The typical miss is RMSE $= \sqrt{9.25} \approx 3.04$ thousand INR. This is the single most common interpretation error.

Homework H1

Verify all four totals from the master table

  1. $\sum|e_A| = 22$ $$2+1+3+3+1+3+4+5 = 22\ \checkmark \qquad \Rightarrow \text{MAE} = 22/8 = 2.75$$
  2. $\sum e_A^2 = 74$ $$4+1+9+9+1+9+16+25 = 74\ \checkmark \qquad \Rightarrow \text{MSE} = 74/8 = 9.25,\ \ \text{RMSE} = 3.04$$
  3. $\sum\text{APE}_A \approx 45.50\%$ $$6.667+2.857+7.500+6.667+2.000+5.455+6.667+7.692 = 45.504\ \checkmark \Rightarrow \text{MAPE} = 5.69\%$$
  4. $\sum e_B^2 = 60$ $$4+1+9+4+1+9+16+16 = 60\ \checkmark$$

    Model B differs only on S4 ($42 \to 43$) and S8 ($70 \to 69$); in both cases it is closer, hence $74 \to 60$.

  5. (c) When would you report MAE, MAPE, or RMSE? And what is MAPE's zero-value limitation?

    MAE — when every unit of error carries the same cost, and when you need one interpretable number for non-technical stakeholders ("on average we are off by 2.75k").
    MAPE — when relative error matters and you are comparing models on different scales (a ₹3k error on a ₹30k stipend means something very different from a ₹3k error on a ₹6 lakh salary).
    RMSE — when one big miss is costlier than many small misses.
    MAPE's zero limitation: $y_i$ sits in the denominator. If any actual value is $0$, the APE becomes undefined (division by zero); and if $y_i$ is very close to zero the APE explodes and dominates the whole average.

4$R^2$ from the Mean-Only Baseline ⭐

▷ Central Question

The previous four metrics tell us how big the residuals are. But is Model A meaningfully better than a model that just predicts the same stipend for every student?

Full computation

Computing $R^2$ for Model A step by step

  1. Step 1 — Build the mean-only baseline $$\bar y = \frac{30+35+40+45+50+55+60+65}{8} = \frac{380}{8} = \mathbf{47.5}$$

    The baseline predicts 47.5 thousand INR for every student, regardless of input.

  2. Step 2 — Measure the total variation available to explain (TSS) $$\text{TSS} = \sum_{i=1}^{n}(y_i - \bar y)^2$$
    $y_i$3035404550556065
    $y_i - \bar y$−17.5−12.5−7.5−2.52.57.512.517.5
    $(y_i-\bar y)^2$306.25156.2556.256.256.2556.25156.25306.25
    $$\text{TSS} = 306.25+156.25+56.25+6.25+6.25+56.25+156.25+306.25 = \mathbf{1050}$$
  3. Step 3 — Measure the variation left after using Model A (RSS) $$\text{RSS} = \sum_{i=1}^{n}(y_i - \hat y_i)^2 = \mathbf{74}$$

    RSS is the residual sum of squares: the squared variation that remains unexplained even after Model A.

  4. Step 4 — Compare leftover variation with original variation $$R^2 = 1 - \frac{\text{RSS}}{\text{TSS}} = 1 - \frac{74}{1050} = 1 - 0.07048 = \mathbf{0.9295}$$

    Equivalent explained-fraction view:

    $$\frac{\text{TSS} - \text{RSS}}{\text{TSS}} = \frac{1050 - 74}{1050} = \frac{976}{1050} = \mathbf{0.9295}\ \checkmark$$
★ Key Insight

TSS is the total squared variation of the actual stipends around their mean. This is the variation the trained model gets a chance to account for. If we only predict the mean, all 1050 of it stays unexplained.

On these students, Model A accounts for roughly 92.95% of the squared variation present around the mean-only baseline. About 7.05% stays unexplained.

Interpret the landmarks

ValueCorrect interpretation
$R^2 = 1$Perfect fit: the predictions match every actual value and $\text{RSS} = 0$.
$R^2 = 0$No improvement over the mean-only baseline: $\text{RSS} = \text{TSS}$.
$0 < R^2 < 1$Better than the mean-only baseline, but some variation is still unexplained.
$R^2 < 0$Worse than the mean-only baseline on the evaluated data: $\text{RSS} > \text{TSS}$.
△ DO NOT LET THIS MISCONCEPTION SURVIVE

$R^2 = 0.93$ does NOT mean 93% accuracy, nor "93% of predictions are correct", nor "7% average error". $R^2$ is a relative sum-of-squares comparison against the mean baseline. For error size, report MAE or RMSE.

Practice P3

Same RMSE, different $R^2$

Q: Two datasets can have the same RMSE but different $R^2$ values. Which additional property changes $R^2$?

The spread (variance) of the target $y$ around its mean — i.e. TSS.

Reasoning: $R^2 = 1 - \frac{\text{RSS}}{\text{TSS}}$ and $\text{RMSE} = \sqrt{\text{RSS}/n}$. The same RMSE (same $n$) ⟹ the same RSS. But $R^2$ also depends on TSS.

Concrete example: both datasets have $\text{RSS} = 74$ and $n = 8$, so both have RMSE $= 3.04$.

  • Dataset 1: stipends in the 30–65 range, $\text{TSS} = 1050$ ⟹ $R^2 = 1 - 74/1050 = \mathbf{0.93}$ — excellent.
  • Dataset 2: stipends all clustered near 47–48, $\text{TSS} = 80$ ⟹ $R^2 = 1 - 74/80 = \mathbf{0.075}$ — almost useless.

Intuition: if everyone's stipend is roughly the same, the mean baseline is already very good — beating it is hard. If stipends are widely spread, the mean baseline is weak and beating it is easy. $R^2$ depends on how difficult your baseline is, not only on your error.

5$R^2$ Limitations and Adjusted $R^2$ ⭐

▷ Central Question

If adding the last digit of a student's roll number nudges training $R^2$ up slightly, has that extra predictor earned its place in the model?

In ordinary least squares, on the training data with an intercept, adding a predictor cannot increase RSS; therefore training $R^2$ cannot decrease. Even a useless feature can fit some noise. $R^2$ rewards fit but never charges for complexity.

Adjusted $R^2$$$R^2_{\text{adj}} = 1 - (1 - R^2)\,\frac{n-1}{n-p-1} \qquad\text{equivalently}\qquad R^2_{\text{adj}} = 1 - \left(\frac{\text{RSS}}{\text{TSS}}\right)\left(\frac{n-1}{n-p-1}\right)$$

where $n$ = number of observations and $p$ = number of predictors, excluding the intercept. The factor $\frac{n-1}{n-p-1}$ grows with $p$, so a new predictor must reduce unexplained variation enough to overcome that bigger penalty.

★ Adjusted $R^2$ — term by term
  • $R^2$ is the model's raw improvement over the mean-only baseline; $1 - R^2$ is the fraction left unexplained.
  • $n$ is the number of observations. The numerator $n-1$ is tied to estimating the target mean.
  • $p$ is the number of predictors, excluding the intercept; $n - p - 1$ are the residual degrees of freedom.
  • The ratio $\frac{n-1}{n-p-1}$ enlarges the unexplained fraction as predictors are added. The outer $1-$ converts it back into an adjusted explained-variation score.
Worked Comparison

Did the extra feature earn its place?

Model B predicts $(32, 34, 43, 43, 49, 58, 56, 69)$ for S1–S8; its extra predictor reduces RSS from 74 to 60. Here $n = 8$.

ModelPredictors$p$RSS$R^2$Adjusted $R^2$
ACGPA + interview score2740.92950.9013
BModel A + roll-number last digit3600.94290.9000
  1. Model A — Adjusted $R^2$ $$R^2_{\text{adj},A} = 1 - \left(\frac{74}{1050}\right)\left(\frac{8-1}{8-2-1}\right) = 1 - (0.070476)\left(\frac{7}{5}\right)$$ $$= 1 - (0.070476)(1.4) = 1 - 0.098667 = \mathbf{0.9013}$$
  2. Model B — Adjusted $R^2$ $$R^2_{\text{adj},B} = 1 - \left(\frac{60}{1050}\right)\left(\frac{8-1}{8-3-1}\right) = 1 - (0.057143)\left(\frac{7}{4}\right)$$ $$= 1 - (0.057143)(1.75) = 1 - 0.100000 = \mathbf{0.9000}$$
  3. Also compute the raw $R^2$ values for comparison $$R^2_A = 1 - \frac{74}{1050} = \mathbf{0.9295}, \qquad R^2_B = 1 - \frac{60}{1050} = \mathbf{0.9429}$$
  4. Decision
    Model B has the higher raw $R^2$ (0.9429), but Model A has the higher Adjusted $R^2$ (0.9013 > 0.9000).

    The roll-number feature did NOT earn its place. Model B reduced RSS (74 → 60) and raised raw $R^2$, but the improvement was too small to offset the third-predictor penalty. The penalty factor jumped $1.4 \to 1.75$ — a 25% bigger penalty — while the unexplained fraction only moved $0.0705 \to 0.0571$ (a 19% reduction).

    Note: using $1-R^2 = \text{RSS}/\text{TSS}$ here avoids carrying rounded $R^2$ values forward — it is more accurate.

★ What Adjusted $R^2$ does — and does NOT — tell us
  • Useful for comparing regression models fitted on the same target and observations but with different $p$.
  • It can decrease when a new feature adds very little explanatory value; normally $R^2_{\text{adj}} \le R^2$.
  • It is not an automatic feature-selection oracle, and not a replacement for validation or cross-validation.
  • Requires $n > p+1$, and $p$ does not count the intercept.
♦ Takeaway — the Part 1 ladder

Signed residual → absolute size → relative size → large-error penalty → target units → mean baseline → feature-count penalty.

★ Why accuracy is not enough

Accuracy counts every wrong label as one error, but it does not identify the type or direction of that error. Consider two completely different mistakes:

  • Error Type 1 — "Missed Ready": a student who is actually Ready but the model predicts Needs Practice or Needs Support. The student was capable, yet the model failed to recognise it.
  • Error Type 2 — "False Ready": a student who is actually Needs Practice or Needs Support but the model predicts Ready. The student needed help, but the model labelled them ready.

Both error types reduce accuracy by exactly one count. The accuracy score alone cannot distinguish between these completely different kinds of incorrect prediction. It cannot tell you whether the model is primarily missing students who need help, or wrongly labelling struggling students as ready. To understand what kind of mistakes are happening and which classes are getting confused, you need the confusion matrix, precision and recall.

Confusion-matrix convention (memorise this)
  • Rows are actual classes; columns are predicted classes (scikit-learn convention).
  • The diagonal cells are exact matches; the off-diagonal cells are specific confusions.

△ Undefined cases

If a model never predicts some class, that class's precision denominator becomes zero. If the evaluation set contains no actual example of a class, its recall denominator is zero. A report must state how the library handled the undefined value (usually by setting it to 0 or raising a warning).

9Macro, Weighted, and Micro Averages ⭐

▷ Central Question

Accuracy gives one overall count. When you need to summarise precision, recall or F1 across several classes — should every class get equal weight, or should bigger classes contribute more?

Provided inputs for aggregation

Back to the original Master Test Data C (Practice P9 was a what-if):

ClassActual countPrecisionRecallF1
Ready80.8570.7500.800
Needs Practice60.5710.6670.615
Needs Support40.5000.5000.500
Where these per-class numbers come from (verify them yourself)

Ready: Precision $= 6/7 = 0.857$ (column R total is 7, of which 6 are truly R). Recall $= 6/8 = 0.750$ (row R total is 8). F1 $= \frac{2(0.857)(0.750)}{0.857+0.750} = 0.800$.

Needs Practice: Precision $= 4/7 = 0.571$. Recall $= 4/6 = 0.667$. F1 $= \frac{2(0.571)(0.667)}{0.571+0.667} = 0.615$.

Needs Support: Precision $= 2/4 = 0.500$. Recall $= 2/4 = 0.500$. F1 $= 0.500$.

Macro average — every class gets one equal vote

$$\text{Macro}(M) = \frac{M_R + M_P + M_S}{3}$$
$$\text{Macro Precision} = \frac{0.857 + 0.571 + 0.500}{3} = \frac{1.928}{3} = \mathbf{0.643}$$ $$\text{Macro Recall} = \frac{0.750 + 0.667 + 0.500}{3} = \frac{1.917}{3} = \mathbf{0.639}$$ $$\text{Macro F1} = \frac{0.800 + 0.615 + 0.500}{3} = \frac{1.915}{3} = \mathbf{0.638}$$

Macro averaging ignores class size. Use it when a small class should matter as much as a large one.

Weighted average — use actual class count as the weight

$$\text{Weighted}(M) = \frac{8M_R + 6M_P + 4M_S}{18}$$
$$\text{Weighted Precision} = \frac{8(6/7) + 6(4/7) + 4(1/2)}{18} = \frac{43}{63} \approx \mathbf{0.683}$$ $$\text{Weighted Recall} = \frac{8(0.750) + 6(0.667) + 4(0.500)}{18} = \frac{6 + 4 + 2}{18} = \frac{12}{18} \approx \mathbf{0.667}$$ $$\text{Weighted F1} = \frac{8(0.800) + 6(0.615) + 4(0.500)}{18} = \frac{6.40 + 3.69 + 2.00}{18} \approx \mathbf{0.672}$$

Micro average — pool all class decisions first

$TP = 12$, $FP = 6$, $FN = 6$ (pooled across all three classes).

$$\text{Micro Precision} = \frac{12}{12+6} = \frac{12}{18} = \mathbf{0.667}$$ $$\text{Micro Recall} = \frac{12}{12+6} = \frac{12}{18} = \mathbf{0.667}$$ $$\text{Micro F1} = \frac{2(12)}{2(12)+6+6} = \frac{24}{36} = \mathbf{0.667}$$

Every wrong single-label prediction contributes one pooled FP for the predicted class and one pooled FN for the missed actual class. That is why, on this task, micro precision, recall and F1 all equal accuracy.

Why is weighted F1 (0.672) higher than macro F1 (0.638) here?

Because the weakest class is also the smallest class.

Needs Support has the lowest F1 (0.500) and contains only 4 students. Macro gives it a full $1/3$ vote. Weighted gives it only $4/18 = 22\%$ weight, and gives the strongest class (Ready, F1 $=0.800$) $8/18 = 44\%$ weight. Weighting effectively down-weights the model's biggest weakness — so the score rises.

Practical lesson: if the minority class is operationally important (as Needs Support is here), report macro — weighted will paint a rosier picture that hides the real problem.

△ DO NOT LET THIS MISCONCEPTION SURVIVE

Macro F1 is the arithmetic average of the per-class F1 scores. It is generally NOT the harmonic mean of macro precision and macro recall. (Check: harmonic mean of 0.643 and 0.639 = 0.641 ≠ 0.638.)

♦ Takeaway

A model is not good because one of its scores is high. It is good when its errors are acceptable for the decision we have to make, on data that represents the world the model will be used in.

Exit Check

Three questions — with full answers

  1. 1. How can two regression datasets have the same RMSE but different $R^2$ values?

    RMSE depends only on $\text{RSS}/n$. But $R^2 = 1 - \text{RSS}/\text{TSS}$ also depends on TSS — the spread of the target around its own mean. With the same errors, a dataset whose targets are tightly clustered (small TSS) will show a lower $R^2$, because the mean baseline is hard to beat. With spread-out targets (large TSS) those same errors give a high $R^2$.

  2. 2. Why did Model B obtain a higher $R^2$ but a lower Adjusted $R^2$ than Model A?

    Model B cut RSS from 74 to 60, so raw $R^2$ rose $0.9295 \to 0.9429$ (raw $R^2$ can never fall when a predictor is added). But B uses a third predictor, so the penalty factor $\frac{n-1}{n-p-1}$ went from $\frac{7}{5} = 1.4$ to $\frac{7}{4} = 1.75$ — a 25% bigger penalty. The unexplained fraction only moved $0.0705 \to 0.0571$ (a 19% reduction). A 19% gain could not cover a 25% penalty, so Adjusted $R^2$ fell $0.9013 \to 0.9000$.

  3. 3. How can the classifier be 66.7% accurate while recall for Needs Support is only 50%?

    Accuracy is computed over all 18 students and is dominated by the largest class. Of Ready's 8 students, 6 are correct — those alone contribute $6/18 = 33\%$ accuracy. Needs Support has only 4 students; missing 2 of them costs just $2/18 \approx 11\%$ of accuracy, yet halves that class's recall ($2/4 = 0.50$). That is why per-class recall must be reported alongside overall accuracy.

⚠ Common Mistakes

GaltiSahi Baat
"$R^2 = 0.93$ means 93% accuracy"$R^2$ is a relative sum-of-squares comparison against the mean baseline. For error size, use MAE/RMSE.
"MSE $= 9.25$ means a typical miss of 9.25"MSE is in squared units. The typical miss is RMSE $= 3.04$.
Writing $TP+FN$ in precision's denominatorPrecision: $TP+FP$ (predicted positives). Recall: $TP+FN$ (actual positives).
Not stating the orientation of the confusion matrixRows = actual, columns = predicted. Transposing changes the meaning of every off-diagonal cell.
"Predicted-S total of 4 means 4 students were actually Support"The column total also contains FP. Only 2 were actually Support.
Taking macro F1 as the harmonic mean of macro-P and macro-RMacro F1 = the arithmetic average of the per-class F1 scores.
Reporting only accuracy on imbalanced data66.7% accuracy was hiding a minority-class recall of just 50%.
Counting the intercept inside $p$ in Adjusted $R^2$$p$ = predictors excluding the intercept.
Using MAPE on zero or near-zero actualsUndefined at $y_i = 0$; explodes near zero.

⚡ Quick Revision

MAE

$\frac1n\sum|e_i| = 22/8 = 2.75$

MAPE

$\frac{100}{n}\sum\left|\frac{e_i}{y_i}\right| = 5.69\%$ · undefined at $y_i = 0$

MSE / RMSE

$74/8 = 9.25$ · $\sqrt{9.25} = 3.04$

$R^2$

$1 - \frac{\text{RSS}}{\text{TSS}} = 1 - \frac{74}{1050} = 0.9295$

Adjusted $R^2$

$1 - \left(\frac{\text{RSS}}{\text{TSS}}\right)\left(\frac{n-1}{n-p-1}\right)$

Accuracy

$\frac{\text{diagonal}}{\text{total}} = \frac{12}{18} = 0.667$

Precision / Recall

$\frac{TP}{TP+FP}$ / $\frac{TP}{TP+FN}$ · both 0.500 here

F1

$\frac{2TP}{2TP+FP+FN}$ · does not use TN

Macro vs Weighted vs Micro

Equal vote (0.638) · size-weighted (0.672) · pooled = accuracy (0.667)

FP vs FN

FP = Type I (false alert) hurts precision. FN = Type II (miss) hurts recall.
