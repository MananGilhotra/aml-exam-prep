Batch Gradient Descent
for Multiple Linear Regression

Jab closed-form OLS kaam na kare — iterative optimization se optimal parameters tak pahuchna.

⏱ ~32 min📐 Gradient derivation 🧮 Full epoch by hand✓ 10 MCQs
⚡ Ek Line Mein

OLS exact hai par $O(m^3)$ mehnga aur singular $\mathbf X^\top\mathbf X$ par fail ho jaata hai. Gradient Descent ka idea simple hai: loss ka slope nikalo, aur uske ulte direction mein chhota step lo — baar baar. Rule: $\boldsymbol\theta_{\text{new}} = \boldsymbol\theta_{\text{old}} - \alpha\nabla L$. MSE ke liye $\nabla L = \frac{2}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)$. "Batch" isliye kyunki har update mein poora dataset use hota hai.

1Why OLS is not enough

▷ Hook

Lecture 4 mein humne kuch elegant kiya. Loss ka gradient zero set kiya aur seedha $\boldsymbol\theta$ solve kar liya. Result exact tha. To phir ek aur method ki zaroorat kyun?

The closed-form OLS solution$$\boldsymbol\theta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$$

Yahan koi trial and error nahi, koi epoch nahi, koi learning rate nahi. Lekin do major limitations hain:

Limitation 1 · Computational cost

$\mathbf X$ ke paas $m+1$ columns hain (intercept sahit), to $\mathbf X^\top\mathbf X$ ka size $(m+1)\times(m+1)$ hai. Is matrix ko directly invert karne ki cost approximately:

$$O(m^3)$$

Agar model ke paas 5 features hain — inversion trivial hai. Agar millions of features hain — inversion computationally impossible ho jaata hai.

Limitation 2 · Invertibility & numerical stability

Formula sirf tab kaam karta hai jab $\mathbf X^\top\mathbf X$ invertible ho (yaani uska determinant non-zero ho). Iske liye $\mathbf X$ ke columns ko linearly independent hona zaroori hai.

★ Key Insight

Agar do features exact duplicates hain, ya ek feature doosre ka linear combination hai, to $\mathbf X^\top\mathbf X$ singular ban jaata hai — inverse exist hi nahi karta.

Hume ek aisa method chahiye jo $\mathbf X^\top\mathbf X$ ko explicitly invert na kare. Wo method hai Batch Gradient Descent.

Practice P1

Scenario evaluation — OLS or Gradient Descent?

  1. Scenario A: 10,000 rows but only 3 features (Age, Income, Credit Score)
    Use OLS.

    Why: $m = 3$, to $\mathbf X^\top\mathbf X$ sirf $4\times4$ hai. Inversion cost $\approx 4^3 = 64$ operations — nothing. Rows ki sankhya ($n = 10{,}000$) inversion cost ko affect hi nahi karti (wo sirf $m$ par depend karti hai). Closed-form ek hi step mein exact answer de dega, bina learning rate tune kiye.

  2. Scenario B: Computer-vision regression with 50,000 image-derived features
    Use Gradient Descent.

    Why: $m^3 = (5\times10^4)^3 = 1.25\times10^{14}$ operations — days lagenge, aur $50{,}001 \times 50{,}001$ matrix store karne ke liye ~20 GB RAM chahiye. GD har iteration mein sirf $O(nm)$ cost leta hai aur kabhi inverse banata hi nahi.

  3. Scenario C: A junior engineer includes both Price_USD and Price_Cents (where Price_Cents = 100 × Price_USD)

    What specific error will OLS throw?

    A singular matrix error — $\det(\mathbf X^\top\mathbf X) = 0$, so $(\mathbf X^\top\mathbf X)^{-1}$ does not exist (in NumPy: LinAlgError: Singular matrix).

    Can Batch Gradient Descent still run on this data? Yes.
    GD kabhi koi matrix invert nahi karta — wo sirf $\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)$ compute karta hai, jo hamesha defined hai. Wo converge kar jayega, par ek nuance ke saath: kyunki infinitely many $\boldsymbol\theta$ same minimum loss dete hain, GD unme se ek par settle hoga (jo initialization par depend karta hai). Predictions reliable hongi; individual coefficients $\theta_{\text{USD}}$ aur $\theta_{\text{cents}}$ interpret karne layak nahi honge.

2Introduction to Gradient Descent

▷ Hook

Gradient Descent ka objective hai loss function ke minimum tak pahuchna: wo parameter values jahan prediction error sabse chhota hai.

Single-variable case

Ek function $f(x)$ ke liye, derivative $f'(x)$ hume slope batata hai:

  • Agar $f'(x) > 0$, function badhta hai jaise $x$ badhta hai.
  • Agar $f'(x) < 0$, function ghatta hai jaise $x$ badhta hai.

Agar hume function ko decrease karna hai, to hume derivative ki opposite direction mein move karna hoga.

Multivariable case

Ek function $f(\theta_0, \theta_1, \dots, \theta_m)$ ke liye, gradient saare partial derivatives ka vector hai:

$$\nabla f = \begin{bmatrix}\dfrac{\partial f}{\partial\theta_0}\\[4pt] \dfrac{\partial f}{\partial\theta_1}\\[2pt] \vdots\\[2pt] \dfrac{\partial f}{\partial\theta_m}\end{bmatrix}$$
Worked example

Computing a gradient and taking one step

Let $f(x, y) = x^2 + y^2$.

  1. Compute the gradient $$\nabla f = \begin{bmatrix}\partial f/\partial x\\ \partial f/\partial y\end{bmatrix} = \begin{bmatrix}2x\\ 2y\end{bmatrix}$$
  2. Evaluate at the point $(3, 4)$ $$\nabla f\big|_{(3,4)} = \begin{bmatrix}2(3)\\ 2(4)\end{bmatrix} = \begin{bmatrix}6\\ 8\end{bmatrix}$$
  3. Take one step with $\alpha = 0.1$ $$\boldsymbol\theta_{\text{new}} = \begin{bmatrix}3\\4\end{bmatrix} - 0.1\begin{bmatrix}6\\8\end{bmatrix} = \begin{bmatrix}3 - 0.6\\ 4 - 0.8\end{bmatrix} = \begin{bmatrix}\mathbf{2.4}\\ \mathbf{3.2}\end{bmatrix}$$
    Moved closer to the minimum at $(0,0)$ ✓
  4. Now try $\alpha = 1$ — watch what breaks $$\boldsymbol\theta_{\text{new}} = \begin{bmatrix}3\\4\end{bmatrix} - 1\begin{bmatrix}6\\8\end{bmatrix} = \begin{bmatrix}\mathbf{-3}\\ \mathbf{-4}\end{bmatrix}$$
    Overshoot! Hum minimum ko cross karke doosri taraf pahuch gaye, exactly same distance par. $f$ ki value badli hi nahi ($9+16 = 25$ dono jagah). Agla step hume wapas $(3,4)$ le jayega — infinite oscillation.

    Yeh "$\alpha$ too large" failure mode ka exact mathematical demonstration hai.

♦ Takeaway — the key geometric fact

Gradient function ke steepest increase ki direction mein point karta hai. Isliye negative gradient steepest decrease ki direction mein point karta hai.

Ek convex bowl-shaped loss ke liye, repeatedly negative gradient follow karne se hum kisi bhi starting point se same global minimum par pahuchte hain — bashart ki learning rate appropriate ho.

The update rule

Single parameter$$\theta_{\text{new}} = \theta_{\text{old}} - \alpha\left.\frac{dL}{d\theta}\right|_{\theta_{\text{old}}}$$

Yahan $\alpha > 0$ learning rate hai: ek user-chosen hyperparameter jo har step ka size control karta hai. Gradient Descent is rule ko iteratively apply karta hai — old becomes new, gradient recompute hota hai, aur process convergence tak chalta rehta hai (jab loss ya parameters negligibly badalte hain).

Coordinate-wise, for MLR with $m$ features ($m+1$ parameters)$$\theta_{j,\text{new}} = \theta_{j,\text{old}} - \alpha\left.\frac{\partial L}{\partial\theta_j}\right|_{\boldsymbol\theta_{\text{old}}} \qquad\text{for } j = 0, 1, \dots, m$$
△ Warning — SIMULTANEOUS UPDATE

Saare partial derivatives $\boldsymbol\theta$ ki OLD value se compute hone chahiye, aur saare parameters simultaneously update hone chahiye. $\theta_0$ ko update karke phir naye $\theta_0$ se $\theta_1$ ka derivative mat nikalna.

Vector form$$\boxed{\;\boldsymbol\theta_{\text{new}} = \boldsymbol\theta_{\text{old}} - \alpha\,\nabla L(\boldsymbol\theta_{\text{old}})\;}$$
  • $\boldsymbol\theta$ — the full parameter vector
  • $\nabla L$ — the vector of all partial derivatives
  • $\alpha$ — the learning rate
  • Minus sign isliye aata hai kyunki gradient uphill point karta hai, par hume downhill jaana hai

Parameter initialization

  • Linear Regression aur Logistic Regression mein use hone wali convex loss functions ke liye, $\boldsymbol\theta_{\text{old}}$ ko zero vector se initialize karo.
  • Non-convex Neural Network losses ke liye parameters randomly initialize kiye jaate hain (parallel Deep Learning course mein cover hoga).

Effect of the learning rate on convergence

Derive the vectorized update rule

  1. 1. Stack the old parameters into a vector $\boldsymbol\theta$ $$\boldsymbol\theta_{\text{old}} = \begin{bmatrix}\theta_0\\ \theta_1\\ \vdots\\ \theta_m\end{bmatrix}$$
  2. 2. Stack all the partial derivatives into the gradient vector $\nabla L$ $$\nabla L = \begin{bmatrix}\partial L/\partial\theta_0\\ \partial L/\partial\theta_1\\ \vdots\\ \partial L/\partial\theta_m\end{bmatrix}$$
  3. 3. Write the final simultaneous vector update equation
    $\boldsymbol\theta_{\text{new}} = \boldsymbol\theta_{\text{old}} - \alpha\,\nabla L(\boldsymbol\theta_{\text{old}})$

3Deriving the Batch GD update for MSE ⭐

▷ Hook

Ab loss definition, gradient, aur update rule ko Mean Squared Error ke liye mathematically consistent banate hain.

MSE loss (matrix form)$$L(\boldsymbol\theta) = \frac{1}{m}(\mathbf X\boldsymbol\theta - \mathbf y)^\top(\mathbf X\boldsymbol\theta - \mathbf y) \qquad\text{equivalently}\qquad L(\boldsymbol\theta) = \frac{1}{m}\|\mathbf X\boldsymbol\theta - \mathbf y\|_2^2$$

Note: yahan $m$ = number of training examples (is worksheet ki notation). Feature count ko $d$ se denote kiya gaya hai jahan zaroori hai.

Practice P4 · Derivation

Compute the gradient step by step

  1. Step 1 — Expand the loss function $$L(\boldsymbol\theta) = \frac{1}{m}\left[(\boldsymbol\theta^\top\mathbf X^\top - \mathbf y^\top)(\mathbf X\boldsymbol\theta - \mathbf y)\right]$$ $$L(\boldsymbol\theta) = \frac{1}{m}\left[\,\mathbf y^\top\mathbf y \;-\; 2\,\mathbf y^\top\mathbf X\boldsymbol\theta \;+\; \boldsymbol\theta^\top\mathbf X^\top\mathbf X\boldsymbol\theta\,\right]$$

    (Same three-term expansion as Lecture 4, with the two middle scalars combined.)

  2. Step 2 — Differentiate with respect to $\boldsymbol\theta$

    Recall the three identities:

    $$\frac{\partial}{\partial\boldsymbol\theta}(\mathbf y^\top\mathbf y) = \mathbf 0, \qquad \frac{\partial}{\partial\boldsymbol\theta}(-2\,\mathbf y^\top\mathbf X\boldsymbol\theta) = -2\,\mathbf X^\top\mathbf y, \qquad \frac{\partial}{\partial\boldsymbol\theta}(\boldsymbol\theta^\top\mathbf X^\top\mathbf X\boldsymbol\theta) = 2\,\mathbf X^\top\mathbf X\boldsymbol\theta$$ $$\nabla L = \frac{1}{m}\left[\mathbf 0 \;-\; 2\,\mathbf X^\top\mathbf y \;+\; 2\,\mathbf X^\top\mathbf X\boldsymbol\theta\right]$$
  3. Step 3 — Factor out the 2 and $\mathbf X^\top$
    The MSE gradient$$\boxed{\;\nabla L = \frac{2}{m}\,\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)\;}$$
  4. Step 4 — Plug into the update rule
    Batch Gradient Descent update rule$$\boxed{\;\boldsymbol\theta := \boldsymbol\theta - \alpha\,\frac{2}{m}\,\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)\;}$$
★ Key Insight — why is it called "Batch"?

Kyunki gradient poori matrix $\mathbf X$ aur poore target vector $\mathbf y$ ka use karta hai. Har single training example har single update step mein contribute karta hai.

Instructor note — the missing factor of 2

Kuch books loss ko aise define karte hain:

$$L(\boldsymbol\theta) = \frac{1}{2m}\|\mathbf X\boldsymbol\theta - \mathbf y\|_2^2$$

Us convention ke saath gradient se factor 2 gayab ho jaata hai (kyunki $\frac{1}{2}\cdot 2 = 1$), aur update $\boldsymbol\theta := \boldsymbol\theta - \alpha\frac{1}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)$ ban jaata hai. Is lecture mein hum actual MSE definition use kar rahe hain, isliye factor 2 rehta hai. Exam mein question ki convention dekh lena.

★ Key Insight

Feature scaling Gradient Descent apply karne se pehle essential hai. Features ko comparable scales par laane se ek large-magnitude feature gradient ko dominate nahi kar paata, aur convergence usually faster aur zyada stable hoti hai.

5Epochs and the full training loop

▷ Hook

Upar humne jo kiya wo ek update tha. Par model train karne ka matlab hai us update ko bohot baar repeat karna. Process ko carefully naam dete hain.

Epoch

Batch Gradient Descent mein, ek epoch ka matlab hai full training dataset ka ek complete pass aur ek full-dataset gradient update.

Training loop — 7 steps

  1. Initialize parameters. Is convex Linear Regression loss ke liye, $\boldsymbol\theta = \mathbf 0$ set karo. Neural Networks random initialization use karte hain.
  2. Choose the number of epochs.
  3. Compute predictions. $\hat{\mathbf y} = \mathbf X\boldsymbol\theta$
  4. Compute residuals. $\mathbf X\boldsymbol\theta - \mathbf y$
  5. Compute the gradient. $\nabla L = \frac{2}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)$
  6. Update parameters. $\boldsymbol\theta := \boldsymbol\theta - \alpha\nabla L$
  7. Repeat for the chosen number of epochs.
Practice P5

Epoch trivia

Agar NST dataset mein 3 students hain aur hum Batch Gradient Descent se 100 epochs train karte hain, to model kitni baar full dataset use karke gradient compute karta hai?

100 times.

Reasoning: BGD mein, ek epoch = ek complete pass = exactly ek full-dataset gradient computation aur exactly ek parameter update. 100 epochs ⟹ 100 gradient computations ⟹ 100 parameter updates. (Contrast karo SGD se, jahan 100 epochs $\times$ 3 samples = 300 updates hote. 👉 Lecture 6)

♦ Takeaway

Gradient Descent ek general optimization algorithm hai, sirf Linear Regression tak limited nahi. Wo kisi bhi differentiable loss function ko optimize kar sakta hai, bas parameters ko negative-gradient direction mein repeatedly move karke.

6Learning rate, hyperparameter tuning, and trade-offs

Learning rate $\alpha$ ek hyperparameter hai. Ise hum training se pehle choose karte hain — gradient descent isse seekhta nahi. Yeh control karta hai ki har step kitna bada hai.

Case 1 · $\alpha$ too small

Loss ghatti hai, par bohot dheere. Model sahi direction mein ja raha hai, par har step tiny hai.

Case 2 · $\alpha$ too large

Loss oscillate ya diverge kar sakti hai. Direction locally downhill ho sakti hai, par step itna bada hai ki algorithm minimum ko overshoot kar deta hai.

Case 3 · $\alpha$ well chosen

Loss pehle tezi se girti hai aur phir minimum ke paas gradually flatten ho jaati hai.

Hyperparameter tuning — how to actually pick $\alpha$

Best $\alpha$ dhoondhne ke liye hum candidate values pick karte hain (e.g. $0.1, 0.01, 0.001$), model ko har value ke saath separately train karte hain, aur ek held-out validation set par loss track karte hain. (Test set final evaluation ke liye rakha jaata hai, repeatedly settings select karne ke liye nahi.)

What is validation loss?

Validation loss un examples par average prediction error hai jo $\boldsymbol\theta$ ko update karne ke liye use nahi hue. $m_{\text{val}}$ examples wale validation set ke liye:

$$L_{\text{val}} = \frac{1}{m_{\text{val}}}\sum_{i=1}^{m_{\text{val}}}(y_i - \hat y_i)^2$$

Step-by-step tuning process

  1. Available development data ko training aur validation sets mein split karo; test set untouched rakho.
  2. Candidate learning rates ko logarithmic scale par choose karo, jaise $0.1, 0.01, 0.001$.
  3. Har candidate run ko same zero vector se start karo aur same epoch budget ke liye train karo.
  4. Har epoch ke baad training loss aur validation loss dono record karo.
  5. Un candidates ko reject karo jo diverge ya severely oscillate karte hain.
  6. Har remaining candidate ka best validation loss compare karo.
  7. Sabse kam validation loss wala learning rate select karo — kyunki usne unseen validation data par sabse chhoti error produce ki — phir final chosen setup ko ek baar test set par evaluate karo.

Advantages of Batch Gradient Descent

  • Har gradient computation ke liye full dataset use karta hai, to update direction stable hoti hai.
  • Linear regression ke MSE jaise convex loss ke liye, appropriate learning rate par global minimum tak converge kar sakta hai.
  • $(\mathbf X^\top\mathbf X)^{-1}$ explicitly compute karne se bachta hai.
  • Tab bhi chal sakta hai jab inverse-based closed-form formula fail ho jaaye kyunki $\mathbf X^\top\mathbf X$ singular hai.

Disadvantages of Batch Gradient Descent

  • Har epoch mein poore dataset par ek full pass chahiye. (100,000 rows? Har ek update ke liye saari 100,000 rows.)
  • Jab dataset bohot bada hai to slow ho sakta hai.
  • Full batch gradient efficiently compute karne ke liye poora dataset usually available hona chahiye.
  • Poor learning-rate choices training ko extremely slow ya unstable bana sakte hain.
