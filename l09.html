⚡ Ek Line Mein

Har training sample thoda alag model deta hai. Bias = average prediction truth se kitni door hai. Variance = samples badalne par predictions kitni hilti hain. Simple model → high bias, low variance (underfit). Bohot flexible model → low bias, high variance (overfit). Aur:
$\text{MSE} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}$

Learning outcomes

  1. Explain the model $Y = f(X) + \varepsilon$.
  2. Explain why different training samples produce different fitted models.
  3. Identify high bias, high variance, underfitting and overfitting.
  4. Use $\text{MSE} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}$ in a controlled simulation.
  5. Keep training, validation and test data separate.
  6. Use cross-validation and learning curves to diagnose a regression model.

PART A · Controlled experiment — the true function is known

1Start with $Y = f(X) + \varepsilon$

The data-generating model$$Y = f(X) + \varepsilon$$
  • $f(X)$ — the true pattern we are trying to learn.
  • $Y$ — the observed output (what we actually see in the dataset).
  • $\varepsilon$ — random noise that the model can never predict.
The lab's controlled setting

Lab mein $f(x) = x^2$ use kiya gaya. Population mein $-15$ se $10$ ke beech 100 evenly spaced input values hain. Har point par normally distributed noise add kiya gaya: mean $0$, standard deviation $20$.

Yeh deliberately artificial hai. Hum true function jaante hain kyunki humne khud data banaya hai. Real data mein $f(x)$ hume kabhi pata nahi hota — isliye Part B mein hume alag diagnostic tools chahiye.

2One estimator, different training samples

Ek estimator ek learning rule hai (jaise "degree-2 polynomial fit karo"). Fitted result, $\hat f(x)$, badal jaata hai jab training sample badalta hai. Lab mein isko same population se teen independent samples draw karke demonstrate kiya gaya.

Degree 1 — interpretation

Teeno lines ek dusre se kaafi similar hain, par koi bhi curved true function reproduce nahi kar sakti. Yeh expected high-bias, low-variance pattern hai. Model underfits.

Degree 5 — interpretation

Flexible curves quadratic shape follow kar sakti hain, to unki bias kam ho sakti hai. Lekin unke shapes samples ke across sharply badalte hain kyunki wo noise par bhi react karti hain. Yeh expected low-bias, high-variance pattern hai. Model overfits.

Model behaviourBiasVarianceUsual result
Too simpleHighLowUnderfitting
Suitable complexityModerate/lowModerate/lowBetter generalisation
Too flexibleLowHighOverfitting

3Bias and variance at one input value ⭐

At a fixed input $x$:

Bias$$\text{Bias}(x) = E\!\left[\hat f(x)\right] - f(x)$$

Bias measure karta hai ki average prediction truth se kitni door hai.

Variance$$\text{Variance}(x) = E\!\left[\left(\hat f(x) - E[\hat f(x)]\right)^2\right]$$

Variance measure karta hai ki alag training samples par predictions kitni badalti hain.

★ How the lab estimates these

Lab har degree ke liye 100 models train karta hai (100 alag simulated training datasets se) aur $x = 5$ par unki predictions compare karta hai. Kyunki $f(5) = 5^2 = 25$, true value known hai — to hum literally $E[\hat f(5)]$ aur $\operatorname{Var}(\hat f(5))$ approximate kar sakte hain.

Real problems mein yeh possible nahi hai (na hum population se repeatedly sample kar sakte hain, na hume $f$ pata hai). Isliye Part B mein proxies use hote hain.

4MSE decomposition ⭐

Squared-error regression ke liye, expected prediction error ko aise likha ja sakta hai:

The bias–variance decomposition$$\boxed{\;\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon)\;}$$

Last term irreducible error hai. Zyada flexible modelling us randomness ko hata nahi sakti jo data mein already maujood hai.

Worked check

Two-line computation straight from the lecture

  1. If the average prediction is 12 and the true value is 10, what is the bias? $$\text{Bias} = E[\hat f(x)] - f(x) = 12 - 10 = \mathbf{2}$$
  2. If bias is 2, variance is 3, and noise variance is 1, what is the expected MSE? $$\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon) = 2^2 + 3 + 1 = 4 + 3 + 1 = \mathbf{8}$$
    Note: bias squared hoti hai. $2 + 3 + 1 = 6$ likhna sabse common error hai.
  3. If irreducible error increases while bias and variance stay fixed, what happens to MSE?
    It increases by exactly the same amount.

    Teeno terms additive hain. Agar $\operatorname{Var}(\varepsilon)$ $1 \to 4$ ho jaye, to MSE $8 \to 11$ ho jaayegi. Aur yeh wo hissa hai jise koi bhi model kam nahi kar sakta — ise kam karne ke liye tumhe better data chahiye (kam measurement noise, better features), better algorithm nahi.

5Observing the tradeoff

Lab ki simulation poore input range par results average karti hai aur har degree ke liye bias², variance, irreducible noise aur total error plot karti hai.

★ Interpretation (from the lab)

Degree 1 quadratic pattern represent nahi kar sakta, to uski bias high hai. Degree 2 true family se match karta hai aur normally yahan best balance deta hai. Bohot high degrees training sample par strongly react karti hain, to variance badh jaati hai.

Lab mein y-axis logarithmic hai kyunki sabse flexible models baaki sab se kahin bade errors produce kar sakte hain.

PART B · Real data — the true function is unknown

6From theory to diagnosis

△ The core practical problem

Ek real problem mein humare paas ek dataset hota hai, population se har possible sample nahi. Aur hume true $f(x)$ pata nahi hota. Isliye hum normally exact mathematical bias aur variance calculate nahi kar sakte.

Instead, hum model behaviour ko in tools se diagnose karte hain:

  • Training aur validation error
  • Ek train / validation / test split
  • Cross-validation
  • Learning curves

Lab ke applied section mein Study_Hours se Exam_Score predict kiya jaata hai — ek one-input regression example taaki model complexity plot karna easy rahe.

8Compare model complexity — reading the error pattern ⭐

Training MSE complexity badhne par almost hamesha girta hai (ya same rehta hai). Validation MSE batata hai ki extra flexibility unseen data par help kar rahi hai ya nahi.

PatternTraining errorValidation errorDiagnosis

△ Instructor note

"High" aur "low" jaise exact words task ke relative hain. Models ko same dataset aur same metric par compare karo — koi universal MSE cutoff invent mat karo.

9Cross-validation checks stability

Ek validation result ek split par depend karta hai. Five-fold cross-validation train/validation process ko paanch folds ke across repeat karta hai.

  • Mean CV MSE — average error measure karta hai.
  • Standard deviation of CV MSE — dikhata hai ki wo error folds ke across kitna badalta hai (stability).

10Learning curves ⭐

Ek learning curve dikhata hai ki jaise-jaise training data ki quantity badhti hai, training aur validation error kaise badalte hain.

High-bias pattern

Dono errors high rehte hain aur ek dusre ke paas hote hain. Zyada data add karne se help nahi milegi — model apni structural limitation se bandha hua hai. Fix: model complexity badhao (features add karo, higher degree, kam regularization).

High-variance pattern

Training error validation error se bohot kam hai. Zyada representative data gap kam kar sakta hai. Fix: zyada data lao, complexity kam karo, regularization add karo, ya features kam karo.

★ Instructor discussion

Problem ka naam lene se pehle dono curves ke beech ka gap describe karo. Ek bada persistent gap high-variance diagnosis support karta hai. Do relatively high curves jo milti hain, wo high-bias diagnosis support karti hain. Data add karna tab sabse zyada help karta hai jab variance main problem ho.

11Final test evaluation

Degree ab test set use kiye bina select ho chuki hai. Hum us degree ko training + validation rows combined par refit karte hain, aur phir test set ek baar use karte hain. Degree 1 ko ek simple reference model ki tarah bhi report kiya jaata hai.

⚠ Common Mistakes

GaltiSahi Baat
$\text{MSE} = \text{Bias} + \text{Variance} + \text{Noise}$Bias squared hoti hai: $\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon)$.
"Better model se irreducible error bhi kam ho jaayega"Irreducible error data ki property hai, model ki nahi. Koi algorithm use nahi hata sakta.
"Overfitting par zyada data hamesha help karega"Overfitting (high variance) par haan. Underfitting (high bias) par nahi — model structurally limited hai.
"Low training error = good model"Training error complexity ke saath hamesha girta hai. Validation error aur train–val gap dekho.
High bias aur high variance ko mutually exclusive samajhnaEk model dono mein high ho sakta hai (worst case) — misspecified aur unstable.
Degree select karne ke liye test error dekhnaTest set ek baar, sab choices ke baad. Selection validation par.
"Ek validation split enough hai"Ek split noisy ho sakta hai. Cross-validation mean aur stability (std) deta hai.
Bias ko "model galat hai" aur variance ko "data galat hai" samajhnaDono estimator ki properties hain. Bias = systematic offset. Variance = sample-to-sample instability.

♦ Lab 9 summary
  • Different samples produce different fitted models.
  • Simple models tend toward higher bias and lower variance.
  • Very flexible models tend toward lower bias and higher variance.
  • Expected MSE contains bias squared, variance, and irreducible error.
  • In real data, diagnose behaviour with train/validation results, cross-validation, and learning curves.
  • Keep the test set untouched until the model choice is finished.
