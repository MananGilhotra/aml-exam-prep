⚡ Ek Line Mein

Each training sample gives a slightly different model. Bias = how far the average prediction sits from the truth. Variance = how much the predictions move when the sample changes. A simple model → high bias, low variance (underfit). A very flexible model → low bias, high variance (overfit). And:
$\text{MSE} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}$

Learning outcomes

  1. Explain the model $Y = f(X) + \varepsilon$.
  2. Explain why different training samples produce different fitted models.
  3. Identify high bias, high variance, underfitting and overfitting.
  4. Use $\text{MSE} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}$ in a controlled simulation.
  5. Keep training, validation and test data separate.
  6. Use cross-validation and learning curves to diagnose a regression model.

PART A · Controlled experiment — the true function is known

1Start with $Y = f(X) + \varepsilon$

The data-generating model$$Y = f(X) + \varepsilon$$
  • $f(X)$ — the true pattern we are trying to learn.
  • $Y$ — the observed output (what we actually see in the dataset).
  • $\varepsilon$ — random noise that the model can never predict.
The lab's controlled setting

The lab uses $f(x) = x^2$. The population has 100 evenly spaced input values between $-15$ and $10$. At each point, normally distributed noise is added: mean $0$, standard deviation $20$.

This is deliberately artificial. We know the true function because we generated the data ourselves. With real data we never know $f(x)$ — which is exactly why Part B needs a different set of diagnostic tools.

2One estimator, different training samples

An estimator is a learning rule (such as "fit a degree-2 polynomial"). The fitted result, $\hat f(x)$, changes when the training sample changes. The lab demonstrates this by drawing three independent samples from the same population.

Degree 1 — interpretation

All three lines are quite similar to each other, yet none of them can reproduce the curved true function. This is the expected high-bias, low-variance pattern. The model underfits.

Degree 5 — interpretation

Flexible curves can follow the quadratic shape, so their bias can be low. But their shapes change sharply across samples because they also react to the noise. This is the expected low-bias, high-variance pattern. The model overfits.

Model behaviourBiasVarianceUsual result
Too simpleHighLowUnderfitting
Suitable complexityModerate/lowModerate/lowBetter generalisation
Too flexibleLowHighOverfitting

3Bias and variance at one input value ⭐

At a fixed input $x$:

Bias$$\text{Bias}(x) = E\!\left[\hat f(x)\right] - f(x)$$

Bias measures how far the average prediction is from the truth.

Variance$$\text{Variance}(x) = E\!\left[\left(\hat f(x) - E[\hat f(x)]\right)^2\right]$$

Variance measures how much the predictions change across different training samples.

★ How the lab estimates these

For each degree, the lab trains 100 models (from 100 different simulated training datasets) and compares their predictions at $x = 5$. Because $f(5) = 5^2 = 25$, the true value is known — so we can literally approximate $E[\hat f(5)]$ and $\operatorname{Var}(\hat f(5))$.

In real problems this is not possible (we can neither sample repeatedly from the population, nor do we know $f$). So Part B uses proxies instead.

4MSE decomposition ⭐

For squared-error regression, the expected prediction error can be written as:

The bias–variance decomposition$$\boxed{\;\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon)\;}$$

The last term is the irreducible error. More flexible modelling cannot remove the randomness that is already present in the data.

Worked check

Two-line computation straight from the lecture

  1. If the average prediction is 12 and the true value is 10, what is the bias? $$\text{Bias} = E[\hat f(x)] - f(x) = 12 - 10 = \mathbf{2}$$
  2. If bias is 2, variance is 3, and noise variance is 1, what is the expected MSE? $$\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon) = 2^2 + 3 + 1 = 4 + 3 + 1 = \mathbf{8}$$
    Note: the bias is squared. Writing $2 + 3 + 1 = 6$ is the most common error here.
  3. If irreducible error increases while bias and variance stay fixed, what happens to MSE?
    It increases by exactly the same amount.

    All three terms are additive. If $\operatorname{Var}(\varepsilon)$ goes $1 \to 4$, then MSE goes $8 \to 11$. And this is the part no model can reduce — lowering it needs better data (less measurement noise, better features), not a better algorithm.

5Observing the tradeoff

The lab's simulation averages results over the whole input range and plots bias², variance, irreducible noise and total error for each degree.

★ Interpretation (from the lab)

Degree 1 cannot represent a quadratic pattern, so its bias is high. Degree 2 matches the true family and normally gives the best balance here. Very high degrees react strongly to the training sample, so variance rises.

The lab uses a logarithmic y-axis because the most flexible models can produce errors far larger than everything else.

PART B · Real data — the true function is unknown

6From theory to diagnosis

△ The core practical problem

In a real problem we have one dataset, not every possible sample from the population. And we do not know the true $f(x)$. So we normally cannot compute exact mathematical bias and variance.

Instead, we diagnose model behaviour using these tools:

  • Training aur validation error
  • Ek train / validation / test split
  • Cross-validation
  • Learning curves

The lab's applied section predicts Exam_Score from Study_Hours — a one-input regression example, so that model complexity is easy to plot.

8Compare model complexity — reading the error pattern ⭐

Training MSE almost always falls (or stays the same) as complexity rises. Validation MSE tells us whether the extra flexibility actually helps on unseen data.

PatternTraining errorValidation errorDiagnosis
High biasHighHighBoth high and close to each other → underfitting
High varianceLowMuch higherA large gap → overfitting
Better balanceModerateLowValidation error is low and the train–validation gap is not excessive → good
△ Instructor note

Words like "high" and "low" are relative to the task. Compare models on the same dataset and the same metric — never invent a universal MSE cutoff.

9Cross-validation checks stability

A single validation result depends on one split. Five-fold cross-validation repeats the train/validation process across five folds.

  • Mean CV MSE — measures the average error.
  • Standard deviation of CV MSE — shows how much that error varies across folds (stability).

10Learning curves ⭐

A learning curve shows how training and validation error change as the quantity of training data grows.

High-bias pattern

Both errors stay high and close to each other. Adding more data will not help — the model is bound by its own structural limitation. Fix: increase model complexity (add features, raise the degree, reduce regularization).

High-variance pattern

Training error is much lower than validation error. More representative data can close the gap. Fix: get more data, reduce complexity, add regularization, or use fewer features.

★ Instructor discussion

Describe the gap between the two curves before naming the problem. A large persistent gap supports a high-variance diagnosis. Two relatively high curves that meet support a high-bias diagnosis. Adding data helps most when variance is the main problem.

11Final test evaluation

The degree has now been selected without using the test set. We refit that degree on the training + validation rows combined, and then use the test set once. Degree 1 is also reported as a simple reference model.

⚠ Common Mistakes

GaltiSahi Baat
$\text{MSE} = \text{Bias} + \text{Variance} + \text{Noise}$The bias is squared: $\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon)$.
"A better model will also reduce the irreducible error"Irreducible error is a property of the data, not of the model. No algorithm can remove it.
"More data always helps with overfitting"For overfitting (high variance), yes. For underfitting (high bias), no — the model is structurally limited.
"Low training error = good model"Training error always falls with complexity. Look at validation error and the train–val gap.
Treating high bias and high variance as mutually exclusiveA model can be high in both (the worst case) — misspecified and unstable.
Looking at test error in order to select the degreeUse the test set once, after all the choices. Selection happens on validation.
"One validation split is enough"A single split can be noisy. Cross-validation gives both a mean and a measure of stability (std).
Reading bias as "the model is wrong" and variance as "the data is wrong"Both are properties of the estimator. Bias = systematic offset. Variance = sample-to-sample instability.

♦ Lab 9 summary
  • Different samples produce different fitted models.
  • Simple models tend toward higher bias and lower variance.
  • Very flexible models tend toward lower bias and higher variance.
  • Expected MSE contains bias squared, variance, and irreducible error.
  • In real data, diagnose behaviour with train/validation results, cross-validation, and learning curves.
  • Keep the test set untouched until the model choice is finished.
