L0From Code to AI, ML & DL

What is the paradigm flip between Traditional Programming and Machine Learning?
Traditional: Data + Rules → Answers.  ML: Data + Answers → Rules.
In traditional programming the human writes the rules; in ML the algorithm discovers them.
How do AI, ML and DL relate — and what is in AI that is not in ML?
$\text{DL} \subset \text{ML} \subset \text{AI}$.
AI also includes non-learning systems — such as search algorithms (Google Maps routing). Those are AI but not ML.
What does "deep" technically mean in Deep Learning?
The structural architecture — dozens or hundreds of hidden layers stacked sequentially. It is not about the size of the training data, the depth of tuning, or the feature count.
What fundamentally separates Reinforcement Learning from the other three paradigms?
It uses no static dataset at all. The agent explores an unknown environment and generates its own training signal.
Trap: "it uses unlabelled data" is wrong — unsupervised learning does that too.
3 core tasks aur unke output types?
Regression → continuous scalar (supervised) · Classification → discrete label (supervised) · Clustering → natural groups (unsupervised)
Image classification vs image segmentation?
Classification gives the whole image one label. Segmentation labels every pixel, producing a map of what each region of the image contains.

L1Lifecycle Part 1

Chaar scaling formulas aur unke use cases?
Min-Max $\frac{X-X_{\min}}{X_{\max}-X_{\min}}$ → bounded/clean · Z-Score $\frac{X-\mu}{\sigma}$ → Gaussian · Max Abs $\frac{X}{\max|X|}$ → sparse (preserves zeros) · Robust $\frac{X-\text{Med}}{Q_3-Q_1}$ → heavy outliers
Why does Min-Max scaling fail with outliers?
A single outlier blows up the denominator $(X_{\max}-X_{\min})$, which squashes all the other normal values near 0 and makes them indistinguishable.
Example: $[100,150,200,250,50000]$ → $0, 0.001, 0.002, 0.003, 1$
The 4 steps of robust scaling, and the answer for $[100,150,200,250,50000]$?
Median $=200$ · $Q_1 = \frac{100+150}{2} = 125$ · $Q_3 = \frac{250+50000}{2} = 25125$ · IQR $=25000$
$X=100 \to \frac{-100}{25000} = \mathbf{-0.004}$  ·  $X=50000 \to \frac{49800}{25000} = \mathbf{1.992}$
Which feature type would you classify a PIN code as, and why?
Categorical (Nominal). It looks like a number but arithmetic on it is meaningless — 110001 + 110002 means nothing. Star ratings (1–5) are similarly Ordinal, not continuous numerical.
Label Encoding misleads KNN but not a Decision Tree. Why?
KNN computes distances — $|Red-Green|=2$ vs $|Red-Blue|=1$ becomes a fabricated similarity.
A tree splits on thresholds — "is value $\le 0.5$?" — so magnitude plays no role.
One-Hot vs Binary for 1000 categories — how many columns?
One-Hot: 1000 columns (curse of dimensionality). Binary: $\lceil\log_2 1000\rceil = $ ~10 columns.
The 7 goals of the EDA checklist?
1. Dataset Structure · 2. Missing Values · 3. Outliers · 4. Duplicates · 5. Distributions · 6. Relationships · 7. Class Imbalance
95% Class A / 5% Class B. The model always predicts A → 95% accuracy. Useful?
No. Class B's recall is $0$. The model has learnt nothing — it is just guessing the majority class. This is class imbalance; accuracy is lying.

L2Lifecycle Part 2

Parameter vs Hyperparameter — the difference in one line?
Parameter: the model learns it itself, during training (weights $w_1$, intercept $w_0$, bias).
Hyperparameter: the engineer sets it manually, before training (max_depth, n_estimators, learning_rate).
Keyword: "learned during" = parameter.
Split ratio aur golden rule?
70% Train · 15% Validation · 15% Test.
Golden rule: Split FIRST, engineer SECOND. The test set is used once, at the very end.
Computing the mean over the whole dataset, then splitting, then imputing the training set — is that leakage?
Yes, definitely. That mean carries information from the test-set rows — meaning the test set influenced training. The test score is now artificially optimistic.
Right way: split first, compute the mean from the training rows only, and apply that same mean to all three sets.
The 5 steps of the training loop (in the correct order)?
1. Initialize (random weights) → 2. Forward Pass (predictions) → 3. Compute Loss (MSE) → 4. Backward Pass (gradient descent) → 5. Convergence Check
MAE, RMSE, $R^2$ — kab kaunsa?
MAE — "on average how many units off?" (interpretable, equal weight).
RMSE — when one large error is catastrophic (the squaring punishes it).
$R^2$ — "how much better than random guessing / the baseline?" (relative).
Periodic vs Triggered retraining?
Periodic: a fixed schedule (monthly), regardless of performance.
Triggered: fires when monitoring detects accuracy below a threshold.
For unpredictable events (drought, pandemic) you need Triggered.

L3Simple Linear Regression

The three loss attempts, and the problem with each?
1. Signed $\sum e_i$ → positives and negatives cancel out (a total of 0 ≠ a perfect model).
2. Absolute $\sum|e_i|$ → not differentiable at $e=0$ (a sharp V corner).
3. Squared ✓ $\sum e_i^2$ → non-negative, smooth, but sensitive to outliers.
The three properties of squared error?
1. Always non-negative (no cancellation) · 2. Differentiable everywhere (derivative of $x^2$ is $2x$, defined at 0) · 3. Penalizes large errors quadratically
If the error is 10× larger, how much larger is the squared penalty?
100×, not 10×. $10^2 = 100$ vs $1^2 = 1$. The penalty grows quadratically.
The two OLS formulas — and which one do you compute first?
$$m = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}, \qquad c = \bar y - m\bar x$$ $m$ first (because the formula for $c$ needs $m$).
What is the #1 mistake in the OLS derivation?
Writing $\sum_{i=1}^{n} c = c$. Correct: $\sum_{i=1}^{n} c = \mathbf{nc}$ — $c$ is a constant, and you are adding it $n$ times.
Which point does the OLS line always pass through — and why?
$(\bar x, \bar y)$ — the centroid of the data.
Proof: $\hat y(\bar x) = m\bar x + c = m\bar x + (\bar y - m\bar x) = \bar y$ ✓
What happens if all the $x_i$ are identical?
$x_i - \bar x = 0$ for every $i$ ⟹ $\sum(x_i-\bar x)^2 = 0$ ⟹ division by zero ⟹ $m$ is undefined.
Geometrically: all the points lie on a vertical line — whose slope simply does not exist.
When an outlier is added, does the OLS line move toward it or away from it?
Toward the outlier. The optimizer is minimizing $\sum e^2$; the way to shrink that huge squared term is to pull the line toward the outlier — even if the fit for every other point gets worse.

L4Multiple Linear Regression

The dimensions of $\mathbf X$, $\boldsymbol\beta$, $\hat{\mathbf y}$ and $\mathbf X^\top\mathbf X$?
$\mathbf X$: $n\times(m{+}1)$ · $\boldsymbol\beta$: $(m{+}1)\times1$ · $\hat{\mathbf y}$: $n\times1$ · $\mathbf X^\top\mathbf X$: $(m{+}1)\times(m{+}1)$
Trap: 200 rows, 5 features → $\mathbf X^\top\mathbf X$ is $\mathbf{6\times6}$ (count the intercept column!), not $5\times5$.
The expanded form of the loss, and the three term types?
$$L(\boldsymbol\beta) = \underbrace{\mathbf y^\top\mathbf y}_{\text{constant}} \underbrace{-\,2\mathbf y^\top\mathbf X\boldsymbol\beta}_{\text{linear}} + \underbrace{\boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta}_{\text{quadratic}}$$ Three types ⟹ three identities are needed.
Teen matrix calculus identities?
$$\frac{\partial c}{\partial\boldsymbol\beta} = \mathbf 0 \qquad \frac{\partial(\mathbf a^\top\boldsymbol\beta)}{\partial\boldsymbol\beta} = \mathbf a \qquad \frac{\partial(\boldsymbol\beta^\top\mathbf A\boldsymbol\beta)}{\partial\boldsymbol\beta} = 2\mathbf A\boldsymbol\beta$$ The third holds only for symmetric $\mathbf A$ — and $\mathbf X^\top\mathbf X$ is always symmetric ✓
The Normal Equation and its solution?
$$\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf X^\top\mathbf y \qquad\Longrightarrow\qquad \boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$$
Why do the two middle terms combine in the loss expansion?
Both are $1\times1$ scalars, and the transpose of a scalar is that same scalar. So $\mathbf y^\top\mathbf X\boldsymbol\beta = \boldsymbol\beta^\top\mathbf X^\top\mathbf y$, giving $-2\mathbf y^\top\mathbf X\boldsymbol\beta$.
Why is the inversion cost $O(k^3)$?
Gauss–Jordan elimination has three nested loops: $k$ outer pivot columns × $k$ middle rows per pivot × $\sim 2k$ inner elements = $2k^3 \to O(k^3)$.
$m = 10{,}000$ → $10^{12}$ operations — which is exactly why Gradient Descent exists.
OLS aur Gradient Descent alag answers denge?
No. The loss is convex — there is only one global minimum. OLS jumps straight there; GD walks there.

L5–L6Gradient Descent Family

MSE gradient aur BGD update rule?
$$\nabla L = \frac{2}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y) \qquad \boldsymbol\theta := \boldsymbol\theta - \alpha\frac{2}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)$$ Convention alert: if the loss is $\frac{1}{2m}\|\cdot\|^2$, the factor of 2 disappears.
Why is "Batch" Gradient Descent called Batch?
Because the gradient uses the entire matrix $\mathbf X$ and the entire vector $\mathbf y$ — every single training example contributes to every single update step.
Why is the simultaneous update mandatory?
All the partial derivatives must be evaluated at the same old $\boldsymbol\theta$. If you update $\theta_0$ and then take the derivative for $\theta_1$ using the new $\theta_0$, you are computing the gradient at a mixed, undefined point.
$f(x,y)=x^2+y^2$, point $(3,4)$, $\alpha = 1$ — what happens?
$\nabla f = [6,8]^\top$. $[3,4] - 1\cdot[6,8] = \mathbf{[-3,-4]}$.
The loss is the same at both ($25$) — an overshoot! The next step takes you back to $(3,4)$ — infinite oscillation. This is the exact demonstration of "$\alpha$ too large".
Updates per epoch — teeno methods?
Batch GD: 1  ·  SGD: $m$  ·  Mini-Batch: $\lceil m/b\rceil$
Classic trap: $m = 1000$, $b = 100$ → 10 updates, not 1000.
Cost per update — teeno methods?
Batch $O(md)$ · SGD $O(d)$ · Mini-Batch $O(bd)$. The cost per epoch is $O(md)$ for all three.
Why is shuffling critical in SGD?
Real datasets are ordered (by date, class, region). Without shuffling, consecutive updates follow the ordering pattern instead of the true learning signal — giving biased update sequences.
Four misconceptions about SGD, and their corrections?
1. "It ignores most of the data" → one update uses one sample, one epoch uses all of them.
2. "The loss must fall at every update" → it can temporarily rise on a noisy update.
3. "More updates = faster convergence" → each update is cheaper but less accurate.
4. "Stochastic = random parameters" → the randomness is only in the sample selection.
A student writes SGD but accumulates the gradients and updates at the end — what have they implemented?
Batch Gradient Descent. The update line must be inside the sample loop, not outside it. That is the one line that moves between BGD and SGD.

L7Evaluation Metrics

What is the difference between the units of MSE and RMSE?
MSE is in squared units (e.g. (thousand INR)²). RMSE is in target units.
"MSE = 9.25 means typical miss of 9.25" — FALSE. The typical miss is RMSE $= 3.04$.
The formula for $R^2$, and its biggest misconception?
$$R^2 = 1 - \frac{\text{RSS}}{\text{TSS}}$$ Misconception: $R^2 = 0.93$ does NOT mean 93% accuracy, nor "93% of predictions correct", nor "7% average error". It is a relative sum-of-squares comparison against the mean baseline.
Two datasets with the same RMSE but different $R^2$ — why?
The same RMSE ⟹ the same RSS. But $R^2$ also depends on TSS — the spread of the target around its mean.
Tightly clustered targets (small TSS) → the mean baseline is already strong → low $R^2$. Spread-out targets → high $R^2$.
The Adjusted $R^2$ formula — and does $p$ count the intercept?
$$R^2_{\text{adj}} = 1 - (1-R^2)\frac{n-1}{n-p-1} = 1 - \left(\frac{\text{RSS}}{\text{TSS}}\right)\left(\frac{n-1}{n-p-1}\right)$$ $p$ = predictors excluding the intercept. Requires $n > p+1$.
Model B has a higher $R^2$ but a lower Adjusted $R^2$ — why?
B reduced RSS ($74 \to 60$), so raw $R^2$ rose ($0.9295 \to 0.9429$). But its larger $p$ pushed the penalty factor from $\frac{7}{5} = 1.4$ to $\frac{7}{4} = 1.75$ — a 25% bigger penalty against only a 19% smaller unexplained fraction. Net result: $R^2_{\text{adj}}$ fell $0.9013 \to 0.9000$.
The denominators of Precision and Recall?
Precision $= \frac{TP}{TP+FP}$ — Predicted positives.
Recall $= \frac{TP}{TP+FN}$ — Real (actual) positives.
F1 never uses TN at all.
Which metric does FP hurt, and which does FN hurt?
FP (Type I, a false alert) → Precision falls.
FN (Type II, a miss) → Recall falls.
Missing costly? → Recall. False alerts costly? → Precision. Both? → F1.
Macro, Weighted, Micro — what is the difference between the three?
Macro: every class gets an equal vote ($\frac1C\sum M_c$).
Weighted: weighted by class size ($\frac{\sum n_cM_c}{\sum n_c}$).
Micro: pool the TP/FP/FN first. In single-label multiclass, micro $=$ accuracy.
Why was weighted F1 (0.672) higher than macro F1 (0.638)?
Because the weakest class was also the smallest (Needs Support: F1 $=0.500$, only 4 of 18). Macro gives it a $\frac13$ vote; weighted gives it only $\frac{4}{18} = 22\%$. The weighting down-weighted the model's biggest weakness.
66.7% accuracy but one class has only 50% recall — how?
Accuracy is dominated by the largest class. Ready's 6 correct alone give $6/18 = 33\%$. The Support class has only 4 students — missing 2 costs just $2/18 \approx 11\%$ of accuracy but halves that class's recall.

L8Polynomial Regression & Assumptions

Is Polynomial Regression a new algorithm?
No. It is a feature transformation. The model is still linear in its parameters — the same OLS / Gradient Descent applies, just with extra columns in $\mathbf X$.
Degree $n$ polynomial — kitne columns, kitne bends?
$n+1$ columns (including the intercept) and up to $n-1$ bends (the derivative has degree $n-1$, which can have $n-1$ roots).
"$R^2$ rose when I added $x^3$, so the cubic term is useful" — correct?
Wrong. Training $R^2$ can never fall when a predictor is added — even a useless feature will fit some noise. Look at Adjusted $R^2$ or validation error.
5 assumptions — naam aur diagnostic?
1. Linearity → residual vs fitted (U-shape = bad)
2. Normality of residuals → histogram
3. Homoscedasticity → residual vs fitted (funnel = bad)
4. No autocorrelation → residual vs observation order
5. No multicollinearity → input–input correlation; $\det(\mathbf X^\top\mathbf X)$
Do not confuse heteroscedasticity with autocorrelation — what is the difference?
Hetero: the spread changes when plotted against $\hat y$ (a funnel).
Auto: there is a pattern in the residuals when plotted against observation order (runs/waves).
Does multicollinearity ruin prediction or inference?
Inference. The individual coefficients become unreliable (large opposite-signed values that cancel out). Prediction is usually fine, because the combined effect is still estimated correctly.
The singularity chain of perfect multicollinearity (the 7-step summary)?
$\exists\,\mathbf c \ne \mathbf 0$ with $\mathbf X\mathbf c = \mathbf 0$ ⟹ $\mathbf X^\top\mathbf X\mathbf c = \mathbf 0$ ⟹ $\mathbf X^\top\mathbf X$ sends a non-zero vector to zero ⟹ singular ⟹ $\det = \mathbf 0$ ⟹ $(\mathbf X^\top\mathbf X)^{-1}$ does not exist.
"Linearity means every point must lie on the line" — correct?
Wrong. Real data has noise. The assumption is only that the central trend is reasonably represented by a straight line (or a linear combination of the features).

L9Bias–Variance

The MSE decomposition, and the most common mistake?
$$\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon)$$ Mistake: forgetting to square the bias. Bias 2, variance 3, noise 1 → MSE $= 4+3+1 = \mathbf 8$, not 6.
The definitions of Bias and Variance?
$$\text{Bias}(x) = E[\hat f(x)] - f(x) \qquad \text{Variance}(x) = E\!\left[(\hat f(x) - E[\hat f(x)])^2\right]$$ Bias = how far the average prediction is from the truth. Variance = how much the predictions move when the samples change.
How do you diagnose high bias vs high variance from the error curves?
High bias: training and validation error are both high and close to each other.
High variance: training error is low, validation error is much higher (a large gap).
When will more data help — and when will it not?
For high variance, yes — the gap starts closing.
For high bias, no — the curves already meet and sit on a high plateau; the model is structurally limited. Change the model, not the data volume.
What is irreducible error — can a better algorithm remove it?
$\operatorname{Var}(\varepsilon)$ — the randomness that is already present in the data.
No — no amount of flexible modelling can remove it. Reducing it needs better measurements or better features.

L10Feature Selection

3 feature behaviours?
Relevant — stable information that helps predict the target.
Redundant — the same information that another feature already carries (CGPA_copy).
Irrelevant — it varies but has no stable relationship with the target (Random_number).
Student_ID has very high variance — so is it useful?
No. Variance is a necessary-but-not-sufficient screen. Student_ID has $r = -0.02$ with the target. A feature must both vary AND co-vary with the target.
What is the Pearson correlation for $y = x^2$ — and what does it teach?
$x = [-2,-1,0,1,2]$, $\bar x = 0$, $\bar y = 2$. Numerator $= -4+1+0-1+4 = 0$, so $r = \mathbf 0$.
An $|r| \ge 0.30$ filter would REMOVE a perfectly predictive feature. Pearson measures only linear association.
Exhaustive vs sequential search cost?
Exhaustive: $2^p - 1$ (exponential). $p=30$ → 1,073,741,823.
Sequential path: $\frac{p(p+1)}{2}$ (quadratic). $p=30$ → 465.
Forward vs Backward selection — when is each one natural?
Forward: $p$ is large and the final subset is small (keep ~10 out of 100). You never even need to fit the full model.
Backward: the model can fit all $p$ and the final subset retains most of them (~90 out of 100).
Forward and backward select different subsets — is that a bug?
No. Both are greedy and explore different paths. Once a feature is removed or skipped it is never reconsidered. This is expected behaviour.
The golden rule of feature selection?
Selection must happen INSIDE cross-validation, using only the training portion of each fold. Selecting on the whole dataset and then cross-validating = data leakage = an optimistically biased score.
$x$ and $x^2$ are highly correlated — should you drop the squared term?
No, not without validating. That correlation is a mathematical artefact. The squared term was added specifically to capture curvature. Removing it removes the model's ability to bend.

L11PCA

The one-line definition of PCA?
An unsupervised linear feature-extraction method that finds a new set of orthogonal axes (principal components) along which the variance of the data is maximized.
Feature selection vs feature extraction — core difference?
Selection: keep or discard original columns. The original meanings are preserved.
Extraction (PCA): rotate the coordinate system, then project. The new components are combinations of the original features.
Why is mean centering compulsory?
The mean term $\mathbf u^\top\bar{\mathbf X}$ appears in the variance-along-$\mathbf u$ formula. Centering makes it exactly zero. Otherwise PC₁ picks the direction from the origin to the mean, not the direction of the spread.
Is standardization always necessary too?
No — it is conditional. Apply it when the features have different units/scales. With shared units, centering alone is enough.
The covariance matrix formula and its dimensions?
$$S = \frac{1}{n-1}X_c^\top X_c \qquad (p\times p,\ \text{symmetric})$$ Diagonal = feature variances. Off-diagonal = pairwise covariances.
What does an eigenvalue mean geometrically in PCA?
The variance (spread) of the projected data along that principal direction. A larger $\lambda$ = more information. $\lambda = 0$ = no variation at all in that direction — it can be discarded with no loss.
Why are principal components uncorrelated?
$S$ is a real symmetric matrix, so by the spectral theorem its eigenvectors can be chosen mutually orthogonal. Projecting centered data onto orthogonal directions makes the covariance of the scores zero.
The dimensions of $W_k$ and the projection formula?
$W_k$ is $\mathbf{p \times k}$ (its columns are the first $k$ eigenvectors, each of length $p$).
$Z = X_cW_k$ is $(n\times p)(p\times k) = \mathbf{n\times k}$ ✓
How do you apply PCA to the test set?
$$Z_{\text{test}} = \left(X_{\text{test}} - \mathbf 1_{\text{test}}\boldsymbol\mu_{\text{tr}}^\top\right)W_k$$ Use the stored training $\boldsymbol\mu$, $\mathbf s$ and $W_k$. NEVER refit on test.
Why is maximizing variance the same as minimizing reconstruction error?
Pythagorean decomposition: $\|\mathbf x_i\|^2 = z_i^2 + \|\mathbf e_i\|^2$. The total norm does not depend on $\mathbf u$ at all, so maximizing $\sum z_i^2$ and minimizing $\sum\|\mathbf e_i\|^2$ are exactly the same optimisation.
The three failure cases of PCA?
1. Circular/isotropic data — $\lambda_1 \approx \lambda_2$, no dominant direction.
2. Symmetric classes — projecting onto PC₁ makes the classes merge.
3. Nonlinear manifolds — linear PCA cannot unroll a curved structure.
You chose $k$ from a 90% variance threshold — is that enough?
No. EVR is an unsupervised criterion — it never looks at $y$. The discarded variance may contain the direction most predictive of $y$. Validate $k$ as a hyperparameter inside CV.

⚡ 60-Second One-Liners

The whole course in one sentence

Clean the data → split it → build the model → optimize it → measure it → improve generalization.

Why squared error?

Non-negative (no cancellation) + differentiable everywhere (clean calculus) + punishes large errors. Cost: outlier-sensitive.

Why gradient descent?

OLS costs $O(m^3)$ and needs $\det(\mathbf X^\top\mathbf X)\ne0$. GD never inverts anything.

Why mini-batch?

Batch waits too long; SGD is too noisy; mini-batch averages $b$ gradients and fits GPUs best.

Why Adjusted $R^2$?

Raw $R^2$ rewards fit but never charges for complexity. Adjusted $R^2$ charges for each extra predictor.

Why per-class metrics?

Accuracy is dominated by the largest class and hides minority-class failure.

Why the 5 assumptions?

They decide whether the model's inference (coefficients, relationships) can be trusted — not just its predictions.

Why PCA over selection?

When information is spread across several correlated columns and no single column captures it alone.
