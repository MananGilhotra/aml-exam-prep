L0From Code to AI, ML & DL

Traditional Programming aur Machine Learning ka paradigm flip kya hai?
Traditional: Data + Rules → Answers.  ML: Data + Answers → Rules.
Traditional mein insaan rules likhta hai; ML mein algorithm rules discover karta hai.
AI, ML aur DL ka relation kya hai — aur AI mein aisa kya hai jo ML mein nahi?
$\text{DL} \subset \text{ML} \subset \text{AI}$.
AI mein non-learning systems bhi aate hain — jaise search algorithms (Google Maps routing). Wo AI hain par ML nahi.
"Deep" Learning mein "deep" ka technically matlab kya hai?
Structural architecture — dozens ya hundreds of hidden layers sequentially stacked. Yeh training data ke size, tuning depth ya feature count ke baare mein nahi hai.
Reinforcement Learning ko baaki teen paradigms se fundamentally kya alag karta hai?
Wo koi static dataset use hi nahi karta. Agent ek unknown environment explore karke apna khud ka training signal generate karta hai.
Trap: "unlabelled data use karta hai" galat hai — unsupervised learning bhi wahi karta hai.
3 core tasks aur unke output types?
Regression → continuous scalar (supervised) · Classification → discrete label (supervised) · Clustering → natural groups (unsupervised)
Image classification vs image segmentation?
Classification poori image ko ek label deta hai. Segmentation har pixel ko label karta hai, ek map produce karke ki image ka har region kya contain karta hai.

L1Lifecycle Part 1

Chaar scaling formulas aur unke use cases?
Min-Max $\frac{X-X_{\min}}{X_{\max}-X_{\min}}$ → bounded/clean · Z-Score $\frac{X-\mu}{\sigma}$ → Gaussian · Max Abs $\frac{X}{\max|X|}$ → sparse (preserves zeros) · Robust $\frac{X-\text{Med}}{Q_3-Q_1}$ → heavy outliers
Min-Max scaling outliers ke saath kyun fail hota hai?
Ek outlier denominator $(X_{\max}-X_{\min})$ ko blow up kar deta hai, jisse baaki saari normal values 0 ke paas squash ho jaati hain aur indistinguishable ban jaati hain.
Example: $[100,150,200,250,50000]$ → $0, 0.001, 0.002, 0.003, 1$
Robust scaling ki 4 steps aur $[100,150,200,250,50000]$ ka answer?
Median $=200$ · $Q_1 = \frac{100+150}{2} = 125$ · $Q_3 = \frac{250+50000}{2} = 25125$ · IQR $=25000$
$X=100 \to \frac{-100}{25000} = \mathbf{-0.004}$  ·  $X=50000 \to \frac{49800}{25000} = \mathbf{1.992}$
PIN code ko kaunsa feature type classify karoge, aur kyun?
Categorical (Nominal). Wo dikhta number jaisa hai par uspar arithmetic meaningless hai — 110001 + 110002 ka koi matlab nahi. Star ratings (1–5) similarly Ordinal hain, continuous numerical nahi.
Label Encoding KNN ko mislead karta hai par Decision Tree ko nahi. Kyun?
KNN distances compute karta hai — $|Red-Green|=2$ vs $|Red-Blue|=1$ ek fabricated similarity ban jaati hai.
Tree thresholds par split karta hai — "value $\le 0.5$?" — magnitude ka koi role nahi.
1000 categories par One-Hot vs Binary — kitne columns?
One-Hot: 1000 columns (curse of dimensionality). Binary: $\lceil\log_2 1000\rceil = $ ~10 columns.
EDA checklist ke 7 goals?
1. Dataset Structure · 2. Missing Values · 3. Outliers · 4. Duplicates · 5. Distributions · 6. Relationships · 7. Class Imbalance
95% Class A / 5% Class B. Model hamesha A predict karta hai → 95% accuracy. Useful?
Nahi. Class B ka recall $= 0$ hai. Model ne kuch seekha hi nahi — sirf majority class guess kar raha hai. Yeh class imbalance hai; accuracy jhoot bol rahi hai.

L2Lifecycle Part 2

Parameter vs Hyperparameter — ek line mein difference?
Parameter: model khud seekhta hai, training ke dauraan (weights $w_1$, intercept $w_0$, bias).
Hyperparameter: engineer manually set karta hai, training se pehle (max_depth, n_estimators, learning_rate).
Keyword: "learned during" = parameter.
Split ratio aur golden rule?
70% Train · 15% Validation · 15% Test.
Golden rule: Split FIRST, engineer SECOND. Test set sirf ek baar, aakhir mein.
Poore dataset ka mean nikaal ke, phir split karke, training set impute karna — leakage hai?
Haan, definitely. Us mean mein test set ki rows ki information baithi hai — yaani test ne training ko influence kiya. Test score ab artificially optimistic hai.
Sahi: pehle split, phir sirf training rows se mean, aur wahi mean teeno par apply.
Training loop ki 5 steps (correct order)?
1. Initialize (random weights) → 2. Forward Pass (predictions) → 3. Compute Loss (MSE) → 4. Backward Pass (gradient descent) → 5. Convergence Check
MAE, RMSE, $R^2$ — kab kaunsa?
MAE — "on average how many units off?" (interpretable, equal weight).
RMSE — jab ek bada error catastrophic ho (squaring punish karti hai).
$R^2$ — "random guessing/baseline se kitna behtar?" (relative).
Periodic vs Triggered retraining?
Periodic: fixed schedule (monthly), performance ki parwah kiye bina.
Triggered: monitoring accuracy ko threshold ke neeche detect kare tab fire hota hai.
Unpredictable events (drought, pandemic) ke liye Triggered chahiye.

L3Simple Linear Regression

Teen loss attempts aur har ek ka problem?
1. Signed $\sum e_i$ → positives aur negatives cancel ho jaate hain (0 total ≠ perfect model).
2. Absolute $\sum|e_i|$ → $e=0$ par differentiable nahi (sharp V corner).
3. Squared ✓ $\sum e_i^2$ → non-negative, smooth, par outliers ke prati sensitive.
Squared error ke teen properties?
1. Always non-negative (no cancellation) · 2. Differentiable everywhere (derivative of $x^2$ is $2x$, defined at 0) · 3. Penalizes large errors quadratically
Error 10× bada hone par squared penalty kitni badi?
100×, not 10×. $10^2 = 100$ vs $1^2 = 1$. Penalty quadratically grow karti hai.
OLS ke do formulas — aur konsa pehle compute karna hai?
$$m = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}, \qquad c = \bar y - m\bar x$$ $m$ pehle (kyunki $c$ ke formula mein $m$ chahiye).
OLS derivation ki #1 mistake kya hai?
$\sum_{i=1}^{n} c = c$ likhna. Correct: $\sum_{i=1}^{n} c = \mathbf{nc}$ — $c$ constant hai, use $n$ baar add kar rahe ho.
OLS line kis point se hamesha guzarti hai — aur kyun?
$(\bar x, \bar y)$ — data ka centroid.
Proof: $\hat y(\bar x) = m\bar x + c = m\bar x + (\bar y - m\bar x) = \bar y$ ✓
Agar saare $x_i$ identical hon to kya hota hai?
$x_i - \bar x = 0$ har $i$ ke liye ⟹ $\sum(x_i-\bar x)^2 = 0$ ⟹ division by zero ⟹ $m$ undefined.
Geometrically: saare points ek vertical line par hain — uska slope exist hi nahi karta.
Outlier add karne par OLS line uski taraf jaayegi ya door?
Toward the outlier. Optimizer $\sum e^2$ minimize kar raha hai; us huge squared term ko shrink karne ka tareeka line ko outlier ki taraf kheenchna hai — chahe baaki saare points ka fit kharab ho jaye.

L4Multiple Linear Regression

$\mathbf X$, $\boldsymbol\beta$, $\hat{\mathbf y}$, $\mathbf X^\top\mathbf X$ ke dimensions?
$\mathbf X$: $n\times(m{+}1)$ · $\boldsymbol\beta$: $(m{+}1)\times1$ · $\hat{\mathbf y}$: $n\times1$ · $\mathbf X^\top\mathbf X$: $(m{+}1)\times(m{+}1)$
Trap: 200 rows, 5 features → $\mathbf X^\top\mathbf X$ is $\mathbf{6\times6}$ (intercept column count karo!), not $5\times5$.
Loss ka expanded form aur teeno term types?
$$L(\boldsymbol\beta) = \underbrace{\mathbf y^\top\mathbf y}_{\text{constant}} \underbrace{-\,2\mathbf y^\top\mathbf X\boldsymbol\beta}_{\text{linear}} + \underbrace{\boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta}_{\text{quadratic}}$$ Teen types ⟹ teen identities chahiye.
Teen matrix calculus identities?
$$\frac{\partial c}{\partial\boldsymbol\beta} = \mathbf 0 \qquad \frac{\partial(\mathbf a^\top\boldsymbol\beta)}{\partial\boldsymbol\beta} = \mathbf a \qquad \frac{\partial(\boldsymbol\beta^\top\mathbf A\boldsymbol\beta)}{\partial\boldsymbol\beta} = 2\mathbf A\boldsymbol\beta$$ Teesri sirf symmetric $\mathbf A$ ke liye — aur $\mathbf X^\top\mathbf X$ hamesha symmetric hai ✓
Normal Equation aur uska solution?
$$\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf X^\top\mathbf y \qquad\Longrightarrow\qquad \boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$$
Loss expansion mein do middle terms kyun combine ho jaate hain?
Dono $1\times1$ scalars hain, aur ek scalar ka transpose khud wahi scalar hota hai. So $\mathbf y^\top\mathbf X\boldsymbol\beta = \boldsymbol\beta^\top\mathbf X^\top\mathbf y$, giving $-2\mathbf y^\top\mathbf X\boldsymbol\beta$.
Inversion cost kyun $O(k^3)$ hai?
Gauss–Jordan elimination mein teen nested loops: outer $k$ pivot columns × middle $k$ rows per pivot × inner $\sim 2k$ elements = $2k^3 \to O(k^3)$.
$m = 10{,}000$ → $10^{12}$ operations (one trillion).
OLS aur Gradient Descent alag answers denge?
Nahi. Loss convex hai — ek hi global minimum. OLS wahan jump karta hai; GD wahan walk karke pahuchta hai.

L5–L6Gradient Descent Family

MSE gradient aur BGD update rule?
$$\nabla L = \frac{2}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y) \qquad \boldsymbol\theta := \boldsymbol\theta - \alpha\frac{2}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)$$ Convention alert: agar loss $\frac{1}{2m}\|\cdot\|^2$ ho to factor 2 gayab ho jaata hai.
"Batch" Gradient Descent ko Batch kyun kehte hain?
Kyunki gradient poori matrix $\mathbf X$ aur poore vector $\mathbf y$ use karta hai — har single training example har single update step mein contribute karta hai.
Simultaneous update kyun mandatory hai?
Saare partial derivatives same old $\boldsymbol\theta$ par evaluate hone chahiye. Agar $\theta_0$ update karke phir naye $\theta_0$ se $\theta_1$ ka derivative nikaalo, to tum ek mixed, undefined point ka gradient compute kar rahe ho.
$f(x,y)=x^2+y^2$, point $(3,4)$, $\alpha = 1$ — kya hota hai?
$\nabla f = [6,8]^\top$. $[3,4] - 1\cdot[6,8] = \mathbf{[-3,-4]}$.
Loss dono par same ($25$) — overshoot! Agla step wapas $(3,4)$ le jaayega — infinite oscillation. Yeh "$\alpha$ too large" ka exact demonstration hai.
Updates per epoch — teeno methods?
Batch GD: 1  ·  SGD: $m$  ·  Mini-Batch: $\lceil m/b\rceil$
Classic trap: $m = 1000$, $b = 100$ → 10 updates, not 1000.
Cost per update — teeno methods?
Batch $O(md)$ · SGD $O(d)$ · Mini-Batch $O(bd)$. Cost per epoch teeno ke liye $O(md)$ hai.
SGD mein shuffling kyun critical hai?
Real datasets ordered hote hain (date, class, region). Bina shuffling ke consecutive updates true learning signal ki jagah ordering pattern follow karti hain — biased update sequences.
SGD ke baare mein 4 misconceptions aur corrections?
1. "Most data ignore karta hai" → ek update ek sample, ek epoch saare.
2. "Loss har update par girni chahiye" → noisy update par temporarily badh sakti hai.
3. "Zyada updates = faster convergence" → har update sasti par kam accurate.
4. "Stochastic = random parameters" → randomness sirf sample selection mein hai.
Ek student SGD likhta hai par gradients accumulate karke end mein update karta hai — kya implement hua?
Batch Gradient Descent. Update line sample loop ke andar honi chahiye, bahar nahi. Yahi wo ek line hai jo BGD aur SGD ke beech move karti hai.

L7Evaluation Metrics

MSE aur RMSE ke units mein kya difference hai?
MSE squared units mein hai (e.g. (thousand INR)²). RMSE target units mein.
"MSE = 9.25 means typical miss of 9.25" — FALSE. Typical miss RMSE $= 3.04$ hai.
$R^2$ ki formula aur uska sabse bada misconception?
$$R^2 = 1 - \frac{\text{RSS}}{\text{TSS}}$$ Misconception: $R^2 = 0.93$ ka matlab 93% accuracy NAHI hai, na hi "93% predictions correct", na hi "7% average error". Yeh ek relative sum-of-squares comparison hai mean baseline ke saath.
Do datasets ka same RMSE par different $R^2$ — kyun?
Same RMSE ⟹ same RSS. Par $R^2$ TSS par bhi depend karta hai — target ka mean ke around spread.
Tightly clustered targets (small TSS) → mean baseline already strong → low $R^2$. Spread-out targets → high $R^2$.
Adjusted $R^2$ ki formula — aur $p$ mein intercept count hota hai?
$$R^2_{\text{adj}} = 1 - (1-R^2)\frac{n-1}{n-p-1} = 1 - \left(\frac{\text{RSS}}{\text{TSS}}\right)\left(\frac{n-1}{n-p-1}\right)$$ $p$ = predictors excluding the intercept. Requires $n > p+1$.
Model B ka $R^2$ zyada par Adjusted $R^2$ kam — kyun?
B ne RSS kam ki ($74 \to 60$), to raw $R^2$ badha ($0.9295 \to 0.9429$). Par uske $p$ badhne se penalty factor $\frac{7}{5} = 1.4 \to \frac{7}{4} = 1.75$ ho gaya — 25% badi penalty vs sirf 19% kam unexplained fraction. Net: $R^2_{\text{adj}}$ $0.9013 \to 0.9000$ gira.
Precision aur Recall ke denominators?
Precision $= \frac{TP}{TP+FP}$ — Predicted positives.
Recall $= \frac{TP}{TP+FN}$ — Real (actual) positives.
F1 TN use karta hi nahi.
FP aur FN kis metric ko hurt karte hain?
FP (Type I, false alert) → Precision girti hai.
FN (Type II, miss) → Recall girti hai.
Missing costly? → Recall. False alerts costly? → Precision. Both? → F1.
Macro, Weighted, Micro — teeno mein difference?
Macro: har class ko equal vote ($\frac1C\sum M_c$).
Weighted: class size se weight ($\frac{\sum n_cM_c}{\sum n_c}$).
Micro: pehle TP/FP/FN pool karo. Single-label multiclass mein micro $=$ accuracy.
Weighted F1 (0.672) macro F1 (0.638) se zyada kyun tha?
Kyunki sabse weak class bhi sabse chhoti thi (Needs Support: F1 $=0.500$, sirf 4 of 18). Macro use $\frac13$ vote deta hai; weighted sirf $\frac{4}{18} = 22\%$. Weighting ne model ki sabse badi weakness down-weight kar di.
66.7% accuracy par ek class ka recall sirf 50% — kaise?
Accuracy sabse badi class se dominate hoti hai. Ready ke 6 correct alone $6/18 = 33\%$ dete hain. Support class mein sirf 4 students — 2 miss karna accuracy se $2/18 \approx 11\%$ leta hai par us class ka recall aadha kar deta hai.

L8Polynomial Regression & Assumptions

Polynomial Regression naya algorithm hai?
Nahi. Wo ek feature transformation hai. Model apne parameters mein abhi bhi linear hai — wahi OLS / Gradient Descent apply hota hai, bas $\mathbf X$ mein extra columns aate hain.
Degree $n$ polynomial — kitne columns, kitne bends?
$n+1$ columns (intercept sahit) aur up to $n-1$ bends (derivative degree $n-1$ hai, jiski $n-1$ roots ho sakti hain).
"$R^2$ badh gaya jab $x^3$ add kiya, to cubic term useful hai" — sahi?
Galat. Training $R^2$ predictor add karne par kabhi ghat nahi sakta — ek useless feature bhi noise fit kar lega. Adjusted $R^2$ ya validation error dekho.
5 assumptions — naam aur diagnostic?
1. Linearity → residual vs fitted (U-shape = bad)
2. Normality of residuals → histogram
3. Homoscedasticity → residual vs fitted (funnel = bad)
4. No autocorrelation → residual vs observation order
5. No multicollinearity → input–input correlation; $\det(\mathbf X^\top\mathbf X)$
Heteroscedasticity aur autocorrelation confuse mat karo — kya difference hai?
Hetero: spread badalta hai, $\hat y$ ke against plot karne par (funnel).
Auto: residuals mein pattern hai, observation order ke against plot karne par (runs/waves).
Multicollinearity prediction ko kharab karti hai ya inference ko?
Inference ko. Individual coefficients unreliable ho jaate hain (bade opposite-signed values jo cancel karte hain). Prediction usually theek rehti hai kyunki combined effect correctly estimate ho jaata hai.
Perfect multicollinearity ka singularity chain (7 steps ka summary)?
$\exists\,\mathbf c \ne \mathbf 0$ with $\mathbf X\mathbf c = \mathbf 0$ ⟹ $\mathbf X^\top\mathbf X\mathbf c = \mathbf 0$ ⟹ $\mathbf X^\top\mathbf X$ ek non-zero vector ko zero bhejta hai ⟹ singular ⟹ $\det = \mathbf 0$ ⟹ $(\mathbf X^\top\mathbf X)^{-1}$ exist nahi karta.
"Linearity ka matlab har point line par hona chahiye" — sahi?
Galat. Real data mein noise hota hai. Assumption sirf yeh hai ki central trend ek straight line (ya features ka linear combination) se reasonably represent ho.

L9Bias–Variance

MSE decomposition aur sabse common galti?
$$\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon)$$ Galti: bias ko square karna bhool jaana. Bias 2, variance 3, noise 1 → MSE $= 4+3+1 = \mathbf 8$, not 6.
Bias aur Variance ki definitions?
$$\text{Bias}(x) = E[\hat f(x)] - f(x) \qquad \text{Variance}(x) = E\!\left[(\hat f(x) - E[\hat f(x)])^2\right]$$ Bias = average prediction truth se kitni door. Variance = samples badalne par predictions kitni hilti hain.
High bias aur high variance ko error curves se kaise diagnose karo?
High bias: training aur validation error dono high aur ek dusre ke paas.
High variance: training error low, validation error bohot zyada (bada gap).
Zyada data kab help karega — aur kab nahi?
High variance par haan — gap close hone lagta hai.
High bias par nahi — curves already saath hain aur high plateau par hain; model structurally limited hai. Model badlo, data volume nahi.
Irreducible error kya hai — kya better algorithm use hata sakta hai?
$\operatorname{Var}(\varepsilon)$ — wo randomness jo data mein already maujood hai.
Nahi — koi bhi amount of flexible modelling use nahi hata sakta. Ise kam karne ke liye better measurements ya better features chahiye.

L10Feature Selection

3 feature behaviours?
Relevant — stable information jo target predict karne mein help kare.
Redundant — wahi information jo kisi aur feature mein pehle se hai (CGPA_copy).
Irrelevant — varies par target ke saath koi stable relationship nahi (Random_number).
Student_ID ki variance bohot high hai — to wo useful hai?
Nahi. Variance ek necessary-but-not-sufficient screen hai. Student_ID ka $r = -0.02$ hai target ke saath. Feature ko vary karna AUR target ke saath co-vary karna dono chahiye.
$y = x^2$ par Pearson correlation kya hai — aur wo kya sikhata hai?
$x = [-2,-1,0,1,2]$, $\bar x = 0$, $\bar y = 2$. Numerator $= -4+1+0-1+4 = 0$, so $r = \mathbf 0$.
Ek $|r| \ge 0.30$ filter ek perfectly predictive feature ko REMOVE kar dega. Pearson sirf linear association measure karta hai.
Exhaustive vs sequential search cost?
Exhaustive: $2^p - 1$ (exponential). $p=30$ → 1,073,741,823.
Sequential path: $\frac{p(p+1)}{2}$ (quadratic). $p=30$ → 465.
Forward vs Backward selection — kab kaunsa natural hai?
Forward: $p$ bada, final subset chhota (100 mein se ~10 rakhni hai). Full model fit karne ki zaroorat hi nahi.
Backward: model saare $p$ fit kar sakta hai aur final subset zyadatar retain karta hai (100 mein se ~90).
Forward aur backward alag subsets select kar lein — bug hai?
Nahi. Dono greedy hain aur alag paths explore karte hain. Ek baar feature removed/skipped ho gaya to reconsider nahi hota. Expected behaviour hai.
Feature selection ka golden rule?
Selection cross-validation ke ANDAR hona chahiye, har fold ke training portion se hi. Poore dataset par select karke phir CV karna = data leakage = optimistically biased score.
$x$ aur $x^2$ highly correlated hain — squared term drop kar do?
Nahi, bina validate kiye nahi. Wo correlation ek mathematical artefact hai. Squared term specifically curvature capture karne ke liye add kiya gaya tha. Use hataane se model ki bend karne ki ability chali jaati hai.

L11PCA

PCA ki one-line definition?
Ek unsupervised linear feature-extraction method jo orthogonal axes (principal components) ka naya set dhoondta hai jinke along data ka variance maximized hota hai.
Feature selection vs feature extraction — core difference?
Selection: original columns keep ya discard karo. Original meanings preserve hote hain.
Extraction (PCA): coordinate system rotate karo, phir project karo. Naye components original features ke combinations hain.
Mean centering compulsory kyun hai?
Variance-along-$\mathbf u$ formula mein mean term $\mathbf u^\top\bar{\mathbf X}$ appear karta hai. Centering isse exactly zero bana deta hai. Warna PC₁ origin se mean tak ki direction pick karta hai, spread ki nahi.
Standardization bhi hamesha zaroori hai?
Nahi — wo conditional hai. Jab features ke different units/scales hon tab apply karo. Same units par centering alone kaafi hai.
Covariance matrix ki formula aur dimensions?
$$S = \frac{1}{n-1}X_c^\top X_c \qquad (p\times p,\ \text{symmetric})$$ Diagonal = feature variances. Off-diagonal = pairwise covariances.
Eigenvalue ka geometric matlab PCA mein kya hai?
Us principal direction ke along projected data ki variance (spread). Bada $\lambda$ = zyada information. $\lambda = 0$ = us direction mein koi variation nahi — bina loss ke discard kiya ja sakta hai.
Principal components uncorrelated kyun hote hain?
$S$ ek real symmetric matrix hai, to spectral theorem se uske eigenvectors mutually orthogonal chune ja sakte hain. Orthogonal directions par centered data project karne se scores ki covariance zero ho jaati hai.
$W_k$ ke dimensions aur projection formula?
$W_k$ is $\mathbf{p \times k}$ (columns = pehle $k$ eigenvectors, har ek length $p$).
$Z = X_cW_k$ is $(n\times p)(p\times k) = \mathbf{n\times k}$ ✓
Test set par PCA kaise apply karo?
$$Z_{\text{test}} = \left(X_{\text{test}} - \mathbf 1_{\text{test}}\boldsymbol\mu_{\text{tr}}^\top\right)W_k$$ Stored training $\boldsymbol\mu$, $\mathbf s$ aur $W_k$ use karo. KABHI test par refit mat karo.
Variance maximize karna aur reconstruction error minimize karna — same kyun hai?
Pythagorean decomposition: $\|\mathbf x_i\|^2 = z_i^2 + \|\mathbf e_i\|^2$. Total norm $\mathbf u$ par depend hi nahi karta, to $\sum z_i^2$ max karna aur $\sum\|\mathbf e_i\|^2$ min karna exactly same optimisation hai.
PCA ke teen failure cases?
1. Circular/isotropic data — $\lambda_1 \approx \lambda_2$, koi dominant direction nahi.
2. Symmetric classes — PC₁ par project karne se classes merge ho jaati hain.
3. Nonlinear manifolds — linear PCA curved structure unroll nahi kar sakta.
90% variance threshold se $k$ choose kar liya — kaafi hai?
Nahi. EVR ek unsupervised criterion hai — wo $y$ dekhta hi nahi. Discarded variance mein wo direction ho sakti hai jo $y$ ki sabse zyada predictive hai. $k$ ko hyperparameter ki tarah CV ke andar validate karo.

⚡ 60-Second One-Liners

The whole course in one sentence

Data ko clean karo → split karo → model banao → optimize karo → measure karo → generalization improve karo.

Why squared error?

Non-negative (no cancellation) + differentiable everywhere (clean calculus) + punishes large errors. Cost: outlier-sensitive.

Why gradient descent?

OLS costs $O(m^3)$ and needs $\det(\mathbf X^\top\mathbf X)\ne0$. GD never inverts anything.

Why mini-batch?

Batch waits too long; SGD is too noisy; mini-batch averages $b$ gradients and fits GPUs best.

Why Adjusted $R^2$?

Raw $R^2$ rewards fit but never charges for complexity. Adjusted $R^2$ charges for each extra predictor.

Why per-class metrics?

Accuracy is dominated by the largest class and hides minority-class failure.

Why the 5 assumptions?

They decide whether the model's inference (coefficients, relationships) can be trusted — not just its predictions.

Why PCA over selection?

When information is spread across several correlated columns and no single column captures it alone.

✅ Final Checklist — can you do all of these?

  • Min-Max, Z-Score aur Robust scaling by hand compute karna.
  • Ek encoding choose karke justify karna (Label / Ordinal / One-Hot / Binary).
  • OLS ke $m$ aur $c$ ki poori derivation likhna, including $\sum c = nc$ step.
  • 5-point dataset par $m$, $c$ aur ek prediction compute karna.
  • Design matrix banana aur $\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$ by hand solve karna (det + adjugate).
  • Teeno matrix calculus identities state karna aur unse Normal Equation derive karna.
