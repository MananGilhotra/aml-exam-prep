PART I · Polynomial Regression

1Start from the failure of a straight line

▷ Hook

Suppose we want to predict an NST student's internship stipend from one feature: project depth score (1 = basic project, 10 = strong, production-like portfolio).

At first glance, higher project depth should mean a higher stipend. But the relationship may not grow at a constant rate:

  • Going from score 2 to 4 helps a little.
  • Going from score 8 to 10 helps a lot more, because strong projects unlock better companies and referrals.

So the scatter plot may curve upward.

The ordinary one-feature Linear Regression model$$y = \beta_0 + \beta_1 x$$

This has only one slope, and that slope is constant. If $x$ increases by one unit, the predicted value changes by the same amount everywhere. That is exactly what a straight line means.

But in the scatter plot, the effect of one extra unit of project depth looks larger at high $x$ than at low $x$. We need a model whose slope can change as $x$ changes.

2The Simple Idea: Create a New Feature $x^2$

▷ Hook

Do not think of Polynomial Regression as a brand-new algorithm. Think of it as a feature transformation: building a new input column out of an existing one. We are not collecting new data. We are changing how each record is represented.

For example: if the original feature value is $x = 4$, the new feature is $x^2 = 16$. If $x = 8$, then $x^2 = 64$. Notice that $x^2$ grows faster when $x$ is large. That gives the model a way to bend upward.

After adding the new feature$$y = \beta_0 + \beta_1 x + \beta_2 x^2$$
★ Key Insight — feature space

A feature space is the coordinate system formed by the features we hand to the model.

  • With only one feature $x$, each student is located by one coordinate.
  • With two features $x$ and $x^2$, each student is located by two coordinates.

The target $y$ then becomes the vertical axis.

3The 3D Mental Model: A Curve Becomes a Plane

▷ Hook

Rename $x^2$ as $z$ for a minute: $z = x^2$. The model then becomes $y = \beta_0 + \beta_1 x + \beta_2 z$. That is the equation of a plane in the three-dimensional space with axes $x$, $z$ and $y$.

In the original graph we saw a curve. But after adding $x^2$, the model is fitting a plane. When that fitted plane is viewed only along that path, it appears as a curve in the original $(x, y)$ plot.

♦ Takeaway ⭐

Polynomial Regression is not a new algorithm. We simply gave Linear Regression a better coordinate system. The model is still linear in its parameters $\beta_0, \beta_1, \beta_2$. It is only non-linear in the original feature $x$.

4Generalizing to Higher-Degree Polynomial Features

A polynomial degree is the highest power of $x$ used in the model:

  • Degree 1: $y = \beta_0 + \beta_1x$   (straight line)
  • Degree 2: $y = \beta_0 + \beta_1x + \beta_2x^2$   (can create a U-shape or upward bend)
  • Degree 3: $y = \beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3$   (can bend more flexibly)
General degree-$n$ polynomial regression model$$y = \beta_0 + \beta_1x + \beta_2x^2 + \cdots + \beta_nx^n$$

Each new power is just one more feature column. The coefficient $\beta_k$ controls how much the $x^k$ column contributes to the prediction.

△ Warning — OVERFITTING

Overfitting means the model captures the accidental fluctuations of the training data instead of the stable pattern that will repeat on future data. A very high-degree polynomial can twist itself to reduce training error, but that guarantees nothing about predictions on new students.

Classroom question: If a degree-8 curve passes closer to every training point than the degree-2 curve does, should we automatically prefer degree 8?

Answer: no. Training error always falls (or stays the same) as degree rises — it is not evidence of model quality. What matters is validation/test error. The degree-8 curve has memorised noise; on a new student it can be wildly wrong. This is exactly the bias–variance tradeoff.

PART II · The Five Assumptions of Linear Regression

Why assumptions matter

Polynomial Regression showed an important lesson: Linear Regression is powerful when the representation of the data matches the real pattern. But even after choosing the model, we still have to ask whether the model is behaving in a trustworthy way.

Linear Regression relies on several assumptions to ensure the validity and reliability of its estimates and inferences. Here inference means understanding relationships between variables, interpreting coefficients, and making statements about how changes in the inputs affect the output.

Notation: Residual $= $ actual value $-$ predicted value:  $e = y - \hat y$

The five key assumptions:

  1. Linearity
  2. Normality of Residuals
  3. Homoscedasticity
  4. No Autocorrelation of Errors
  5. No (or little) Multicollinearity

5Assumption 1 — Linearity

▷ The assumption

There is a linear relationship between the independent variables and the dependent variable. The model assumes that changes in the independent variables produce proportional changes in the dependent variable.

△ Very common misconception

Linearity does NOT mean every point lies exactly on the line. Real data has noise. It means the central trend should be reasonably represented by a straight line, or by a linear combination of the features.

How to check this assumption

  1. Scatter plots: plot $y$ against each independent variable. If the relationship looks linear, the assumption is likely satisfied. Nonlinear patterns indicate a violation.
  2. Residual plots: plot the residuals against the predicted values. If the assumption holds, the residuals should be randomly scattered around zero, with no discernible pattern.
  3. Polynomial terms: add polynomial terms to the model and compare the fit with the original linear model. If the new model improves the fit significantly, that suggests the linearity assumption is being violated.
What to do when this assumption fails
  • Transformations: apply logarithmic, square-root or other transformations so the relationship becomes more linear.
  • Polynomial Regression: add polynomial terms of the independent variables to capture non-linear relationships. (That was Part I!)

6Assumption 2 — Normality of Residuals

▷ The assumption

The error terms (residuals) roughly follow a normal distribution with mean zero and variance $\sigma^2$.

Mean zero means the residuals are centred around zero. The model should not systematically over-predict or under-predict.

Normal distribution means most residuals are small, and very large positive or negative residuals are rare.

How to check: Histogram of residuals

7Assumption 3 — Homoscedasticity

▷ The assumption

The spread of the error terms (residuals) should be constant across all levels of the independent variables. If the spread changes systematically, that is heteroscedasticity, which can affect the efficiency of the estimates.

What to do when this assumption fails

Transformations: apply logarithmic, square-root or inverse transformations to stabilise the variance of the residuals.

8Assumption 4 — No Autocorrelation of Errors

▷ The assumption

There should be no apparent correlation or pattern in the residuals. Independence of errors means one residual should not help us predict the next residual.

This matters especially when the data has a natural order (time series) — daily stock prices, monthly sales, sensor readings over time, or user activity logs.

9Assumption 5 — No Multicollinearity ⭐

▷ The assumption

Multicollinearity occurs when two or more independent variables in a regression model are highly correlated. They exhibit a strong linear relationship, which makes it hard to isolate the individual effect of each variable.

9.1 The setup

Suppose we have two features $X_1$ and $X_2$, and we want to predict $Y$:

$$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \varepsilon_1$$

Here $\varepsilon_1$ represents the part of $Y$ that the model does not explain. If $X_1$ and $X_2$ are highly correlated, then:

$$X_1 = a_0 + a_1X_2 + \varepsilon_2$$

If we substitute $X_1$ into the equation for $Y$, the model becomes:

$$Y \approx \underbrace{(\beta_0 + \beta_1 a_0)}_{C_0} + \underbrace{(\beta_1 a_1 + \beta_2)}_{C_1}X_2 + \underbrace{(\beta_1\varepsilon_2 + \varepsilon_1)}_{\text{combined noise}}$$

So effectively, $Y$ becomes a linear function of $X_2$ alone. The model ends up finding $C_0$ and $C_1$ instead of cleanly separating the effects of $\beta_1$ and $\beta_2$. That makes it hard to figure out how much each individual variable affects $Y$.

9.2 Inference vs Prediction ⭐

★ Key Insight
  • If the goal is inference (understanding relationships, interpreting coefficients), multicollinearity is bad, because $\beta_1$ and $\beta_2$ become unreliable.
  • If the goal is prediction only, multicollinearity is usually less harmful. The model can still predict well, but the individual coefficient values will not be trustworthy.

9.3 Perfect Multicollinearity

If $X_1$ and $X_2$ are perfectly correlated, then:

$$X_1 = a_0 + a_1X_2 \qquad \text{(no error term)}$$

One feature is a perfect linear combination of another. Recall the OLS equation:

$$\hat{\boldsymbol\beta} = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$$

When some columns of $\mathbf X$ are a perfect linear combination of other columns, the matrix $\mathbf X^\top\mathbf X$ becomes singular — that is, its determinant becomes zero.

9.4 · Proof

Proof that $\mathbf X^\top\mathbf X$ is singular

  1. Step 1 Suppose the columns of $\mathbf X$ are linearly dependent. That means there exists a non-zero vector $\mathbf c$ such that: $$\mathbf X\,\mathbf c = \mathbf 0$$
  2. Step 2 Multiply both sides by $\mathbf X^\top$: $$\mathbf X^\top\mathbf X\,\mathbf c = \mathbf X^\top\mathbf 0$$
  3. Step 3 Therefore: $$\mathbf X^\top\mathbf X\,\mathbf c = \mathbf 0$$
  4. Step 4 But $\mathbf c$ is not the zero vector. That means $\mathbf X^\top\mathbf X$ sends a non-zero vector to zero. Therefore $\mathbf X^\top\mathbf X$ has linearly dependent columns.
  5. Step 5 So $\mathbf X^\top\mathbf X$ is singular.
  6. Step 6 Therefore: $$\det(\mathbf X^\top\mathbf X) = \mathbf 0$$
  7. Step 7 Hence: $$(\mathbf X^\top\mathbf X)^{-1}\ \textbf{does not exist}$$
    And therefore the OLS closed-form solution has no unique answer.
9.5 · Numerical Example

A $3\times3$ matrix where Column 3 = Column 1 + Column 2

$$\mathbf X = \begin{bmatrix}1 & 1 & 2\\ 1 & 2 & 3\\ 1 & 3 & 4\end{bmatrix}$$

Here Column 3 $=$ Column 1 $+$ Column 2 ($2 = 1+1$, $3 = 1+2$, $4 = 1+3$). The columns are linearly dependent.

  1. Compute $\mathbf X^\top\mathbf X$
    EntryComputationValue
    $(1,1)$$1^2+1^2+1^2$3
    $(1,2)$$1(1)+1(2)+1(3)$6
    $(1,3)$$1(2)+1(3)+1(4)$9
    $(2,2)$$1^2+2^2+3^2$14
    $(2,3)$$1(2)+2(3)+3(4)$20
    $(3,3)$$2^2+3^2+4^2$29
    $$\mathbf X^\top\mathbf X = \begin{bmatrix}3 & 6 & 9\\ 6 & 14 & 20\\ 9 & 20 & 29\end{bmatrix}$$

    Notice: the dependence carries through — Column 3 of $\mathbf X^\top\mathbf X$ is also Column 1 $+$ Column 2 ($3+6=9$, $6+14=20$, $9+20=29$).

  2. Compute the determinant $$\det = 3(14 \cdot 29 - 20 \cdot 20) - 6(6 \cdot 29 - 20 \cdot 9) + 9(6 \cdot 20 - 14 \cdot 9)$$ $$= 3(406 - 400) - 6(174 - 180) + 9(120 - 126)$$ $$= 3(6) - 6(-6) + 9(-6) = 18 + 36 - 54 = \mathbf{0}$$
  3. Conclusion
    $\mathbf X^\top\mathbf X$ is singular, and $(\mathbf X^\top\mathbf X)^{-1}$ does not exist.
Practice P3

Multicollinearity Detective

An e-commerce team predicts monthly sales revenue using:

$X_1$Number of website visitors
$X_2$Number of page views
$X_3$Marketing spend (in $\times$1000)
$X_4$Number of social media ad clicks
$X_5$Temperature in the city (Celsius)
  1. (a) Which pairs are most likely to exhibit multicollinearity?
    Pair 1: $X_1$ (visitors) and $X_2$ (page views)

    Reason: page views are generated mechanically from visitors — every visitor views one or more pages. If one goes up, the other almost certainly goes up. Correlation is typically $> 0.95$.

    Pair 2: $X_3$ (marketing spend) and $X_4$ (ad clicks)

    Reason: ad clicks are bought with marketing spend. Spend more, get more impressions, get more clicks. These essentially measure the same underlying quantity in two different units.

  2. (b) If $X_1$ and $X_2$ have correlation 0.98, and the model gives $\beta_1 = 15.2$ and $\beta_2 = -14.8$, what is wrong with interpreting these coefficients individually?

    These coefficients are not trustworthy at all. Two large, opposite-signed coefficients that almost cancel each other out ($15.2 - 14.8 = 0.4$) are the classic signature of severe multicollinearity.

    The model cannot separate the effects of $X_1$ and $X_2$. It is only capturing their combined effect. Taken literally, $\beta_2 = -14.8$ would mean "more page views reduce revenue" — which is obviously absurd.

    And these estimates are unstable: adding or removing a few rows could turn the coefficients into $(40, -39)$ or $(-10, 11)$, while the predictions stay almost the same.

  3. (c) If the team's goal is only to predict next month's revenue (not to understand which feature drives sales), should they worry about multicollinearity?
    No (mostly).

    Justify: for pure prediction, multicollinearity is less harmful. The combined effect is still estimated correctly, so $\hat y$ stays accurate. Caveats: (i) if the relationship between $X_1$ and $X_2$ changes in future, extrapolation can break; (ii) a near-singular $\mathbf X^\top\mathbf X$ is numerically unstable.

  4. (d) Suppose the team discovers $X_4 = 0.5 \times X_3$ exactly. What specific mathematical problem will OLS encounter?
    Perfect multicollinearity ⟹ the columns of $\mathbf X$ are linearly dependent ⟹ $\det(\mathbf X^\top\mathbf X) = 0$ ⟹ $\mathbf X^\top\mathbf X$ is singular ⟹ $(\mathbf X^\top\mathbf X)^{-1}$ does not exist ⟹ OLS has no unique solution.

    In practice NumPy will raise LinAlgError: Singular matrix. Fix: drop one column — it was carrying no new information anyway.

  1. (c) Find the Mistake — A student writes: "In perfect multicollinearity, $\mathbf X^\top\mathbf X$ has a determinant of 1, so it is invertible."
    Both parts are wrong. In perfect multicollinearity, $\det(\mathbf X^\top\mathbf X) = \mathbf 0$, so $\mathbf X^\top\mathbf X$ is singular and NOT invertible.

    Corrected statement: "In perfect multicollinearity, the columns of $\mathbf X$ are linearly dependent, so $\det(\mathbf X^\top\mathbf X) = 0$, making $\mathbf X^\top\mathbf X$ singular; therefore $(\mathbf X^\top\mathbf X)^{-1}$ does not exist and OLS has no unique solution."

    Note: a determinant of $=1$ actually implies invertibility — the student wrote exactly the opposite condition.

  2. (d) Predict the Outcome — An ML engineer predicts house prices using: square footage, number of rooms, and total area of all rooms (which equals square footage × fraction used as rooms). What specific problem will occur, and why?
    Perfect (or near-perfect) multicollinearity — leading to a singular or near-singular $\mathbf X^\top\mathbf X$.

    Why: the third feature is derived deterministically from the first. If that fraction is constant across the dataset (say 0.8), then total_room_area = 0.8 × square_footage — an exact linear multiple. The columns are then linearly dependent, $\det(\mathbf X^\top\mathbf X) = 0$, and the OLS formula fails.

    If the fraction varies slightly between houses, the columns are almost dependent — the matrix is near-singular. The determinant is technically nonzero, but microscopic. The inverse exists mathematically but explodes numerically: the coefficients will be wildly unstable, with huge magnitudes and opposite signs, and changing one row can flip them completely.

    Fix: drop the third feature — it contains no new information.

⚠ Common Mistakes

GaltiSahi Baat
"Polynomial Regression is a non-linear algorithm"It is linear in the parameters — only non-linear in $x$. The same OLS/GD is used.
"A higher degree is always better because training error drops"Training error always drops with degree. Look at validation error — overfitting is real.
"Linearity means every point must lie on the line"Only the central trend has to be linear. Noise is expected.
"Multicollinearity = a bit of correlation"It means high correlation or exact linear dependence. A little correlation is normal.
"Multicollinearity always ruins the predictions"Prediction is often fine. What breaks is inference — the individual coefficients become unreliable.
"Perfect multicollinearity means $\det = 1$"$\det = \mathbf 0$. A determinant of 1 would make the matrix invertible.
Confusing heteroscedasticity with autocorrelationHetero = the spread changes (against $\hat y$). Auto = there is a pattern (against observation order).
"A degree-$n$ polynomial has $n$ feature columns"$n+1$ columns including the intercept: $[\mathbf 1, x, x^2, \dots, x^n]$.
