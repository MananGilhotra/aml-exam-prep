PART I · Polynomial Regression

1Start from the failure of a straight line

▷ Hook

Maan lo hum ek NST student ka internship stipend predict karna chahte hain ek feature se: project depth score (1 = basic project, 10 = strong, production-like portfolio).

Pehli nazar mein, higher project depth ka matlab higher stipend hona chahiye. Par relationship constant rate se nahi badh sakti:

  • Score 2 se 4 jaana thodi help karta hai.
  • Score 8 se 10 jaana bohot zyada help karta hai, kyunki strong projects better companies aur referrals unlock karte hain.

Scatter plot curve upward kar sakta hai.

The ordinary one-feature Linear Regression model$$y = \beta_0 + \beta_1 x$$

Iske paas sirf ek slope hai. Slope constant hai. Agar $x$ ek unit badhta hai, predicted value har jagah same amount se badalti hai. Straight line ka exactly yahi matlab hai.

Par scatter plot mein, ek extra unit of project depth ka effect high $x$ par zyada lagta hai vs low $x$ par. Hume ek aisa model chahiye jiska slope badal sake jaise $x$ badalta hai.

2The Simple Idea: Create a New Feature $x^2$

▷ Hook

Polynomial Regression ko ek bilkul naya algorithm mat samjho. Ise ek feature transformation samjho: ek existing input column se ek naya input column banana. Hum naya data collect nahi kar rahe. Hum badal rahe hain ki har record ko kaise represent kiya jaata hai.

For example: if the original feature value is $x = 4$, the new feature is $x^2 = 16$. If $x = 8$, then $x^2 = 64$. Notice that $x^2$ grows faster when $x$ is large. Yeh model ko upar bend karne ka ek tareeka de deta hai.

After adding the new feature$$y = \beta_0 + \beta_1 x + \beta_2 x^2$$
★ Key Insight — feature space

Ek feature space wo coordinate system hai jo un features se banta hai jo hum model ko dete hain.

  • Sirf ek feature $x$ ke saath, har student ek coordinate se locate hota hai.
  • Do features $x$ aur $x^2$ ke saath, har student do coordinates se locate hota hai.

Target $y$ phir vertical axis ban jaata hai.

3The 3D Mental Model: A Curve Becomes a Plane

▷ Hook

Ek minute ke liye $x^2$ ko $z$ rename kar do: $z = x^2$. Tab model ban jaata hai $y = \beta_0 + \beta_1 x + \beta_2 z$. Yeh axes $x$, $z$, aur $y$ wale three-dimensional space mein ek plane ka equation hai.

Original graph mein humne ek curve dekha. Par $x^2$ add karne ke baad, model ek plane fit kar raha hai. Jab us fitted plane ko sirf us path ke along dekha jaata hai, to wo original $(x, y)$ plot mein ek curve ki tarah dikhta hai.

♦ Takeaway ⭐

Polynomial Regression ek naya algorithm nahi hai. Humne Linear Regression ko ek better coordinate system de diya. Model apne parameters $\beta_0, \beta_1, \beta_2$ mein abhi bhi linear hai. Wo sirf original feature $x$ mein non-linear hai.

4Generalizing to Higher-Degree Polynomial Features

A polynomial degree is the highest power of $x$ used in the model:

  • Degree 1: $y = \beta_0 + \beta_1x$   (straight line)
  • Degree 2: $y = \beta_0 + \beta_1x + \beta_2x^2$   (can create a U-shape or upward bend)
  • Degree 3: $y = \beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3$   (can bend more flexibly)
General degree-$n$ polynomial regression model$$y = \beta_0 + \beta_1x + \beta_2x^2 + \cdots + \beta_nx^n$$

Har new power sirf ek aur feature column hai. Coefficient $\beta_k$ control karta hai ki $x^k$ column prediction mein kitna contribute karta hai.

△ Warning — OVERFITTING

Overfitting ka matlab hai ki model training data ke accidental fluctuations capture kar leta hai, us stable pattern ki jagah jo future data par repeat hoga. Ek bohot high-degree polynomial apne aap ko twist karke training error kam kar sakta hai, par isse naye students par better prediction guarantee nahi hoti.

Classroom question: Agar ek degree-8 curve har training point ke degree-2 curve se zyada paas se guzarti hai, to kya humein automatically degree 8 prefer karna chahiye?

Answer: Nahi. Training error hamesha degree ke saath ghatti hai (ya same rehti hai) — wo model quality ka evidence nahi hai. Jo matter karta hai wo hai validation/test error. Degree-8 curve ne noise memorize kar liya hai; naye student par wo wildly galat predict kar sakti hai. Yahi bias–variance tradeoff hai.

PART II · The Five Assumptions of Linear Regression

Why assumptions matter

Polynomial Regression ne ek important lesson dikhaya: Linear Regression tab powerful hai jab data ka representation real pattern se match karta ho. Par model choose karne ke baad bhi, hume yeh poochna hota hai ki model trustworthy tareeke se behave kar raha hai ya nahi.

Linear Regression kai assumptions par rely karta hai taaki estimates aur inferences ki validity aur reliability ensure ho. Yahan inference ka matlab hai variables ke beech relationship samajhna, coefficients interpret karna, aur yeh statements dena ki inputs mein changes output ko kaise affect karte hain.

Notation: Residual $= $ actual value $-$ predicted value:  $e = y - \hat y$

The five key assumptions:

  1. Linearity
  2. Normality of Residuals
  3. Homoscedasticity
  4. No Autocorrelation of Errors
  5. No (or little) Multicollinearity

5Assumption 1 — Linearity

▷ The assumption

Independent variables aur dependent variable ke beech ek linear relationship hai. Model assume karta hai ki independent variables mein changes dependent variable mein proportional changes laate hain.

△ Very common misconception

Linearity ka matlab yeh NAHI hai ki har point exactly line par lie kare. Real data mein noise hota hai. Iska matlab hai ki central trend ek straight line ya features ke linear combination se reasonably represent honi chahiye.

How to check this assumption

  1. Scatter plots: $y$ ko har independent variable ke against plot karo. Agar relationship linear lage, assumption likely satisfied hai. Nonlinear patterns violation indicate karte hain.
  2. Residual plots: Residuals ko predicted values ke against plot karo. Agar assumption hold karti hai, residuals zero ke around randomly scattered hone chahiye, bina kisi discernible pattern ke.
  3. Polynomial terms: Model mein polynomial terms add karo aur fit ko original linear model se compare karo. Agar naya model fit ko significantly improve karta hai, to yeh suggest karta hai ki linearity assumption violate ho rahi hai.
What to do when this assumption fails
  • Transformations: Logarithmic, square-root, ya other transformations apply karo taaki relationship zyada linear ho jaye.
  • Polynomial Regression: Independent variables ke polynomial terms add karo taaki non-linear relationships capture ho. (Yehi Part I tha!)

6Assumption 2 — Normality of Residuals

▷ The assumption

Error terms (residuals) roughly ek normal distribution follow karte hain jiska mean zero aur variance $\sigma^2$ hai.

Mean zero ka matlab residuals zero ke around centered hain. Model ko systematically over-predict ya under-predict nahi karna chahiye.

Normal distribution ka matlab zyadatar residuals chhote hain, aur bohot bade positive ya negative residuals rare hain.

How to check: Histogram of residuals

7Assumption 3 — Homoscedasticity

▷ The assumption

Error terms (residuals) ka spread independent variables ke saare levels par constant hona chahiye. Agar spread systematically badalta hai, to yeh heteroscedasticity hai, jo estimates ki efficiency ko affect kar sakti hai.

What to do when this assumption fails

Transformations: Logarithmic, square-root, ya inverse transformations apply karo taaki residuals ka variance stabilize ho.

8Assumption 4 — No Autocorrelation of Errors

▷ The assumption

Residuals mein koi apparent correlation ya pattern nahi hona chahiye. Independence of errors ka matlab hai ki ek residual hume agla residual predict karne mein help nahi karni chahiye.

Yeh especially tab important hai jab data ka ek natural order ho (time series) — jaise daily stock prices, monthly sales, sensor readings over time, ya user activity logs.

9Assumption 5 — No Multicollinearity ⭐

▷ The assumption

Multicollinearity tab hoti hai jab ek regression model mein do ya zyada independent variables highly correlated hote hain. Wo ek strong linear relationship exhibit karte hain, jisse har variable ka individual effect isolate karna mushkil ho jaata hai.

9.1 The setup

Maan lo humare paas do features $X_1$ aur $X_2$ hain, aur hum $Y$ predict karna chahte hain:

$$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \varepsilon_1$$

Yahan $\varepsilon_1$ $Y$ ka wo part represent karta hai jo model explain nahi karta. Agar $X_1$ aur $X_2$ highly correlated hain, to:

$$X_1 = a_0 + a_1X_2 + \varepsilon_2$$

Agar hum $X_1$ ko $Y$ ke equation mein substitute karein, to model ban jaata hai:

$$Y \approx \underbrace{(\beta_0 + \beta_1 a_0)}_{C_0} + \underbrace{(\beta_1 a_1 + \beta_2)}_{C_1}X_2 + \underbrace{(\beta_1\varepsilon_2 + \varepsilon_1)}_{\text{combined noise}}$$

So effectively, $Y$ sirf $X_2$ ka linear function ban jaata hai. Model $C_0$ aur $C_1$ find karne ki koshish karta hai, bajaye iske ki $\beta_1$ aur $\beta_2$ ke effects clearly separate kare. Isse yeh figure out karna mushkil ho jaata hai ki har individual variable $Y$ ko kitna affect karta hai.

9.2 Inference vs Prediction ⭐

★ Key Insight
  • Agar goal inference hai (relationships samajhna, coefficients interpret karna), to multicollinearity bad hai kyunki $\beta_1$ aur $\beta_2$ unreliable ho jaate hain.
  • Agar goal prediction only hai, to multicollinearity usually less harmful hai. Model phir bhi accha predict kar sakta hai, par individual coefficient values trustworthy nahi hongi.

9.3 Perfect Multicollinearity

Agar $X_1$ aur $X_2$ perfectly correlated hain, to:

$$X_1 = a_0 + a_1X_2 \qquad \text{(no error term)}$$

Ek feature doosre ka perfect linear combination hai. Recall the OLS equation:

$$\hat{\boldsymbol\beta} = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$$

Jab $\mathbf X$ ke kuch columns doosre columns ka perfect linear combination hote hain, to $\mathbf X^\top\mathbf X$ matrix singular ban jaata hai, yaani uska determinant zero ho jaata hai.

9.4 · Proof

Proof that $\mathbf X^\top\mathbf X$ is singular

  1. Step 1 Suppose the columns of $\mathbf X$ are linearly dependent. That means there exists a non-zero vector $\mathbf c$ such that: $$\mathbf X\,\mathbf c = \mathbf 0$$
  2. Step 2 Multiply both sides by $\mathbf X^\top$: $$\mathbf X^\top\mathbf X\,\mathbf c = \mathbf X^\top\mathbf 0$$
  3. Step 3 Therefore: $$\mathbf X^\top\mathbf X\,\mathbf c = \mathbf 0$$
  4. Step 4 But $\mathbf c$ is not the zero vector. That means $\mathbf X^\top\mathbf X$ sends a non-zero vector to zero. Therefore $\mathbf X^\top\mathbf X$ has linearly dependent columns.
  5. Step 5 So $\mathbf X^\top\mathbf X$ is singular.
  6. Step 6 Therefore: $$\det(\mathbf X^\top\mathbf X) = \mathbf 0$$
  7. Step 7 Hence: $$(\mathbf X^\top\mathbf X)^{-1}\ \textbf{does not exist}$$
    Aur isliye OLS closed-form solution ka koi unique answer nahi hai.
9.5 · Numerical Example

A $3\times3$ matrix where Column 3 = Column 1 + Column 2

$$\mathbf X = \begin{bmatrix}1 & 1 & 2\\ 1 & 2 & 3\\ 1 & 3 & 4\end{bmatrix}$$

Here Column 3 $=$ Column 1 $+$ Column 2 ($2 = 1+1$, $3 = 1+2$, $4 = 1+3$). The columns are linearly dependent.

  1. Compute $\mathbf X^\top\mathbf X$
    EntryComputationValue
    $(1,1)$$1^2+1^2+1^2$3
    $(1,2)$$1(1)+1(2)+1(3)$6
    $(1,3)$$1(2)+1(3)+1(4)$9
    $(2,2)$$1^2+2^2+3^2$14
    $(2,3)$$1(2)+2(3)+3(4)$20
    $(3,3)$$2^2+3^2+4^2$29
    $$\mathbf X^\top\mathbf X = \begin{bmatrix}3 & 6 & 9\\ 6 & 14 & 20\\ 9 & 20 & 29\end{bmatrix}$$

    Notice: the dependence carries through — Column 3 of $\mathbf X^\top\mathbf X$ is also Column 1 $+$ Column 2 ($3+6=9$, $6+14=20$, $9+20=29$).

  2. Compute the determinant $$\det = 3(14 \cdot 29 - 20 \cdot 20) - 6(6 \cdot 29 - 20 \cdot 9) + 9(6 \cdot 20 - 14 \cdot 9)$$ $$= 3(406 - 400) - 6(174 - 180) + 9(120 - 126)$$ $$= 3(6) - 6(-6) + 9(-6) = 18 + 36 - 54 = \mathbf{0}$$
  3. Conclusion
    $\mathbf X^\top\mathbf X$ is singular, and $(\mathbf X^\top\mathbf X)^{-1}$ does not exist.
Practice P3

Multicollinearity Detective

An e-commerce team predicts monthly sales revenue using:

$X_1$Number of website visitors
$X_2$Number of page views
$X_3$Marketing spend (in $\times$1000)
$X_4$Number of social media ad clicks
$X_5$Temperature in the city (Celsius)
  1. (a) Which pairs are most likely to exhibit multicollinearity?
    Pair 1: $X_1$ (visitors) and $X_2$ (page views)

    Reason: Page views mechanically visitors se generate hote hain — har visitor ek ya zyada pages dekhta hai. Ek badhega to doosra lagbhag definitely badhega. Correlation typically $> 0.95$.

    Pair 2: $X_3$ (marketing spend) and $X_4$ (ad clicks)

    Reason: Ad clicks khareede jaate hain marketing spend se. Zyada spend karo, zyada impressions, zyada clicks. Yeh essentially same underlying quantity ko do alag units mein measure kar rahe hain.

  2. (b) If $X_1$ and $X_2$ have correlation 0.98, and the model gives $\beta_1 = 15.2$ and $\beta_2 = -14.8$, what is wrong with interpreting these coefficients individually?

    Yeh coefficients bilkul trustworthy nahi hain. Do bade, opposite-signed coefficients jo lagbhag ek doosre ko cancel kar dete hain ($15.2 - 14.8 = 0.4$) — yeh severe multicollinearity ka classic signature hai.

    Model $X_1$ aur $X_2$ ke effects ko separate nahi kar paa raha. Wo sirf unka combined effect capture kar raha hai. Literally interpret karne par $\beta_2 = -14.8$ ka matlab hoga "zyada page views se revenue ghatta hai" — jo obviously absurd hai.

    Aur yeh estimates unstable hain: kuch rows add/remove karne par coefficients $(40, -39)$ ya $(-10, 11)$ ban sakte hain, jabki predictions lagbhag same rahengi.

  3. (c) If the team's goal is only to predict next month's revenue (not to understand which feature drives sales), should they worry about multicollinearity?
    No (mostly).

    Justify: Pure prediction ke liye multicollinearity less harmful hai. Combined effect correctly estimate ho jaata hai, to $\hat y$ accurate rehti hai. Caveats: (i) agar future mein $X_1$ aur $X_2$ ka relationship badal jaata hai, to extrapolation break ho sakta hai; (ii) near-singular $\mathbf X^\top\mathbf X$ numerically unstable hota hai.

  4. (d) Suppose the team discovers $X_4 = 0.5 \times X_3$ exactly. What specific mathematical problem will OLS encounter?
    Perfect multicollinearity ⟹ $\mathbf X$ ke columns linearly dependent ⟹ $\det(\mathbf X^\top\mathbf X) = 0$ ⟹ $\mathbf X^\top\mathbf X$ singular ⟹ $(\mathbf X^\top\mathbf X)^{-1}$ exist nahi karta ⟹ OLS ka koi unique solution nahi.

    Practically, NumPy LinAlgError: Singular matrix throw karega. Fix: ek column drop kar do — wo koi nayi information de hi nahi raha.

  1. (c) Find the Mistake — A student writes: "In perfect multicollinearity, $\mathbf X^\top\mathbf X$ has a determinant of 1, so it is invertible."
    Both parts are wrong. In perfect multicollinearity, $\det(\mathbf X^\top\mathbf X) = \mathbf 0$, so $\mathbf X^\top\mathbf X$ is singular and NOT invertible.

    Corrected statement: "In perfect multicollinearity, the columns of $\mathbf X$ are linearly dependent, so $\det(\mathbf X^\top\mathbf X) = 0$, making $\mathbf X^\top\mathbf X$ singular; therefore $(\mathbf X^\top\mathbf X)^{-1}$ does not exist and OLS has no unique solution."

  2. (d) Predict the Outcome — An ML engineer predicts house prices using: square footage, number of rooms, and total area of all rooms (which equals square footage × fraction used as rooms). What specific problem will occur, and why?
    Perfect (or near-perfect) multicollinearity — leading to a singular or near-singular $\mathbf X^\top\mathbf X$.

    Why: Teesra feature deterministically derive hota hai pehle se. Agar wo fraction dataset mein constant hai (say 0.8), to total_room_area = 0.8 × square_footage — ek exact linear multiple. Tab columns linearly dependent hain, $\det(\mathbf X^\top\mathbf X) = 0$, aur OLS formula fail ho jaata hai.

    Agar fraction houses ke beech thoda vary karta hai, to columns almost dependent hain — matrix near-singular hai. Determinant technically nonzero hai, par microscopic. Inverse mathematically exist karta hai par numerically explode ho jaata hai: coefficients wildly unstable honge, opposite signs ke saath huge magnitudes, aur ek row change karne se wo bilkul badal jaayenge.

    Fix: teesra feature drop kar do — wo koi nayi information contain nahi karta.

⚠ Common Mistakes

GaltiSahi Baat
"Polynomial Regression ek non-linear algorithm hai"Wo parameters mein linear hai — sirf $x$ mein non-linear. Wahi OLS/GD use hota hai.
"Higher degree hamesha better hai kyunki training error kam hota hai"Training error degree ke saath hamesha ghatti hai. Validation error dekho — overfitting real hai.
"Linearity ka matlab har point line par hona chahiye"Sirf central trend linear honi chahiye. Noise expected hai.
"Multicollinearity = thodi si correlation"High correlation ya exact linear dependence. Thodi correlation normal hai.
"Multicollinearity predictions ko hamesha kharab kar deti hai"Prediction often fine hoti hai. Inference tootti hai — individual coefficients unreliable.
"Perfect multicollinearity mein $\det = 1$"$\det = \mathbf 0$. Determinant 1 hota to matrix invertible hota.

"Degree $n$ polynomial mein $n$ feature columns hote hain"$n+1$ columns (intercept sahit): $[\mathbf 1, x, x^2, \dots, x^n]$.

⚡ Quick Revision

Poly model

$y = \beta_0 + \beta_1x + \cdots + \beta_nx^n$ · $n+1$ columns · up to $n-1$ bends

Linearity · Normality · Homoscedasticity · No Autocorrelation · No Multicollinearity

dependent columns → $\mathbf X\mathbf c = \mathbf 0$ → $\mathbf X^\top\mathbf X\mathbf c = \mathbf 0$ → singular → $\det = 0$ → no inverse
