Simple Linear Regression using the OLS Method

Scatter plots se best-fit line tak — poori Ordinary Least Squares derivation, ek bhi step skip kiye bina.

⏱ ~35 min📐 Full derivation 🧮 5 solved numericals✓ 10 MCQs
⚡ Ek Line Mein

Infinite lines possible hain. Hum wo line chunte hain jo total squared error minimize kare. Squared kyun? Kyunki signed error cancel ho jaata hai, aur absolute error $e=0$ par differentiable nahi hai. Squared error non-negative + smooth + convex hai — to calculus se exact closed-form answer mil jaata hai:
$m = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}$ aur $c = \bar y - m\bar x$.

1The Storyline — from data to a prediction question

▷ Hook

Maan lo mere paas NST students ka dataset hai. Mujhe unka CGPA aur jo internship stipend unhe mila, dono pata hai. Agar ek naya student mujhe apna CGPA bataye, to kya main uska stipend predict kar sakta hoon?

Kyunki data linear trend dikhata hai, hum is relationship ko ek straight-line model se capture karne ki koshish karte hain:

Straight-line model$$\hat y = m(\text{CGPA}) + c$$
  • $\hat y$ (y-hat) = predicted output (predicted stipend)
  • $x$ = input variable (CGPA of the student)
  • $m$ = slope — CGPA ke saath stipend kitni steeply badalta hai
  • $c$ = intercept — predicted stipend jab CGPA $= 0$

Is dataset mein hume input values (CGPA) aur corresponding output values (stipend) dono pata hain. Hum examples se seekh rahe hain jahan correct answers diye gaye hain. Isliye yeh supervised learning ka example hai.

4Formal notation — residuals and errors

"Stipend" aur "CGPA" har baar bolne ki jagah, hum general notation use karte hain:

  • $y$ = actual output value from the dataset
  • $x$ = input value from the dataset
  • Har data point aise likha jaata hai: $(x_i, y_i)$ where $i = 1, 2, \dots, n$
Prediction at the i-th point$$\hat y_i = m x_i + c$$

Model line usually saare data points se exactly nahi guzregi. Actual value aur predicted value ke beech ke mismatch ko us point par error ya residual kehte hain:

Residual$$e_i = y_i - \hat y_i \qquad\Longrightarrow\qquad \boxed{\,e_i = y_i - (m x_i + c)\,}$$
★ Key Insight

Agar errors chhote hain, model accha hai. Agar errors bade hain, model bura hai. To best model choose karne ke liye, hume $m$ aur $c$ ki aisi values choose karni hain jo errors ko jitna ho sake chhota banayein.

    Sign ka matlab (general rule):
    $e > 0$ ⟹ actual predicted se zyada hai ⟹ model ne under-predict kiya (point line ke upar hai).
    $e < 0$ ⟹ actual predicted se kam hai ⟹ model ne over-predict kiya (point line ke neeche hai).

5Building the loss function — three attempts ⭐

Hum jaante hain hume errors minimize karne hain. Par saare individual errors ko ek single number mein kaise combine karein jo overall model quality measure kare? Us single number ko loss function kehte hain.

Attempt 1: Minimize the Total Signed Error

Attempt 1$$\text{Total Signed Error} = \sum_{i=1}^{n} e_i = \sum_{i=1}^{n}(y_i - \hat y_i)$$

Yeh reasonable lagta hai — jis model ka total error sabse chhota, wo best. Par ek fatal problem hai: positive aur negative errors ek dusre ko cancel kar dete hain!

  3. (c) Why is this total misleading?

    Kyunki yeh error ki magnitude measure hi nahi karta — sirf net balance measure karta hai. Yahan har single point galat hai (koi bhi residual zero nahi hai), phir bhi total 0 aata hai. Ek model jo har point ko 10 units se miss karta hai (half upar, half neeche) aur ek model jo perfectly fit karta hai — dono ka score same 0 aayega. Loss function jo perfect aur terrible mein farak na kar sake, useless hai.

△ Warning — The Cancellation Problem

Errors ka plain sum ek reliable loss function NAHI hai. Zero total ka matlab model accha hai aisa nahi — iska sirf matlab hai ki positive aur negative errors ne ek dusre ko cancel kar diya.

Attempt 2: Use Absolute Error

Attempt 2$$\text{Total Absolute Error} = \sum_{i=1}^{n}|e_i| = \sum_{i=1}^{n}|y_i - mx_i - c|$$

Yeh cancellation problem solve kar deta hai — error positive ho ya negative, $|e|$ hamesha non-negative hai. Line ke upar aur neeche ke errors ab cancel nahi ho sakte.

Lekin OLS method ke liye absolute error ek mathematical difficulty create karta hai:

Derivatives

For $e < 0$:   $\dfrac{d}{de}|e| = -1$
For $e > 0$:   $\dfrac{d}{de}|e| = +1$

The blocker

$e = 0$ par derivative undefined hai kyunki graph mein sharp corner hai. Iska matlab $|e|$ everywhere smoothly differentiable nahi hai — jo clean OLS derivation ko block kar deta hai.

Why absolute error is robust to outliers

Absolute error errors ko linearly penalize karta hai. Agar error double ho, penalty bhi double hoti hai. Error of 1 ko penalty 1 milti hai. Error of 10 ko penalty 10. Bada error zyada penalize hota hai, par disproportionately nahi. Isiliye ek single outlier total loss ko dominate nahi kar sakta.

★ Advanced — MAE ka loss surface kyun problematic hai

MAE loss curve piecewise-linear hoti hai: har residual $e_i = 0$ hone par ek kink aata hai, aur minimum ek flat basin (interval) ho sakta hai — ek unique point nahi. Do parameters mein yeh ek faceted polygonal basin banati hai, smooth bowl nahi. Isiliye MAE regression ko Linear Programming se solve kiya jaata hai, simple calculus se nahi. (MSE ki smooth paraboloid bowl ke bilkul ulta.)

Attempt 3: Use Squared Error ✓

The OLS loss function$$E(m, c) = \sum_{i=1}^{n} e_i^{\,2} = \sum_{i=1}^{n}(y_i - m x_i - c)^2$$

Yeh wahi loss function hai jo Ordinary Least Squares mein use hoti hai. Iske teen important properties hain:

1 · Always non-negative

Squaring sign hata deta hai. No cancellation possible.

2 · Differentiable everywhere

$x^2$ ek smooth parabola hai. Uska derivative $2x$ har point par defined hai, including $x = 0$.

3 · Penalizes large errors quadratically

Bade error ko chhote error se bohot zyada penalty milti hai.

Why squared error is sensitive to outliers

Agar error 1 se 2 ho jaye, squared penalty 1 se 4 ho jaati hai (4× larger). Agar error 10 hai, squared penalty 100 hai. To ek error jo $10\times$ bada hai use $100\times$ badi penalty milti hai. Yehi wajah hai ki outlier points OLS best-fit line ko strongly influence karte hain.

7Visualizing the error surface

Squared error function$$E(m, c) = \sum_{i=1}^{n}(y_i - m x_i - c)^2$$

$(m, c)$ ki har pair ke liye hum $E$ ki ek value calculate kar sakte hain. Ek 3D surface imagine karo:

  • x-axis = $m$ (slope)  ·  y-axis = $c$ (intercept)  ·  z-axis = $E(m,c)$ (total squared error)

Simple linear regression ke liye yeh surface ek convex, bowl-shaped surface hai. Bowl ka bottom global minimum hai — best $(m, c)$ pair.

Minimum par surface dono directions mein flat hai. Calculus mein:

Stationarity conditions$$\frac{\partial E}{\partial c} = 0 \qquad \text{and} \qquad \frac{\partial E}{\partial m} = 0$$

Kyunki surface convex hai, yeh stationary point guaranteed global minimum hai (sirf local nahi). Ab hum formulas derive karte hain.

8Deriving the Intercept $c$ (Equation 1)

Derivation

Full step-by-step derivation of $c = \bar y - m\bar x$

Hum yahan se shuru karte hain:

$$E(m,c) = \sum_{i=1}^{n}\left(y_i - m x_i - c\right)^2$$
  1. Step 1 — Partial derivative w.r.t. $c$ lo aur zero set karo $$\frac{\partial E}{\partial c} = 0$$
  2. Step 2 — Chain rule apply karo $$\frac{\partial E}{\partial c} = \frac{\partial}{\partial c}\left[\sum_{i=1}^{n}(y_i - mx_i - c)^2\right] = \sum_{i=1}^{n}\frac{\partial}{\partial c}(y_i - mx_i - c)^2$$

    Let $r_i = y_i - mx_i - c$. Then

    $$\frac{\partial}{\partial c} r_i^2 = \frac{\partial r_i^2}{\partial r_i}\cdot\frac{\partial r_i}{\partial c} = 2r_i\left(\frac{\partial r_i}{\partial c}\right)$$

    Kyunki $y_i$ aur $mx_i$ dono $c$ ke respect mein constant hain, aur $-c$ ka derivative $-1$ hai:

    $$\frac{\partial r_i}{\partial c} = -1 \qquad\Longrightarrow\qquad \frac{\partial}{\partial c}(y_i - mx_i - c)^2 = -2(y_i - mx_i - c)$$ $$\therefore\quad \frac{\partial E}{\partial c} = \sum_{i=1}^{n}\left[-2(y_i - mx_i - c)\right] = 0$$
  3. Step 3 — Zero ke equal set karo aur dono sides ko $-2$ se divide karo $$\sum_{i=1}^{n}(y_i - mx_i - c) = 0$$
  4. Step 4 — Summation ko separate karo $$\sum_{i=1}^{n}y_i \;-\; m\sum_{i=1}^{n}x_i \;-\; \sum_{i=1}^{n}c \;=\; 0$$
    Why does $\sum c$ become $nc$?

    $c$ ek constant hai — wo $i$ ke saath badalta nahi. Ise khud mein $n$ baar add karne se $\underbrace{c + c + \dots + c}_{n\ \text{times}} = nc$ milta hai. Yeh sabse common derivation mistake hai.

    $$\Longrightarrow\quad \sum_{i=1}^{n}y_i - m\sum_{i=1}^{n}x_i - nc = 0$$
  5. Step 5 — $nc$ isolate karo aur $n$ se divide karo $$nc = \sum_{i=1}^{n}y_i - m\sum_{i=1}^{n}x_i$$ $$c = \left(\frac{1}{n}\sum_{i=1}^{n}y_i\right) - m\left(\frac{1}{n}\sum_{i=1}^{n}x_i\right)$$

    Sample means pehchano:

    $$\bar x = \frac{1}{n}\sum_{i=1}^{n}x_i, \qquad \bar y = \frac{1}{n}\sum_{i=1}^{n}y_i$$

    Substituting:

    $$\bar y - m\bar x - c = 0$$
  6. Step 6 — Solve for $c$
    Equation 1$$\boxed{\,c = \bar y - m\bar x\,}$$
★ Key Insight — beautiful intuition

Best-fit OLS line hamesha point $(\bar x, \bar y)$ se guzarti hai — data ka center (mean)! Isko check karo: $x = \bar x$ par, $\hat y = m\bar x + c = m\bar x + (\bar y - m\bar x) = \bar y$. ✓

9Deriving the Slope $m$ (Equation 2)

Derivation

Full step-by-step derivation of $m$

Ab $c = \bar y - m\bar x$ ko wapas error function mein substitute karte hain:

$$E(m,c) = \sum_{i=1}^{n}(y_i - mx_i - c)^2, \qquad c = \bar y - m\bar x$$ $$E(m) = \sum_{i=1}^{n}\left(y_i - mx_i - \bar y + m\bar x\right)^2$$
  1. Step 1 — Bracket ke andar simplify karo (group karo) $$E(m) = \sum_{i=1}^{n}\Big(\underbrace{(y_i - \bar y)}_{a_i} - m\underbrace{(x_i - \bar x)}_{b_i}\Big)^2$$
  2. Step 2 — Shorthand define karo
    • $a_i = y_i - \bar y$  — deviation of each $y$ from the mean
    • $b_i = x_i - \bar x$  — deviation of each $x$ from the mean
    $$E(m) = \sum_{i=1}^{n}(a_i - m b_i)^2$$
  3. Step 3 — $m$ ke respect mein differentiate karo $$\frac{dE}{dm} = \sum_{i=1}^{n} 2(a_i - m b_i)\cdot\frac{d}{dm}(a_i - m b_i)$$

    Since $\dfrac{d}{dm}(a_i - m b_i) = -b_i$:

    $$\frac{dE}{dm} = \sum_{i=1}^{n} 2(a_i - m b_i)(-b_i) = -2\sum_{i=1}^{n} b_i(a_i - m b_i)$$
  4. Step 4 — Minimum ke liye zero set karo $$-2\sum_{i=1}^{n} b_i(a_i - m b_i) = 0$$

    Dividing by $-2$:

    $$\sum_{i=1}^{n} b_i(a_i - m b_i) = 0$$
  5. Step 5 — Summation expand karo $$\sum_{i=1}^{n} b_i a_i - \sum_{i=1}^{n} m b_i^2 = 0$$

    Since $m$ is constant with respect to $i$:

    $$\sum_{i=1}^{n} b_i a_i - m\sum_{i=1}^{n} b_i^2 = 0$$
  6. Step 6 — Solve for $m$ $$m\sum_{i=1}^{n} b_i^2 = \sum_{i=1}^{n} b_i a_i \qquad\Longrightarrow\qquad m = \frac{\sum_{i=1}^{n} b_i a_i}{\sum_{i=1}^{n} b_i^2}$$
  7. Step 7 — Substitute back $b_i = x_i - \bar x$ and $a_i = y_i - \bar y$
    Equation 2$$\boxed{\;m = \frac{\sum_{i=1}^{n}(x_i - \bar x)(y_i - \bar y)}{\sum_{i=1}^{n}(x_i - \bar x)^2}\;}$$
★ Key Insight — what the formula actually says

Numerator measure karta hai ki $x$ aur $y$ kitna saath-saath vary karte hain (covariance).
Denominator measure karta hai ki $x$ khud kitna vary karta hai (variance).
Slope batata hai ki $y$ kitna badalta hai $x$ ke saath, $x$ ke spread ke liye adjusted. Formally:

$$m = \frac{\frac{1}{n}\sum(x_i-\bar x)(y_i-\bar y)}{\frac1n\sum(x_i-\bar x)^2} = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)}$$
△ When does this break?

Yeh formula assume karta hai ki denominator zero nahi hai. Agar har student ka CGPA bilkul same hota, to $x_i = \bar x$ har $i$ ke liye, to $\sum(x_i-\bar x)^2 = 0$ — koi variation nahi, koi meaningful slope nahi, $m$ undefined.

    Taaki two-variable minimization ek single-variable problem ban jaye — $c$ ko $m$ ke terms mein express karne se $E$ sirf $m$ ka function ban jaata hai, jise simple ordinary derivative se solve kar sakte hain.

  2. (b) Compute $\dfrac{d}{dm}(a_i - m b_i)^2$

10The Final OLS Model

The two OLS formulas $$m = \frac{\sum_{i=1}^{n}(x_i-\bar x)(y_i-\bar y)}{\sum_{i=1}^{n}(x_i-\bar x)^2} \qquad\qquad c = \bar y - m\bar x$$

The procedure:

  • Step 1: Compute $m$ using Equation 2.
  • Step 2: Substitute $m$ into Equation 1 to compute $c$.
  • Step 3: Write the final model: $\hat y = mx + c$

Yeh OLS best-fit line hai. "Best-fit" phrase ka matlab precisely yeh hai: wo line jo total squared error minimize karti hai.

Outlier Impact Analysis

Dataset mein 6th student add karo: $(x = 10,\; y = 20)$. Yeh student ne 10 hours padha par sirf 20 score kiya — ek clear outlier.

  1. (a) Under absolute error, the penalty for this point is $|e| = |20 - (m\times10 + c)|$. How does this grow?
    Linearly with the error.

    Pichle model $\hat y = 6.75x + 19.25$ se: $\hat y = 6.75(10)+19.25 = 86.75$, to $e = 20 - 86.75 = -66.75$, aur $|e| = \mathbf{66.75}$.

  2. (b) Under squared error, the penalty is $e^2 = (20-\hat y)^2$. How does this grow?
    Quadratically with the error.

    $e^2 = (66.75)^2 = \mathbf{4455.6}$ — baaki saare points ke combined squared error se kahin zyada.

  3. (c) Which loss function will be more affected by this outlier? Why?
    Squared error (OLS).

    Kyunki $e^2$ error ke saath quadratically grow karta hai, is ek point ka contribution total loss ko dominate kar deta hai. Loss minimize karne ke liye optimizer ko is point ke error ko shrink karna hi padega, chahe baaki paanch points ka fit kharab ho jaye.

  4. (d) Will the OLS best-fit line shift toward this outlier or away from it?
    Toward the outlier.

    Optimizer $\sum e^2$ minimize kar raha hai. Us huge squared term ko kam karne ka sabse effective tareeka hai line ko outlier ki taraf tilt/drop karna. Practically: slope $m$ ghategi (kyunki outlier high $x$ par low $y$ hai), aur line 6 points ke beech mein ek compromise position le legi — saare predictions kharab karke.

⚠ Common Mistakes

GaltiSahi Baat
$\sum_{i=1}^{n} c = c$$\sum_{i=1}^{n} c = \mathbf{nc}$ — yeh derivation ki #1 mistake hai.
Slope formula mein numerator aur denominator ulta karnaNumerator = $\sum(x_i-\bar x)(y_i-\bar y)$ (covariance). Denominator = $\sum(x_i-\bar x)^2$ (variance of $x$ only).
"Squared error outliers ke liye robust hai"Absolute error robust hai. Squared error outliers ke prati sensitive hai.
"Error 10× bada to penalty 10× badi"Squared error mein penalty 100× badi hoti hai.
"OLS line har data point se guzarti hai"Sirf perfectly collinear data mein. Generally residuals nonzero.
Residual ko $\hat y - y$ likhnaConvention: $e_i = y_i - \hat y_i$ (actual minus predicted). Sign matter karta hai.
OLS ko iterative samajhnaOLS closed-form hai — ek formula, ek shot mein answer.
Denominator zero hone ka case bhool jaanaAgar saare $x_i$ same hain, $m$ undefined hai.

⚡ Quick Revision

Model

$\hat y_i = m x_i + c$

Residual

$e_i = y_i - \hat y_i = y_i - (mx_i + c)$

Loss

$E(m,c) = \sum(y_i - mx_i - c)^2$

Slope

$m = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2} = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)}$

Intercept

$c = \bar y - m\bar x$

3 loss attempts

Signed (cancels) → Absolute (non-differentiable at 0) → Squared ✓

Squared error's 3 properties

Non-negative · Differentiable everywhere · Quadratic penalty

Stationarity

$\frac{\partial E}{\partial m}=0$ and $\frac{\partial E}{\partial c}=0$; surface is convex ⟹ global min.
