Simple Linear Regression using the OLS Method

From scatter plots to the best-fit line — the full Ordinary Least Squares derivation, without skipping a single step.

⏱ ~35 min📐 Full derivation 🧮 5 solved numericals✓ 10 MCQs
⚡ Ek Line Mein

Infinitely many lines are possible. We pick the one that minimises total squared error. Why squared? Because signed error cancels out, and absolute error isn't differentiable at $e=0$. Squared error is non-negative + smooth + convex — so calculus hands us an exact closed-form answer:
$m = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}$ and $c = \bar y - m\bar x$.

1The Storyline — from data to a prediction question

▷ Hook

Suppose I have a dataset of NST students. I know both their CGPA and the internship stipend they received. If a new student tells me their CGPA, can I predict their stipend?

StudentCGPA ($x$)Stipend ₹k ($y$)
A8.050
B9.075
C7.045
D7.540
E6.030

Since the data shows a linear trend, we try to capture the relationship with a straight-line model:

Straight-line model$$\hat y = m(\text{CGPA}) + c$$
  • $\hat y$ (y-hat) = predicted output (predicted stipend)
  • $x$ = input variable (CGPA of the student)
  • $m$ = the slope — how steeply the stipend changes with CGPA
  • $c$ = intercept — predicted stipend jab CGPA $= 0$

In this dataset we know both the input values (CGPA) and the corresponding output values (stipend). We are learning from examples where the correct answers are given. That makes this an example of supervised learning.

2Infinite candidate models — which line is best?

Now comes the critical realisation. The model $\hat y = m(\text{CGPA}) + c$ has 2 adjustable numbers: $m$ and $c$. Different students could pick different values:

StudentChosen $m$Chosen $c$Model
Student 110−30$\hat y = 10x - 30$
Student 212−40$\hat y = 12x - 40$
Student 38−10$\hat y = 8x - 10$
  • Changing $m$ changes the line's slope / tilt.
  • Changing $c$ shifts the line up or down.
  • By changing just these two numbers we can generate infinitely many different straight lines.
★ Key Insight — the engineering problem

Out of infinitely many possible straight lines, which one do I choose? We need an objective, mathematical criterion — not a visual guess.

4Formal notation — residuals and errors

Instead of saying "stipend" and "CGPA" every time, we switch to general notation:

  • $y$ = actual output value from the dataset
  • $x$ = input value from the dataset
  • Each data point is written as $(x_i, y_i)$ where $i = 1, 2, \dots, n$
Prediction at the i-th point$$\hat y_i = m x_i + c$$

The model line usually will not pass exactly through every data point. The mismatch between the actual value and the predicted value at a point is called the error or residual at that point:

Residual$$e_i = y_i - \hat y_i \qquad\Longrightarrow\qquad \boxed{\,e_i = y_i - (m x_i + c)\,}$$
★ Key Insight

Small errors mean a good model. Large errors mean a bad one. So to choose the best model, we need values of $m$ and $c$ that make the errors as small as possible.

    What the sign means (general rule):
    $e > 0$ ⟹ actual is greater than predicted ⟹ the model under-predicted (the point is above the line).
    $e < 0$ ⟹ actual is less than predicted ⟹ the model over-predicted (the point is below the line).

5Building the loss function — three attempts ⭐

We know we need to minimise the errors. But how do we combine all the individual errors into a single number that measures overall model quality? That single number is called the loss function.

Attempt 1: Minimize the Total Signed Error

Attempt 1$$\text{Total Signed Error} = \sum_{i=1}^{n} e_i = \sum_{i=1}^{n}(y_i - \hat y_i)$$

This looks reasonable — the model with the smallest total error wins. But there is a fatal problem: positive and negative errors cancel each other out!

The Cancellation Trap

Point123456
Error $e_i$+10+5+4−10−3−6
  1. (a) Compute the total signed error $$\sum e_i = 10 + 5 + 4 + (-10) + (-3) + (-6) = 19 - 19 = \mathbf{0}$$
  2. (b) A total signed error of 0 means the model is perfect. [T/F]
    False
  3. (c) Why is this total misleading?

    Because it doesn't measure the magnitude of the error at all — only the net balance. Here every single point is wrong (no residual is zero), yet the total comes to 0. A model that misses every point by 10 units (half above, half below) and a model that fits perfectly would both score 0. A loss function that cannot tell perfect from terrible is useless.

△ Warning — The Cancellation Problem

A plain sum of errors is NOT a reliable loss function. A zero total doesn't mean the model is good — it only means the positive and negative errors cancelled.

Attempt 2: Use Absolute Error

Attempt 2$$\text{Total Absolute Error} = \sum_{i=1}^{n}|e_i| = \sum_{i=1}^{n}|y_i - mx_i - c|$$

This solves the cancellation problem — whether the error is positive or negative, $|e|$ is always non-negative. Errors above and below the line can no longer cancel.

But for the OLS method, absolute error creates a mathematical difficulty:

Derivatives

For $e < 0$:   $\dfrac{d}{de}|e| = -1$
For $e > 0$:   $\dfrac{d}{de}|e| = +1$

The blocker

At $e = 0$ the derivative is undefined, because the graph has a sharp corner there. That means $|e|$ is not smoothly differentiable everywhere — which blocks the clean OLS derivation.

Why absolute error is robust to outliers

Absolute error penalises errors linearly. Double the error, double the penalty. An error of 1 gets a penalty of 1. An error of 10 gets a penalty of 10. Bigger errors are penalised more, but not disproportionately. That is why a single outlier cannot dominate the total loss.

★ Advanced — why MAE's loss surface is problematic

The MAE loss curve is piecewise-linear: there's a kink wherever a residual $e_i = 0$, and the minimum can be a flat basin (an interval) rather than a unique point. In two parameters this becomes a faceted polygonal basin, not a smooth bowl. That is why MAE regression is solved with Linear Programming rather than simple calculus — the exact opposite of MSE's smooth paraboloid bowl.

Attempt 3: Use Squared Error ✓

The OLS loss function$$E(m, c) = \sum_{i=1}^{n} e_i^{\,2} = \sum_{i=1}^{n}(y_i - m x_i - c)^2$$

This is exactly the loss function used in Ordinary Least Squares. It has three important properties:

1 · Always non-negative

Squaring removes the sign. No cancellation possible.

2 · Differentiable everywhere

$x^2$ is a smooth parabola. Its derivative $2x$ is defined at every point, including $x = 0$.

3 · Penalizes large errors quadratically

A large error gets a far bigger penalty than a small one.

Why squared error is sensitive to outliers

If the error goes from 1 to 2, the squared penalty goes from 1 to 4 (4× larger). If the error is 10, the squared penalty is 100. So an error that is $10\times$ bigger gets a $100\times$ bigger penalty. That is why outlier points strongly influence the OLS best-fit line.

7Visualizing the error surface

Squared error function$$E(m, c) = \sum_{i=1}^{n}(y_i - m x_i - c)^2$$

For every pair $(m, c)$ we can compute a value of $E$. Picture a 3D surface:

  • x-axis = $m$ (slope)  ·  y-axis = $c$ (intercept)  ·  z-axis = $E(m,c)$ (total squared error)

For simple linear regression this surface is a convex, bowl-shaped surface. The bottom of the bowl is the global minimum — the best $(m, c)$ pair.

At the minimum the surface is flat in both directions. In calculus terms:

Stationarity conditions$$\frac{\partial E}{\partial c} = 0 \qquad \text{and} \qquad \frac{\partial E}{\partial m} = 0$$

Because the surface is convex, this stationary point is guaranteed to be the global minimum (not merely a local one). Now we derive the formulas.

8Deriving the Intercept $c$ (Equation 1)

Derivation

Full step-by-step derivation of $c = \bar y - m\bar x$

We start from here:

$$E(m,c) = \sum_{i=1}^{n}\left(y_i - m x_i - c\right)^2$$
  1. Step 1 — take the partial derivative w.r.t. $c$ and set it to zero $$\frac{\partial E}{\partial c} = 0$$
  2. Step 2 — apply the chain rule $$\frac{\partial E}{\partial c} = \frac{\partial}{\partial c}\left[\sum_{i=1}^{n}(y_i - mx_i - c)^2\right] = \sum_{i=1}^{n}\frac{\partial}{\partial c}(y_i - mx_i - c)^2$$

    Let $r_i = y_i - mx_i - c$. Then

    $$\frac{\partial}{\partial c} r_i^2 = \frac{\partial r_i^2}{\partial r_i}\cdot\frac{\partial r_i}{\partial c} = 2r_i\left(\frac{\partial r_i}{\partial c}\right)$$

    Since $y_i$ and $mx_i$ are both constant with respect to $c$, and the derivative of $-c$ is $-1$:

    $$\frac{\partial r_i}{\partial c} = -1 \qquad\Longrightarrow\qquad \frac{\partial}{\partial c}(y_i - mx_i - c)^2 = -2(y_i - mx_i - c)$$ $$\therefore\quad \frac{\partial E}{\partial c} = \sum_{i=1}^{n}\left[-2(y_i - mx_i - c)\right] = 0$$
  3. Step 3 — Set it equal to zero and divide both sides by $-2$ $$\sum_{i=1}^{n}(y_i - mx_i - c) = 0$$
  4. Step 4 — separate the summation $$\sum_{i=1}^{n}y_i \;-\; m\sum_{i=1}^{n}x_i \;-\; \sum_{i=1}^{n}c \;=\; 0$$
    Why does $\sum c$ become $nc$?

    $c$ is a constant — it doesn't change with $i$. Adding it to itself $n$ times gives $\underbrace{c + c + \dots + c}_{n\ \text{times}} = nc$. This is the single most common derivation mistake.

    $$\Longrightarrow\quad \sum_{i=1}^{n}y_i - m\sum_{i=1}^{n}x_i - nc = 0$$
  5. Step 5 — Isolate $nc$ and divide by $n$ $$nc = \sum_{i=1}^{n}y_i - m\sum_{i=1}^{n}x_i$$ $$c = \left(\frac{1}{n}\sum_{i=1}^{n}y_i\right) - m\left(\frac{1}{n}\sum_{i=1}^{n}x_i\right)$$

    Sample means pehchano:

    $$\bar x = \frac{1}{n}\sum_{i=1}^{n}x_i, \qquad \bar y = \frac{1}{n}\sum_{i=1}^{n}y_i$$

    Substituting:

    $$\bar y - m\bar x - c = 0$$
  6. Step 6 — Solve for $c$
    Equation 1$$\boxed{\,c = \bar y - m\bar x\,}$$
★ Key Insight — beautiful intuition

The best-fit OLS line always passes through the point $(\bar x, \bar y)$ — the centre (mean) of the data! Check it: at $x = \bar x$, $\hat y = m\bar x + c = m\bar x + (\bar y - m\bar x) = \bar y$. ✓

9Deriving the Slope $m$ (Equation 2)

Derivation

Full step-by-step derivation of $m$

Now we substitute $c = \bar y - m\bar x$ back into the error function:

$$E(m,c) = \sum_{i=1}^{n}(y_i - mx_i - c)^2, \qquad c = \bar y - m\bar x$$ $$E(m) = \sum_{i=1}^{n}\left(y_i - mx_i - \bar y + m\bar x\right)^2$$
  1. Step 1 — Simplify inside the bracket (group the terms) $$E(m) = \sum_{i=1}^{n}\Big(\underbrace{(y_i - \bar y)}_{a_i} - m\underbrace{(x_i - \bar x)}_{b_i}\Big)^2$$
  2. Step 2 — define the shorthand
    • $a_i = y_i - \bar y$  — deviation of each $y$ from the mean
    • $b_i = x_i - \bar x$  — deviation of each $x$ from the mean
    $$E(m) = \sum_{i=1}^{n}(a_i - m b_i)^2$$
  3. Step 3 — Differentiate with respect to $m$ $$\frac{dE}{dm} = \sum_{i=1}^{n} 2(a_i - m b_i)\cdot\frac{d}{dm}(a_i - m b_i)$$

    Since $\dfrac{d}{dm}(a_i - m b_i) = -b_i$:

    $$\frac{dE}{dm} = \sum_{i=1}^{n} 2(a_i - m b_i)(-b_i) = -2\sum_{i=1}^{n} b_i(a_i - m b_i)$$
  4. Step 4 — Set it to zero for the minimum $$-2\sum_{i=1}^{n} b_i(a_i - m b_i) = 0$$

    Dividing by $-2$:

    $$\sum_{i=1}^{n} b_i(a_i - m b_i) = 0$$
  5. Step 5 — expand the summation $$\sum_{i=1}^{n} b_i a_i - \sum_{i=1}^{n} m b_i^2 = 0$$

    Since $m$ is constant with respect to $i$:

    $$\sum_{i=1}^{n} b_i a_i - m\sum_{i=1}^{n} b_i^2 = 0$$
  6. Step 6 — Solve for $m$ $$m\sum_{i=1}^{n} b_i^2 = \sum_{i=1}^{n} b_i a_i \qquad\Longrightarrow\qquad m = \frac{\sum_{i=1}^{n} b_i a_i}{\sum_{i=1}^{n} b_i^2}$$
  7. Step 7 — Substitute back $b_i = x_i - \bar x$ and $a_i = y_i - \bar y$
    Equation 2$$\boxed{\;m = \frac{\sum_{i=1}^{n}(x_i - \bar x)(y_i - \bar y)}{\sum_{i=1}^{n}(x_i - \bar x)^2}\;}$$
★ Key Insight — what the formula actually says

The numerator measures how much $x$ and $y$ vary together (covariance).
The denominator measures how much $x$ varies on its own (variance).
So the slope tells you how much $y$ changes with $x$, adjusted for the spread of $x$. Formally:

$$m = \frac{\frac{1}{n}\sum(x_i-\bar x)(y_i-\bar y)}{\frac1n\sum(x_i-\bar x)^2} = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)}$$
△ When does this break?

This formula assumes the denominator is not zero. If every student had exactly the same CGPA, then $x_i = \bar x$ for every $i$, so $\sum(x_i-\bar x)^2 = 0$ — no variation, no meaningful slope, and $m$ is undefined.

Derivation fill-in

  1. (a) Why is the intercept $c$ substituted before optimizing the slope?

    So that a two-variable minimisation becomes a single-variable problem — expressing $c$ in terms of $m$ makes $E$ a function of $m$ alone, which an ordinary derivative can solve.

  2. (b) Compute $\dfrac{d}{dm}(a_i - m b_i)^2$
    $= 2(a_i - m b_i)\cdot(-b_i) = -2b_i(a_i - m b_i)$
  3. (c) Starting from $\sum b_i(a_i - mb_i) = 0$, derive the expression for $m$
    $\sum b_i a_i = m\sum b_i^2 \;\Rightarrow\; m = \dfrac{\sum b_i a_i}{\sum b_i^2}$
  4. (d) What does the denominator $\sum(x_i - \bar x)^2$ represent?
    B — Variance of $x$ (technically $n \times$ variance, i.e. the total sum of squares of $x$)
  5. (e) Why would the slope be undefined if every $x_i$ has the same value?

    Because then $x_i - \bar x = 0$ for every $i$, so the denominator $\sum(x_i-\bar x)^2 = 0$, and division by zero is undefined. Geometrically: all the points sit on a vertical line — which has no slope at all.

10The Final OLS Model

The two OLS formulas $$m = \frac{\sum_{i=1}^{n}(x_i-\bar x)(y_i-\bar y)}{\sum_{i=1}^{n}(x_i-\bar x)^2} \qquad\qquad c = \bar y - m\bar x$$

The procedure:

  • Step 1: Compute $m$ using Equation 2.
  • Step 2: Substitute $m$ into Equation 1 to compute $c$.
  • Step 3: Write the final model: $\hat y = mx + c$

This is the OLS best-fit line. The phrase "best-fit" means precisely this: the line that minimises total squared error.

Practice P12

Outlier Impact Analysis

Add a 6th student to the dataset: $(x = 10,\; y = 20)$. This student studied 10 hours but scored only 20 — a clear outlier.

  1. (a) Under absolute error, the penalty for this point is $|e| = |20 - (m\times10 + c)|$. How does this grow?
    Linearly with the error.

    From the earlier model $\hat y = 6.75x + 19.25$: $\hat y = 6.75(10)+19.25 = 86.75$, so $e = 20 - 86.75 = -66.75$, and $|e| = \mathbf{66.75}$.

  2. (b) Under squared error, the penalty is $e^2 = (20-\hat y)^2$. How does this grow?
    Quadratically with the error.

    $e^2 = (66.75)^2 = \mathbf{4455.6}$ — far more than the combined squared error of all the other points.

  3. (c) Which loss function will be more affected by this outlier? Why?
    Squared error (OLS).

    Because $e^2$ grows quadratically with the error, this one point's contribution dominates the total loss. To minimise the loss, the optimiser has to shrink this point's error — even if the fit for the other five points gets worse.

  4. (d) Will the OLS best-fit line shift toward this outlier or away from it?
    Toward the outlier.

    The optimiser is minimising $\sum e^2$. The most effective way to shrink that huge squared term is to tilt/drop the line towards the outlier. Practically: the slope $m$ will decrease (the outlier sits at high $x$ with low $y$), and the line settles into a compromise position among the 6 points — making every prediction worse.

⚡ Quick Revision

Model

$\hat y_i = m x_i + c$

Residual

$e_i = y_i - \hat y_i = y_i - (mx_i + c)$

Loss

$E(m,c) = \sum(y_i - mx_i - c)^2$

Slope

$m = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2} = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)}$

Intercept

$c = \bar y - m\bar x$

Non-negative · Differentiable everywhere · Quadratic penalty

Stationarity

$\frac{\partial E}{\partial m}=0$ and $\frac{\partial E}{\partial c}=0$; surface is convex ⟹ global min.
