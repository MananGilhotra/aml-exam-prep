L3Simple Linear Regression (OLS)

Model & residual$$\hat y_i = mx_i + c \qquad\qquad e_i = y_i - \hat y_i = y_i - (mx_i + c)$$
Loss function$$E(m,c) = \sum_{i=1}^{n}e_i^2 = \sum_{i=1}^{n}(y_i - mx_i - c)^2$$
Closed-form OLS solution ⭐ $$\boxed{\;m = \frac{\sum_{i=1}^{n}(x_i - \bar x)(y_i - \bar y)}{\sum_{i=1}^{n}(x_i - \bar x)^2} = \frac{\operatorname{Cov}(X,Y)}{\operatorname{Var}(X)}\;}$$ $$\boxed{\;c = \bar y - m\bar x\;}$$
Remember

Compute $m$ first, then $c$. The OLS line always passes through $(\bar x, \bar y)$. Undefined when $\sum(x_i - \bar x)^2 = 0$.

Stationarity conditions$$\frac{\partial E}{\partial m} = 0 \qquad \frac{\partial E}{\partial c} = 0 \qquad (\text{surface is convex} \Rightarrow \text{global minimum})$$
Loss attemptFormulaProblem
Signed$\sum e_i$Cancellation
Absolute$\sum|e_i|$Not differentiable at $e=0$
Squared ✓$\sum e_i^2$Sensitive to outliers

L4Multiple Linear Regression (Matrix OLS)

Model$$\hat y = \beta_0 + \beta_1x_1 + \cdots + \beta_mx_m \qquad\Longleftrightarrow\qquad \hat{\mathbf y} = \mathbf X\boldsymbol\beta$$
ObjectDimensions
$\mathbf X$ (design matrix, 1s column first)$n \times (m+1)$
$\boldsymbol\beta$ (parameter vector)$(m+1) \times 1$
$\hat{\mathbf y}$ (predictions)$n \times 1$
$\mathbf X^\top\mathbf X$$(m+1) \times (m+1)$
Loss (compact and expanded) $$L(\boldsymbol\beta) = \mathbf e^\top\mathbf e = (\mathbf y - \mathbf X\boldsymbol\beta)^\top(\mathbf y - \mathbf X\boldsymbol\beta)$$ $$L(\boldsymbol\beta) = \mathbf y^\top\mathbf y - 2\,\mathbf y^\top\mathbf X\boldsymbol\beta + \boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta$$
Three matrix-calculus identities ⭐ $$\frac{\partial(c)}{\partial\boldsymbol\beta} = \mathbf 0 \qquad\qquad \frac{\partial(\mathbf a^\top\boldsymbol\beta)}{\partial\boldsymbol\beta} = \mathbf a \qquad\qquad \frac{\partial(\boldsymbol\beta^\top\mathbf A\boldsymbol\beta)}{\partial\boldsymbol\beta} = 2\mathbf A\boldsymbol\beta \;\;(\mathbf A \text{ symmetric})$$
Normal Equation & solution ⭐ $$\boxed{\;\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf X^\top\mathbf y\;} \qquad\qquad \boxed{\;\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y\;}$$
Conditions & cost

Works only if $\det(\mathbf X^\top\mathbf X) \ne 0$ (no perfect multicollinearity). Inversion of a $k\times k$ matrix costs $O(k^3)$ — from three nested Gauss–Jordan loops: $k \times k \times 2k = 2k^3$.

L5–L6Gradient Descent Family

Generic update rule$$\boldsymbol\theta_{\text{new}} = \boldsymbol\theta_{\text{old}} - \alpha\,\nabla L(\boldsymbol\theta_{\text{old}})$$
MSE gradient & Batch GD update ⭐ $$\nabla L = \frac{2}{m}\,\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y) \qquad\Longrightarrow\qquad \boldsymbol\theta := \boldsymbol\theta - \alpha\frac{2}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)$$
Convention alert

If the loss is defined as $L = \frac{1}{2m}\|\mathbf X\boldsymbol\theta - \mathbf y\|_2^2$, the factor 2 disappears: $\nabla L = \frac{1}{m}\mathbf X^\top(\mathbf X\boldsymbol\theta - \mathbf y)$. Check the question's convention.

Per-sample gradient (SGD, linear regression with $J_i = \frac12 e_i^2$) $$\nabla J_i(\boldsymbol\theta) = \begin{bmatrix}e_i\\ e_i x_i\end{bmatrix}, \qquad e_i = \hat y_i - y_i$$
Stochastic update$$i_t \sim \text{Uniform}\{1,\dots,m\}, \qquad \boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \alpha\nabla J_{i_t}(\boldsymbol\theta_t)$$
MethodSamples / updateUpdates / epochCost / updateNoise

L7Evaluation Metrics — Regression

MetricFormulaUnitsKey property
MAE$\dfrac{1}{n}\sum_{i=1}^{n}|e_i|$target unitsEqual linear weight per unit
MAPE$\dfrac{100}{n}\sum_{i=1}^{n}\left|\dfrac{e_i}{y_i}\right|$%Undefined at $y_i = 0$
MSE$\dfrac{1}{n}\sum_{i=1}^{n}e_i^2$squared unitsPenalises large errors
RMSE$\sqrt{\text{MSE}}$target unitsLarge-error penalty, readable units
$R^2$$1 - \dfrac{\text{RSS}}{\text{TSS}} = \dfrac{\text{TSS} - \text{RSS}}{\text{TSS}}$unitlessRelative to the mean-only baseline
Adjusted $R^2$$1 - (1-R^2)\dfrac{n-1}{n-p-1}$unitlessCharges for extra predictors
The two sums of squares$$\text{TSS} = \sum_{i=1}^{n}(y_i - \bar y)^2 \qquad\qquad \text{RSS} = \sum_{i=1}^{n}(y_i - \hat y_i)^2$$
Traps
  • $R^2 = 0.93$ is NOT 93% accuracy. It is a sum-of-squares comparison with the mean baseline.
  • MSE is in squared units. The typical miss is RMSE, not MSE.
  • In Adjusted $R^2$, $p$ excludes the intercept. Requires $n > p+1$.
  • Use $1 - R^2 = \text{RSS}/\text{TSS}$ to avoid carrying rounded $R^2$ values.

L7Evaluation Metrics — Classification

$$\text{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN} = \frac{\text{diagonal}}{\text{total}}$$ $$\text{Precision} = \frac{TP}{TP+FP} \qquad\qquad \text{Recall (TPR)} = \frac{TP}{TP+FN}$$ $$F1 = \frac{2\,\text{Prec}\cdot\text{Rec}}{\text{Prec}+\text{Rec}} = \frac{2TP}{2TP+FP+FN}$$
Denominator memory hook

Precision uses Predicted positives ($TP+FP$). Recall uses Real (actual) positives ($TP+FN$). F1 never uses TN.

Aggregation across classes $$\text{Macro}(M) = \frac{1}{C}\sum_{c=1}^{C}M_c \qquad\qquad \text{Weighted}(M) = \frac{\sum_c n_c M_c}{\sum_c n_c}$$ $$\text{Micro}: \text{pool } TP, FP, FN \text{ first, then apply the formulas}$$

In single-label multiclass, micro precision $=$ micro recall $=$ micro F1 $=$ accuracy. Macro F1 is the arithmetic mean of class F1s — not the harmonic mean of macro-P and macro-R.

L9Bias–Variance

Data model & definitions $$Y = f(X) + \varepsilon$$ $$\text{Bias}(x) = E[\hat f(x)] - f(x) \qquad\qquad \text{Variance}(x) = E\!\left[\left(\hat f(x) - E[\hat f(x)]\right)^2\right]$$
The decomposition ⭐$$\boxed{\;\text{MSE} = \text{Bias}^2 + \text{Variance} + \operatorname{Var}(\varepsilon)\;}$$
ModelBiasVarianceSymptom (train vs val error)
Too simpleHighLowBoth high and close → underfit
SuitableMod/lowMod/lowVal error low, gap reasonable
Too flexibleLowHighTrain low, val much higher → overfit

More data helps only for high variance. Split: 60% train / 20% validation / 20% test.

L10Feature Selection

Variance filter$$\operatorname{Var}(f_j) = \frac1n\sum_{i=1}^{n}(x_{ij} - \bar x_j)^2; \qquad \text{remove if } \operatorname{Var}(f_j) < \tau$$
Pearson correlation filter$$r_{jY} = \frac{\sum_i(x_{ij}-\bar x_j)(y_i-\bar y)}{\sqrt{\sum_i(x_{ij}-\bar x_j)^2 \;\sum_i(y_i-\bar y)^2}}; \qquad \text{remove if } |r_{jY}| < 0.30$$

L11PCA

Step 1 — Centering (always) & standardization (conditional) $$X_c = X - \mathbf 1\boldsymbol\mu^\top \qquad\qquad z_{ij} = \frac{x_{ij}-\mu_j}{s_j}, \quad s_j = \sqrt{\frac{1}{n-1}\sum_i(x_{ij}-\mu_j)^2}$$
Step 2 — Covariance matrix $$S = \frac{1}{n-1}X_c^\top X_c \quad (p\times p) \qquad\qquad \operatorname{Cov}(x,y) = \frac{1}{n-1}\sum_i(x_i-\bar x)(y_i-\bar y)$$
Step 3 — Eigen-decomposition$$S\mathbf v = \lambda\mathbf v \qquad\Longleftrightarrow\qquad |S - \lambda I| = 0$$
Step 4 — Projection $$z_i = \mathbf u^\top\mathbf x_i \qquad\qquad Z = X_cW_k, \quad W_k \text{ is } p\times k, \quad Z \text{ is } n\times k$$
Step 5 — Explained variance $$\text{total variance} = \sum_{j=1}^{p}\lambda_j = \operatorname{trace}(S)$$ $$\text{EVR of PC}_j = \frac{\lambda_j}{\sum_\ell\lambda_\ell} \qquad\qquad \text{cumulative EVR through } k = \frac{\sum_{j=1}^{k}\lambda_j}{\sum_\ell\lambda_\ell}$$
Applying to test data (never refit!)$$Z_{\text{test}} = \left(X_{\text{test}} - \mathbf 1_{\text{test}}\boldsymbol\mu_{\text{tr}}^\top\right)W_k$$
Variance–reconstruction equivalence $$\|\mathbf x_i\|^2 = z_i^2 + \|\mathbf e_i\|^2 \qquad\Longrightarrow\qquad \max_{\|\mathbf u\|=1}\operatorname{Var}(\mathbf z) \iff \min_{\|\mathbf u\|=1}\sum_i\|\mathbf e_i\|^2$$
PCA fails when

(1) Data is isotropic/circular ($\lambda_1 \approx \lambda_2$) · (2) Classes are symmetric about PC₁ (projection merges them) · (3) Structure is nonlinear (linear PCA cannot unroll manifolds).
