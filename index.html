How to use this handbook

First pass · to learn it

Read in order, starting from Lecture 0. On each page follow Hook → Concept → Diagram → Solved Numerical → MCQs. Don't skip the MCQs — that's where the actual exam difficulty sits.

Second pass · to revise it

Read only the ⚡ Quick Revision and ⚠ Common Mistakes sections of each page, plus the Formula Sheet. Then attempt the Mock Test.

The day before the exam

Quick Revision page → Formula Sheet → Mock Test. Whatever you get wrong, re-read just the Common Mistakes of those lectures.

Pro tips

Top-right icons: ◐ light/dark theme, ⎙ print / save-as-PDF (MCQ explanations auto-expand when printing). On mobile, ☰ opens the menu.
