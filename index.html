How to use this handbook

First pass · seekhne ke liye

Lecture 0 se order mein padho. Har page par Hook → Concept → Diagram → Solved Numerical → MCQs follow karo. MCQs ko skip mat karna — wahi actual exam difficulty hai.

Second pass · revision ke liye

Sirf har page ke ⚡ Quick Revision aur ⚠ Common Mistakes sections padho + Formula Sheet. Phir Mock Test attempt karo.

Exam se 1 din pehle

Quick Revision page → Formula Sheet → Mock Test. Jo galat ho, sirf un lectures ke Common Mistakes dobara padho.

Pro tips
