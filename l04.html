Worksheet 04 · Lecture 4

Multiple Linear Regression using OLS

Ek feature se $m$ features tak. Wahi principle — minimize squared error — par ab matrices aur vectors ke saath.

⏱ ~38 min📐 Matrix calculus 🧮 6 solved numericals✓ 10 MCQs
⚡ Ek Line Mein

Saari $n$ prediction equations ko ek line mein pack karo: $\hat{\mathbf y} = \mathbf X\boldsymbol\beta$. Loss ban jaati hai $L(\boldsymbol\beta) = \mathbf e^\top\mathbf e$. Use expand karo, 3 matrix-calculus identities lagao, gradient zero set karo — aur Normal Equation nikal aati hai: $\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf X^\top\mathbf y$, jiska solution $\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$ hai. Catch: inverse ko exist karna padega (no multicollinearity) aur uski cost $O(m^3)$ hai.

Lecture 3 mein akela CGPA stipend predict karta tha. Par agar IQ, attendance aur project scores bhi matter karte hon? Ek feature kaafi nahi — hume bohot chahiye.

$X_1$$X_2$$X_3$$\cdots$$X_m$$Y$$\hat Y$
$x_{11}$$x_{12}$$x_{13}$$\cdots$$x_{1m}$$y_1$$\hat y_1$
$x_{21}$$x_{22}$$x_{23}$$\cdots$$x_{2m}$$y_2$$\hat y_2$

Yeh $m$ dimensions mein ek hyperplane ka equation hai. Yeh abhi bhi ek linear equation hai — sirf input variables ki sankhya 1 se $m$ ho gayi hai.

2Writing the prediction equation for each data point

▷ Hook

Humare paas ek equation template hai — par $n$ data points. Har single row ke liye prediction kaise likhein?

For the 1st data point:   $\hat y_1 = \beta_0 + \beta_1 x_{11} + \beta_2 x_{12} + \cdots + \beta_m x_{1m}$

For the 2nd data point:   $\hat y_2 = \beta_0 + \beta_1 x_{21} + \beta_2 x_{22} + \cdots + \beta_m x_{2m}$

For the $i$-th data point:   $\hat y_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \cdots + \beta_m x_{im}$

Saari predicted values ko ek vector ki tarah likhte hain:

$$\hat{\mathbf y} = \begin{bmatrix}\hat y_1\\ \hat y_2\\ \vdots\\ \hat y_n\end{bmatrix} = \begin{bmatrix}\beta_0 + \beta_1x_{11} + \cdots + \beta_mx_{1m}\\ \beta_0 + \beta_1x_{21} + \cdots + \beta_mx_{2m}\\ \vdots\\ \beta_0 + \beta_1x_{n1} + \cdots + \beta_mx_{nm}\end{bmatrix}$$
★ Key Insight

Har predicted value ke paas same parameters $(\beta_0, \beta_1, \dots, \beta_m)$ hote hain, par feature values row se row badalti hain.

3Converting the prediction equations into matrix form ⭐

▷ Hook

$n$ alag equations likhna tedious hai. Kya hum sab ko ek single matrix equation mein pack kar sakte hain?

$$\hat{\mathbf y} = \begin{bmatrix}1 & x_{11} & x_{12} & \cdots & x_{1m}\\ 1 & x_{21} & x_{22} & \cdots & x_{2m}\\ \vdots & \vdots & \vdots & \ddots & \vdots\\ 1 & x_{n1} & x_{n2} & \cdots & x_{nm}\end{bmatrix}\begin{bmatrix}\beta_0\\ \beta_1\\ \beta_2\\ \vdots\\ \beta_m\end{bmatrix}$$
△ Why the column of 1s?

Matrix ka pehla column sirf 1s rakhta hai. Yeh column isliye include hota hai kyunki intercept term $\beta_0$ ko har row mein appear karna hai. $1 \times \beta_0 = \beta_0$ — bilkul wahi jo hume chahiye.

Sizes — yeh exam mein pakka poocha jaata hai

ObjectNameDimensionsContents
$\mathbf X$Design matrix$n \times (m+1)$$n$ rows, $m+1$ columns (1s column $+$ $m$ features)
$\boldsymbol\beta$Parameter vector$(m+1) \times 1$$\beta_0$ through $\beta_m$
$\hat{\mathbf y}$Prediction vector$n \times 1$one prediction per row
Compact form$$\boxed{\;\hat{\mathbf y} = \mathbf X\boldsymbol\beta\;}$$

Dimension check: $(n \times (m{+}1)) \cdot ((m{+}1) \times 1) = n \times 1$ ✓

4Defining the residual at each data point

$$e_i = y_i - \hat y_i \qquad\qquad e_i^2 = (y_i - \hat y_i)^2$$
Total squared error — the loss to minimize$$L = e_1^2 + e_2^2 + \cdots + e_n^2 = \sum_{i=1}^{n}(y_i - \hat y_i)^2$$
★ Key Insight

Chhota residual = accurate prediction. Bada residual = poor prediction. Hum is total squared error ko $L(\boldsymbol\beta)$ se denote karte hain — yahi loss function hai jise minimize karna hai.

5Writing the residuals as a vector

$$\mathbf e = \begin{bmatrix}e_1\\ e_2\\ e_3\\ \vdots\\ e_n\end{bmatrix} = \begin{bmatrix}y_1 - \hat y_1\\ y_2 - \hat y_2\\ y_3 - \hat y_3\\ \vdots\\ y_n - \hat y_n\end{bmatrix} = \mathbf y - \hat{\mathbf y}$$

Ab residual vector ko uske transpose se multiply karo:

$$\mathbf e^\top\mathbf e = \begin{bmatrix}(y_1-\hat y_1) & (y_2-\hat y_2) & \cdots & (y_n-\hat y_n)\end{bmatrix}\begin{bmatrix}y_1-\hat y_1\\ y_2-\hat y_2\\ \vdots\\ y_n-\hat y_n\end{bmatrix}$$

Yeh multiplication perform karne par:

$$\mathbf e^\top\mathbf e = (y_1-\hat y_1)^2 + (y_2-\hat y_2)^2 + \cdots + (y_n-\hat y_n)^2 = \sum_{i=1}^{n}(y_i - \hat y_i)^2$$
★ Key Insight

Dot product $\mathbf e^\top\mathbf e$ automatically sum of squared residuals compute kar deta hai — ek matrix operation poori summation ko replace kar deti hai.

Loss in matrix form$$L = \mathbf e^\top\mathbf e \qquad\text{and since } \mathbf e = \mathbf y - \mathbf X\boldsymbol\beta:$$ $$\boxed{\;L(\boldsymbol\beta) = (\mathbf y - \mathbf X\boldsymbol\beta)^\top(\mathbf y - \mathbf X\boldsymbol\beta)\;}$$
♦ Takeaway

Loss function $L(\boldsymbol\beta) = \mathbf e^\top\mathbf e$ parameter vector $\boldsymbol\beta$ ko input leti hai aur ek number (total squared error) return karti hai. Formally: $L : \mathbb R^{m+1} \to \mathbb R$.

6Expanding the Loss Function

▷ Hook

$L(\boldsymbol\beta) = (\mathbf y - \mathbf X\boldsymbol\beta)^\top(\mathbf y - \mathbf X\boldsymbol\beta)$ compact hai par differentiate karna mushkil. Ise term by term expand karte hain.

Derivation

Expanding to three terms

  1. Transpose of a difference $$(\mathbf y - \mathbf X\boldsymbol\beta)^\top = \mathbf y^\top - (\mathbf X\boldsymbol\beta)^\top = \mathbf y^\top - \boldsymbol\beta^\top\mathbf X^\top$$

    Using the rule $(\mathbf{AB})^\top = \mathbf B^\top\mathbf A^\top$, and more generally $(\mathbf{ABC})^\top = \mathbf C^\top\mathbf B^\top\mathbf A^\top$.

  2. Multiply out $$L(\boldsymbol\beta) = (\mathbf y^\top - \boldsymbol\beta^\top\mathbf X^\top)(\mathbf y - \mathbf X\boldsymbol\beta)$$ $$= \mathbf y^\top\mathbf y - \mathbf y^\top\mathbf X\boldsymbol\beta - \boldsymbol\beta^\top\mathbf X^\top\mathbf y + \boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta$$
  3. Dimension verification — sab scalars hain
    TermDimensionsResult
    $\mathbf y^\top\mathbf y$$(1\times n)(n\times 1)$$1\times 1$ — scalar
    $\mathbf y^\top\mathbf X\boldsymbol\beta$$(1\times n)(n\times(m{+}1))((m{+}1)\times 1)$$1\times 1$ — scalar
    $\boldsymbol\beta^\top\mathbf X^\top\mathbf y$$(1\times(m{+}1))((m{+}1)\times n)(n\times 1)$$1\times 1$ — scalar
    $\boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta$$(1\times(m{+}1))((m{+}1)\times(m{+}1))((m{+}1)\times 1)$$1\times 1$ — scalar
  4. The two middle terms are equal $$\mathbf y^\top\mathbf X\boldsymbol\beta = \boldsymbol\beta^\top\mathbf X^\top\mathbf y$$

    Why? Kyunki dono scalars hain, aur ek scalar ka transpose khud wahi scalar hota hai. Formally: $(\mathbf y^\top\mathbf X\boldsymbol\beta)^\top = \boldsymbol\beta^\top\mathbf X^\top\mathbf y$, aur LHS $1\times 1$ hai, to $\mathbf y^\top\mathbf X\boldsymbol\beta = \boldsymbol\beta^\top\mathbf X^\top\mathbf y$.

    $$\text{Combining: }\; -\mathbf y^\top\mathbf X\boldsymbol\beta - \boldsymbol\beta^\top\mathbf X^\top\mathbf y = -2\,\mathbf y^\top\mathbf X\boldsymbol\beta$$
  5. Final expanded form
    Equation 1$$\boxed{\;L(\boldsymbol\beta) = \mathbf y^\top\mathbf y - 2\,\mathbf y^\top\mathbf X\boldsymbol\beta + \boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta\;}$$
★ Key Insight — three terms, three types
  • $\mathbf y^\top\mathbf y$ — constant w.r.t. $\boldsymbol\beta$
  • $-2\,\mathbf y^\top\mathbf X\boldsymbol\beta$ — linear in $\boldsymbol\beta$
  • $\boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta$ — quadratic in $\boldsymbol\beta$

Yeh loss convex hai — minimum exist karta hai aur unique hai. Aur yahi teen types hume teen identities ki zaroorat batati hain.

7Writing the gradient condition for the minimum

Bowl ke bottom par, har direction flat hoti hai. Math mein: saare partial derivatives zero hote hain.

$$\frac{\partial L}{\partial\beta_0} = 0, \quad \frac{\partial L}{\partial\beta_1} = 0, \quad \dots, \quad \frac{\partial L}{\partial\beta_m} = 0$$

Inhe gradient vector mein stack karo:

$$\nabla L = \begin{bmatrix}\dfrac{\partial L}{\partial\beta_0} & \dfrac{\partial L}{\partial\beta_1} & \cdots & \dfrac{\partial L}{\partial\beta_m}\end{bmatrix}^\top \qquad\Longrightarrow\qquad \boxed{\;\frac{\partial L}{\partial\boldsymbol\beta} = \mathbf 0\;}\ \text{(zero vector)}$$
♦ Takeaway

Equation (1) ko differentiate karne ke liye hume teen identities chahiye — har term type ke liye ek (constant, linear, quadratic).

8Identity 1 · Derivative of a Constant w.r.t. a Vector

Agar $f(\boldsymbol\beta) = c$ (ek constant scalar jo $\boldsymbol\beta$ par depend nahi karta):

$$\frac{\partial f}{\partial\boldsymbol\beta} = \mathbf 0 \quad\text{(zero vector)}$$

Humari loss par apply: $\mathbf y^\top\mathbf y$, $\boldsymbol\beta$ se independent hai, isliye:

Equation 2$$\frac{\partial(\mathbf y^\top\mathbf y)}{\partial\boldsymbol\beta} = \mathbf 0$$

9Identity 2 · Derivative of a Linear Form

▷ Hook

$\mathbf a^\top\boldsymbol\beta = a_0\beta_0 + a_1\beta_1 + \cdots$ — har term differentiate karne par wapas $a_i$ milta hai. Poora gradient kaisa dikhta hai?

Derivation

$\dfrac{\partial(\mathbf a^\top\boldsymbol\beta)}{\partial\boldsymbol\beta} = \mathbf a$

Given $f(\boldsymbol\beta) = \mathbf a^\top\boldsymbol\beta$, where $\mathbf a$ is a constant vector:

$$f(\boldsymbol\beta) = a_0\beta_0 + a_1\beta_1 + \cdots + a_m\beta_m$$

Differentiating each component:

$$\frac{\partial f}{\partial\beta_0} = a_0, \quad \frac{\partial f}{\partial\beta_1} = a_1, \quad \dots, \quad \frac{\partial f}{\partial\beta_m} = a_m$$

Stacked into a vector:

Identity 2$$\frac{\partial(\mathbf a^\top\boldsymbol\beta)}{\partial\boldsymbol\beta} = \begin{bmatrix}a_0\\ a_1\\ \vdots\\ a_m\end{bmatrix} = \mathbf a$$

Applied to our loss: the linear term is $-2\,\mathbf y^\top\mathbf X\boldsymbol\beta$. Here $\mathbf a^\top = -2\,\mathbf y^\top\mathbf X$, so $\mathbf a = -2\,\mathbf X^\top\mathbf y$:

Equation 3$$\frac{\partial(-2\,\mathbf y^\top\mathbf X\boldsymbol\beta)}{\partial\boldsymbol\beta} = -2\,\mathbf X^\top\mathbf y$$

10Identity 3 · Derivative of a Quadratic Form

▷ Hook

$\boldsymbol\beta^\top\mathbf A\boldsymbol\beta$ $ax^2$ ka matrix version hai. $ax^2$ ka derivative $2ax$ hota hai. Matrix version kya hoga?

Derivation

Full $2\times 2$ worked example proving $\dfrac{\partial(\boldsymbol\beta^\top\mathbf A\boldsymbol\beta)}{\partial\boldsymbol\beta} = 2\mathbf A\boldsymbol\beta$

Let $\mathbf A = \begin{bmatrix}a_{11} & a_{12}\\ a_{12} & a_{22}\end{bmatrix}$ (symmetric, so $\mathbf A^\top = \mathbf A$) and $\boldsymbol\beta = [\beta_1,\ \beta_2]^\top$.

  1. Step 1 — Compute $\mathbf A\boldsymbol\beta$ $$\mathbf A\boldsymbol\beta = \begin{bmatrix}a_{11}\beta_1 + a_{12}\beta_2\\ a_{12}\beta_1 + a_{22}\beta_2\end{bmatrix}$$
  2. Step 2 — Compute $\boldsymbol\beta^\top(\mathbf A\boldsymbol\beta)$ $$\boldsymbol\beta^\top\mathbf A\boldsymbol\beta = \beta_1(a_{11}\beta_1 + a_{12}\beta_2) + \beta_2(a_{12}\beta_1 + a_{22}\beta_2)$$ $$= a_{11}\beta_1^2 + a_{12}\beta_1\beta_2 + a_{12}\beta_1\beta_2 + a_{22}\beta_2^2$$ $$= a_{11}\beta_1^2 + 2a_{12}\beta_1\beta_2 + a_{22}\beta_2^2$$
  3. Step 3 — Differentiate component-wise $$\frac{\partial f}{\partial\beta_1} = 2a_{11}\beta_1 + 2a_{12}\beta_2, \qquad \frac{\partial f}{\partial\beta_2} = 2a_{12}\beta_1 + 2a_{22}\beta_2$$
  4. Step 4 — Stack and factor $$\frac{\partial f}{\partial\boldsymbol\beta} = \begin{bmatrix}2a_{11}\beta_1 + 2a_{12}\beta_2\\ 2a_{12}\beta_1 + 2a_{22}\beta_2\end{bmatrix} = 2\begin{bmatrix}a_{11} & a_{12}\\ a_{12} & a_{22}\end{bmatrix}\begin{bmatrix}\beta_1\\ \beta_2\end{bmatrix} = 2\mathbf A\boldsymbol\beta$$
    Identity 3 (general result)$$\boxed{\;\frac{\partial(\boldsymbol\beta^\top\mathbf A\boldsymbol\beta)}{\partial\boldsymbol\beta} = 2\mathbf A\boldsymbol\beta \quad\text{(for symmetric }\mathbf A)\;}$$
Applying to our loss — is $\mathbf X^\top\mathbf X$ symmetric?

The quadratic term is $\boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta$. Let $\mathbf A = \mathbf X^\top\mathbf X$. Check:

$$(\mathbf X^\top\mathbf X)^\top = \mathbf X^\top(\mathbf X^\top)^\top = \mathbf X^\top\mathbf X = \mathbf A \quad\checkmark\ \textbf{Yes}$$
Equation 4$$\frac{\partial(\boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta)}{\partial\boldsymbol\beta} = 2\,\mathbf X^\top\mathbf X\boldsymbol\beta$$

11Differentiating the Expanded Loss — The Normal Equation ⭐

The Main Derivation

From $L(\boldsymbol\beta)$ to $\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$

Recall Equation (1):

$$L(\boldsymbol\beta) = \underbrace{\mathbf y^\top\mathbf y}_{\text{Eq 2}} \;\underbrace{-\,2\,\mathbf y^\top\mathbf X\boldsymbol\beta}_{\text{Eq 3}} \;+\; \underbrace{\boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta}_{\text{Eq 4}}$$
  1. Apply the three identities term by term $$\frac{\partial L}{\partial\boldsymbol\beta} = \mathbf 0 \;-\; 2\,\mathbf X^\top\mathbf y \;+\; 2\,\mathbf X^\top\mathbf X\boldsymbol\beta$$
  2. At the minimum, set $\partial L/\partial\boldsymbol\beta = \mathbf 0$ $$-2\,\mathbf X^\top\mathbf y + 2\,\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf 0$$
  3. Rearrange (divide by 2, move terms)
    The Normal Equation$$\boxed{\;\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf X^\top\mathbf y\;}$$
  4. Multiply both sides by $(\mathbf X^\top\mathbf X)^{-1}$
    The closed-form OLS solution$$\boxed{\;\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\,\mathbf X^\top\mathbf y\;}$$
★ Key Insight

Yeh Multiple Linear Regression ka closed-form OLS solution hai. Yeh optimal $\boldsymbol\beta$ ko data se directly compute karta hai — no iteration, no guessing. Equation $\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf X^\top\mathbf y$ ko Normal Equation kehte hain.

♦ Takeaway — how to read the formula

$\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$ — "compute $\mathbf X^\top\mathbf X$, invert it, multiply by $\mathbf X^\top\mathbf y$." Bas.

12When does this closed-form solution work?

$\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$ ke kaam karne ke liye, $(\mathbf X^\top\mathbf X)^{-1}$ ka exist karna zaroori hai. Iske liye $\mathbf X$ ke columns ko linearly independent hona chahiye. Agar $\det(\mathbf X^\top\mathbf X) = 0$, to $\mathbf X^\top\mathbf X$ singular hai aur inverse exist nahi karta.

△ Warning — MULTICOLLINEARITY

Agar $\mathbf X$ ka koi column doosre columns ka linear combination hai, to $\mathbf X^\top\mathbf X$ singular ban jaata hai. Ise multicollinearity kehte hain — closed-form solution poori tarah break down ho jaata hai. (Detail mein 👉 Lecture 8.)

♦ Takeaway

OLS formula $\mathbf X^\top\mathbf X$ ki invertibility par depend karta hai. Dependent columns → no inverse → no solution.

13Computational limitation of the closed-form solution

$\mathbf X^\top\mathbf X$ ke dimensions $(m+1)\times(m+1)$ hain. Ek $k \times k$ matrix invert karne ki cost approximately:

$$O(k^3)$$

Agar $m = 10{,}000$ features:

$$10{,}000^3 = 10^{12}\ \text{operations} \;-\; \textbf{one trillion!}$$
★ Key Insight

Jab features ki sankhya badi hoti hai, closed-form solution impractical ho jaata hai. Tab hum iterative methods jaise Gradient Descent use karte hain (👉 Lecture 5).

14Proof of the $O(k^3)$ inverse complexity

▷ Hook

Ek $k\times k$ matrix invert karne mein exactly $k^3$ operations kyun lagte hain? Teen nested loops poori kahani bata dete hain.

Ek $k\times k$ matrix $\mathbf A$ invert karne ke liye, augmented matrix $[\mathbf A \mid \mathbf I]$ banao aur $\mathbf A$ ko $\mathbf I$ mein row-reduce karo (Gauss–Jordan elimination).

LoopWhat It DoesIterations
OuterIterate through $k$ pivot columns$k$
MiddleEliminate $k$ rows per pivot$k$
InnerProcess $\sim 2k$ elements per row (augmented matrix)$2k$
$$k \times k \times 2k = 2k^3 \;\longrightarrow\; O(k^3)$$
Practice P9

Real-world scenarios

  1. (a) A startup collects three features: temperature (°C), humidity (%), and temperature + humidity (they literally summed the first two columns to create the third). Can they apply the OLS formula?
    No.

    Exactly kya galat hota hai: Column 3 $=$ Column 1 $+$ Column 2 — ek exact linear combination. Iska matlab $\mathbf X$ ke columns linearly dependent hain. Isliye $\mathbf X^\top\mathbf X$ ka $\det = 0$ hoga → $\mathbf X^\top\mathbf X$ singular hai → $(\mathbf X^\top\mathbf X)^{-1}$ exist hi nahi karta → formula undefined.

    Problem ka naam: Perfect (exact) Multicollinearity.

    Fix: teeno mein se ek column drop kar do — wo koi nayi information de hi nahi raha.

  2. (b) Dataset has $m = 100{,}000$ features. Computer does $10^9$ operations/second. How long would matrix inversion take? $$\text{Inversion cost} \approx (100{,}000)^3 = (10^5)^3 = \mathbf{10^{15}}\ \text{operations}$$ $$\text{Time} \approx \frac{10^{15}}{10^9} = 10^6\ \text{seconds}$$ $$= \frac{10^6}{86{,}400} \approx \mathbf{11.6\ days}$$
    Practical? No. Instead use Gradient Descent (iterative, per-iteration cost is only $O(nm)$).
  3. (c) A colleague says: "Always use OLS — it gives the exact optimal answer!" Give two reasons why this is not always a good idea.
    1. Agar features linearly dependent hain (multicollinearity), $\mathbf X^\top\mathbf X$ singular hai aur formula kaam hi nahi karta — exact answer to door ki baat.
    2. Cost $O(m^3)$ hai. Large $m$ ke liye yeh computationally infeasible ho jaata hai (upar dekho: 11.6 days).

    Bonus (worth mentioning in exams): Numerical instability — jab $\mathbf X^\top\mathbf X$ near-singular ho (features almost dependent), inverse mathematically exist karta hai par floating-point mein wildly unstable hota hai.

15Final Takeaway — The Complete MLR-OLS Derivation

StepActionResult
1Write MLR prediction$\hat y_i = \beta_0 + \beta_1x_{i1} + \cdots + \beta_mx_{im}$
2Stack as vector$\hat{\mathbf y} = \mathbf X\boldsymbol\beta$
3Define residual$e_i = y_i - \hat y_i$
4Total squared error$L = \mathbf e^\top\mathbf e = (\mathbf y - \mathbf X\boldsymbol\beta)^\top(\mathbf y - \mathbf X\boldsymbol\beta)$
5Expand loss$L = \mathbf y^\top\mathbf y - 2\mathbf y^\top\mathbf X\boldsymbol\beta + \boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta$
6Derive 3 identitiesEq 2: $\partial(c)/\partial\boldsymbol\beta = \mathbf 0$  ·  Eq 3: $\partial(\mathbf a^\top\boldsymbol\beta)/\partial\boldsymbol\beta = \mathbf a$  ·  Eq 4: $\partial(\boldsymbol\beta^\top\mathbf A\boldsymbol\beta)/\partial\boldsymbol\beta = 2\mathbf A\boldsymbol\beta$
7Differentiate, set $\nabla = \mathbf 0$$\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf X^\top\mathbf y$ (Normal Equation)
8Solve for $\boldsymbol\beta^*$$\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$

△ Reflect 1 — Why was the fit perfect, and would 100 points also fit perfectly?

Humare paas 3 data points aur 3 parameters the — yaani 3 equations, 3 unknowns. Generically iska ek exact solution hota hai, isliye residuals zero aaye.
100 data points par sirf 3 parameters ke saath? Nahi. Ab 100 equations hain par sirf 3 unknowns — system overdetermined hai. Perfect fit tabhi possible hai jab $n \le (m+1)$. Otherwise OLS best compromise dhundta hai jo total squared error minimize kare.
Aur yeh acchi baat hai: perfect fit ka matlab aksar yeh hota hai ki model ne noise memorize kar liya. 👉 Lecture 9 — Bias–Variance

△ Reflect 2 — Formula ek step mein exact answer deta hai. Gradient Descent bohot steps leta hai. Slow method kyun prefer karein?

Kyunki "ek step" ki cost $O(m^3)$ hai. $m = 10{,}000$ par wo $10^{12}$ operations hai. Gradient Descent ki per-iteration cost sirf $O(nm)$ hai — wo hazaar iterations bhi ek single matrix inversion se sasta hoga. Aur GD tab bhi chal jaata hai jab $\mathbf X^\top\mathbf X$ singular ho.

⚠ Common Mistakes

GaltiSahi Baat
Design matrix mein 1s column bhool jaanaBina us column ke intercept $\beta_0$ model mein aata hi nahi. $\mathbf X$ is $n\times(m+1)$, not $n\times m$.
$\mathbf X^\top\mathbf X$ ko $n\times n$ samajhnaWo $(m+1)\times(m+1)$ hai — features ki sankhya se, rows se nahi.
$(\mathbf{AB})^\top = \mathbf A^\top\mathbf B^\top$Correct rule: $(\mathbf{AB})^\top = \mathbf B^\top\mathbf A^\top$ — order reverses.

⚡ Quick Revision

Model

$\hat{\mathbf y} = \mathbf X\boldsymbol\beta$,  $\mathbf X: n\times(m{+}1)$,  $\boldsymbol\beta: (m{+}1)\times1$

Loss

$L(\boldsymbol\beta) = \mathbf y^\top\mathbf y - 2\mathbf y^\top\mathbf X\boldsymbol\beta + \boldsymbol\beta^\top\mathbf X^\top\mathbf X\boldsymbol\beta$

3 Identities

$\partial c/\partial\boldsymbol\beta = \mathbf 0$ · $\partial(\mathbf a^\top\boldsymbol\beta)/\partial\boldsymbol\beta = \mathbf a$ · $\partial(\boldsymbol\beta^\top\mathbf A\boldsymbol\beta)/\partial\boldsymbol\beta = 2\mathbf A\boldsymbol\beta$

Normal Equation

$\mathbf X^\top\mathbf X\boldsymbol\beta = \mathbf X^\top\mathbf y$

Solution

$\boldsymbol\beta^* = (\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y$

Fails when

$\det(\mathbf X^\top\mathbf X) = 0$ (multicollinearity) · or $m$ too large ($O(m^3)$)
